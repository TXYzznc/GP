# 角色美术提示词生成器

## 两种模式

根据用户需求判断使用哪种模式：

| 用户描述 | 模式 |
|---------|------|
| 设定图、三视图、设定板、CG质感、影视级、角色海报 | **模式A：影视级CG设定图** |
| 立绘、头像、卡面、游戏内图片 | **模式B：游戏立绘** |

不确定时默认使用**模式A**，质量更高。

## 模式A：影视级CG角色设定图

### 核心方法论：5层嵌套结构

高质量角色设定图提示词由5层构成，每层都不可缺少：

```
层1 技术基底 → 定义渲染引擎和质量锚点 层2 画面构图 → 定义版式和布局结构
层3 角色核心 → 定义身份、种族、气质（含否定限定） 层4 外观细节 → 从上到下逐部位：脸→发→服→配饰→鞋 层5 氛围渲染 → 光影、环境、特效、色调
```

**关键技巧：**
- 每个部位描述要包含：形态 + 材质 + 颜色 + 特殊元素
- 气质用**对比定位**（"不是A，不是B，而是A和B之间的C"）
- 材质描述要具体（"毛孔轻微可见"而非"皮肤好"）

### 模式A 提示词模板

```

[层2 画面构图] 9:16竖版构图，规整排版，角色设定板，三视图+细节展示 画面结构：左侧为人物正面全身立绘，右侧为正面/侧面/背面三视图排版， 下方与侧边为局部细节特写（脸部、发饰、服装纹理、鞋子）， 整体UI风格干净高级，带少量设计说明文字与装饰线条

[层3 角色核心] 角色设定：[角色名]，[性别]，[种族/职业]，[年龄感]，[身材特征] 气质定位：[正向描述]，不是[否定A]，也不是[否定B]，是[精准定位]

[层5 氛围渲染] 光影与效果：[色调]，[环境元素]，[特效粒子]，[材质高光特征]，[整体氛围] 风格关键词：超写实、CG角色、影视级建模质感、游戏角色设定图、[风格标签]

```

## 模式B：游戏立绘/头像

### 核心设计理念

Clash of Gods 游戏内角色风格：**东方奇幻 + 黑暗史诗**，人物造型厚重有力，服饰融合神话元素。

## 工作流程

1. **判断模式** — 根据用户描述选择A或B
2. **提取角色信息** — 从用户输入或项目文档中提取：名称、种族/职业、外貌、气质、技能特征
3. **逐层填充** — 按模板结构逐层推理，不跳过任何层
4. **输出提示词** — 完整提示词 + 简要推理说明
5. **可选** — 同时输出中文版（用于理解）和英文版（用于生成）

## 信息不足时的处理

- 用户只给角色名 → 先查项目文档（`开发文档/开发文档-毕设角色设计.md`）获取设定
- 用户描述模糊 → 根据职业/种族推断合理的视觉设计，并说明推断依据
- 用户给了参考图 → 结合图片信息和文字描述共同生成

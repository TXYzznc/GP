#### 后羿（ID=1）
- **当前**：10, 20
- **新值**：85, 150
- **改动**：数值调整为符合设计标准

#### 嫦娥（ID=4）
- **当前**：10, 20
- **新值**：85, 150
- **改动**：同上，统一升阶经验

```
RequiredEXP: 85, 150
ConditionEventId: 0, 0

```
- **理由**：蓝色品质，与其他棋子使用相同的升阶经验

#### 恶魂（ID=11）
```
RequiredEXP: 85, 150

AdvanceEffectId: 0
```
- **理由**：蓝色品质，相同的升阶经验标准

  - Boss 通常不可升阶，或需要特殊条件

  - 如果可以升阶，考虑设更高的经验要求

## 升阶经验验证

### 理论基础
- 一场战斗的奖励：击败一个三阶敌方棋子获得 60 EXP
- 升阶总需求：85 + 150 = 235 EXP
- 所需战斗数：235 ÷ 60 ≈ **3.9 ≈ 4 场**

### 升阶进度表
| 升阶 | 所需EXP | 所需战斗数 | 累计EXP | 累计战斗数 |
|------|---------|-----------|---------|-----------|
| 一→二 | 85 | 1.4 场 | 85 | 1.4 |
| 二→三 | 150 | 2.5 场 | 235 | 3.9 ≈ 4 |

**结论**：玩家需要赢得约 4 场战斗才能将一个棋子升级到三阶，这符合设计目标（5-10 分钟的游戏时间）

## Boss 特殊处理

### 黑暗杨戬（ID=12）的处理方案

**选项 1：不可升阶**
```
RequiredEXP: 0, 0
```
- 优点：Boss 无法升阶，保持强度恒定
- 缺点：与普通棋子行为不一致
- 建议：✅ **推荐**

**选项 2：需要极高经验**
```
RequiredEXP: 999999, 999999
```
- 优点：理论可升但实际不会升
- 缺点：配置繁琐
- 建议：不推荐

**选项 3：与普通棋子相同**
```
RequiredEXP: 85, 150
```
- 优点：行为一致
- 缺点：Boss 可能过强
- 建议：需要游戏设计决策

**最终建议**：使用选项 1（0, 0）让 Boss 不可升阶

## 关键发现与决策

### 1. 嫦娥属性严重不合理（最高优先）
**问题**：
- 一阶 HP = 30（极低）
- 三阶 HP = 580（极高）
- 倍数：30 → 420 → 580 = **1:14:19.3**（完全错误！）
- 其他属性也都不规范

**解决**：
- 重新设计为法师辅助型（而非混合输出型）
- 新的 HP 倍数：330 → 528 → 792 = **1:1.6:2.4**（规范）
- 去掉所有物理攻击，强化法强和防御

**影响**：
- 一阶 HP 大幅提升（30 → 330）
- 但这是必要的修正，不是过度设计

### 2. 后羿三阶攻击过高
**问题**：
- 当前：10 → 16 → 26（倍数 2.6x）
- 标准应该：10 → 16 → 24（倍数 2.4x）

**解决**：
- 三阶攻击：26 → 24（-2，-7.7%）
- 通过提升攻击速度补偿（0.8 → 1.2）
- 保持 FC 线性增长

### 3. 邪灵与恶魂需要规范化
**问题**：
- 当前是混合输出型（既有物攻，又有法强）
- 不符合职业-功能标准

**解决**：
- 完全去掉物理攻击（AtkDamage = 0）
- 专注于法强输出/控制
- 规范所有属性为线性倍数

### 4. 恶魂 Armor 二阶异常
**问题**：
- 一阶：20
- 二阶：15（下降！）
- 三阶：20
- 这是明显的配置错误

**解决**：
- 二阶：15 → 32（修复）
- 三阶：20 → 48（规范）
- 倍数：20 → 32 → 48 = **1:1.6:2.4**

### 5. 黑暗杨戬保持超模
**决策**：
- 维持金色品质 + Boss 超模设定
- 规范为线性倍数 1.6x, 2.4x
- 所有属性统一提升 20-50%

## 修改详情

### 1. 后羿（ID=1）— 紫色射手输出

**目的**：规范线性倍数 1.0→1.6→2.4，去除不合理的三阶攻击数值

#### MaxHp 字段
- **当前**：400, 580, 800
- **新值**：400, 640, 960
- **改动**：
  - 二阶：580 → 640（+10%）
  - 三阶：800 → 960（+20%）
- **理由**：规范为线性倍数 1.6x, 2.4x

#### AtkDamage 字段
- **当前**：10, 16, 26
- **新值**：10, 16, 24
- **改动**：
  - 二阶：保持（16 = 16）✓
  - 三阶：26 → 24（-2，即 -7.7%）
- **理由**：规范为线性倍数 1.0x, 1.6x, 2.4x；当前 26 = 2.6x 属于过度设计

#### AtkSpeed 字段
- **当前**：0.5, 0.65, 0.8
- **新值**：0.5, 0.8, 1.2
- **改动**：
  - 二阶：0.65 → 0.8（+23%）
  - 三阶：0.8 → 1.2（+50%）
- **理由**：为了补偿攻击力下调，增加攻击速度；保持 FC 线性增长

#### Armor 字段
- **当前**：20, 25, 30
- **新值**：20, 32, 48
- **改动**：
  - 二阶：25 → 32（+28%）
  - 三阶：30 → 48（+60%）
- **理由**：规范为线性倍数 1.6x, 2.4x；增强射手的防御能力

#### MagicResist 字段
- **当前**：20, 25, 30
- **新值**：20, 32, 48
- **改动**：同 Armor
- **理由**：射手输出职业标准中，魔抗权重 = 护甲权重

#### SpellPower 字段
- **当前**：0, 0, 0
- **新值**：0, 0, 0
- **改动**：无（保持为 0）✓

#### CritRate 字段
- **当前**：0.15, 0.2, 0.25
- **新值**：0.15, 0.24, 0.36
- **改动**：
  - 二阶：0.2 → 0.24（+20%）
  - 三阶：0.25 → 0.36（+44%）
- **理由**：配合攻击力线性化，暴击率也应线性化

### 2. 嫦娥（ID=4）— 紫色法师辅助 **[最高优先级 - 重大改动]**

**目的**：修复严重属性不平衡（当前 HP 倍数 19.3x！），改为纯法系辅助型，去除物理攻击

#### MaxHp 字段
- **当前**：30, 420, 580
- **新值**：330, 528, 792
- **改动**：
  - 一阶：30 → 330（+1000%，这是修复严重 BUG！）
  - 二阶：420 → 528（+25.7%）
  - 三阶：580 → 792（+36.6%）
- **理由**：
  - 当前数据 HP 倍数 1→14.0→19.3，完全违反规范
  - 新值符合线性倍数 1.0→1.6→2.4
  - 紫色品质的法师应该有 330 的一阶生命

#### MaxMp 字段
- **当前**：120, 120, 120
- **新值**：120, 120, 120
- **改动**：无（保持）✓
- **理由**：法力值不参与战力计算，保持原值

#### AtkDamage 字段
- **当前**：8, 12, 20
- **新值**：0, 0, 0
- **改动**：完全删除物理攻击
- **理由**：
  - 嫦娥是法师辅助，不应该有物理伤害
  - 职业-功能标准中 AtkDamage = 0.0（权重为 0）

#### Armor 字段
- **当前**：10, 12, 15
- **新值**：20, 32, 48
- **改动**：
  - 一阶：10 → 20（+100%）
  - 二阶：12 → 32（+167%）
  - 三阶：15 → 48（+220%）
- **理由**：
  - 提升法师防御能力
  - 规范为线性倍数 1.6x, 2.4x
  - 符合法师辅助职业的标准

#### MagicResist 字段
- **当前**：25, 35, 45
- **新值**：20, 32, 48
- **改动**：
  - 一阶：25 → 20（-20%）
  - 二阶：35 → 32（-8.6%）
  - 三阶：45 → 48（+6.7%）
- **理由**：
  - 调整到与 Armor 平衡
  - 规范为线性倍数 1.6x, 2.4x

#### SpellPower 字段
- **当前**：16, 28, 45
- **新值**：16, 25.6, 38.4
- **改动**：
  - 二阶：28 → 25.6（-8.6%）
  - 三阶：45 → 38.4（-14.7%）
- **理由**：
  - 规范为线性倍数 1.6x, 2.4x
  - 当前三阶过度设计，已超过线性范围

#### CritRate 字段
- **当前**：0.15, 0.15, 0.15
- **新值**：0.1, 0.16, 0.24
- **改动**：
  - 二阶：0.15 → 0.16（无实质变化）
  - 三阶：0.15 → 0.24（+60%）
- **理由**：配合法师的等级提升，暴击率应该提高

## 修改流程

### Phase 1：准备（当前）
- ✅ 完成属性分析和计算
- ✅ 生成修改清单
- ⏳ 用户确认修改方案

### Phase 2：数据验证（用户确认后）
- 重新验证所有 FC 值
- 检查品质间倍数
- 确保所有棋子的相对强度合理

### Phase 3：修改配置表（确认后）
1. 使用 DataTable 工具修改 SummonChessTable
2. 修改 ChessAdvanceTable（如果需要调整升阶经验）
3. 更新相关文档

### Phase 4：验证（修改后）
1. 在 Unity 编辑器中加载新数据
2. 运行战斗测试
3. 验证品质间、阶级间的战力差异

## 风险评估

| 风险项 | 影响 | 缓解措施 |
|--------|------|---------|
| 嫦娥大幅修改 | 一阶 HP 增加 1000% | 需要充分测试，确保游戏难度平衡 |
| 恶魂 Armor 二阶异常修复 | 防御能力大幅提升 | 检查是否影响战力平衡 |
| 邪灵与恶魂法强调整 | 伤害输出改变 | 验证与现有 Buff 系统的交互 |
| Boss 属性大幅提升 | Boss 可能过强 | 在实际战斗中充分测试 |

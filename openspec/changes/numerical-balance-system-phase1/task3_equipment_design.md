## 3.2 装备合成配方设计

### 一级合成（小件 → 中件）

```
基础合成公式：两个基础装备合成产生一个中等装备

剑(401) + 盾(402)    → 剑盾(413)         攻击+50 防御+50
剑(401) + 手套(404)  → 破甲刀(414)       攻击+75 破甲-5
盾(402) + 靴(403)    → 防御靴(415)       防御+50 移速+10%
靴(403) + 手套(404)  → 速度手套(416)     暴击+15% 移速+10%
```

### 二级合成（蓝装 → 特殊效果）

```
强化剑(405) + 靴(403)      → 急速剑(417)    攻击+100 攻速+15%
强化盾(406) + 冻结buff     → 寒冰甲(418)    防御+100 减速+15%
强化剑(405) + 手套(404)    → 吸血剑(419)    攻击+100 吸血+20%
```

### 三级合成（中件 → 大件）

```
剑盾(413) + 破甲刀(414)    → 不死之刃(420)  攻击+125 防御+50 破甲-5
```

### 合成系统特性

- ✅ **逐步升级**：鼓励玩家在战斗中不断升级装备
- ✅ **权衡决策**：合成时需要舍弃现有装备以换取更强装备
- ✅ **多种路线**：不同合成组合产生不同强度的装备

## 3.4 装备战斗力提升计算

### 案例：后羿三阶捡到金装

**基础（无装备）**：
- FC = 960 × (24 × 1.2) = 27648

**捡到金装剑（攻击+200）**：
- 新攻击值：24 + (200/20) ≈ 34（简化，实际应按比例）
- 新FC ≈ 960 × (34 × 1.2) = 39168
- **提升倍率：39168 / 27648 ≈ 1.42x（约42% 战力提升）**

**捡到多件金装（攻击+200, 防御+200）**：
- 新攻击值：24 + (200/20) ≈ 34
- 新防御值：48 + 20 = 68
- 新FC ≈ 1008 × (34 × 1.2) = 41097
- **提升倍率：41097 / 27648 ≈ 1.49x（约49% 战力提升）**

✅ **结论**：金装掉落能显著改变战局（20-50% 战力提升），符合设计意图

## 3.5 装备系统的战斗体验设计

### 核心机制

1. **掉落驱动**：战斗中掉落装备，激励玩家主动拾取和装备
2. **即时反馈**：装备后立即生效，看得见的战力提升
3. **组合策略**：可通过合成升级装备，寻求更高效的配置
4. **局内消失**：战斗结束后自动卸下，避免永久收集压力

### 设计亮点

- **小件合成大件**：鼓励玩家在战斗中寻找合成机会
- **品质分层**：白蓝金三个品质对应不同难度的敌人
- **多种路线**：不同合成路线产生不同效果（攻击、防御、混合）

## 架构说明

**ItemTable**（通用物品表）
- 字段：Id、Name、Type、Rarity、IsOnlyInGame、Description、IconId、CanStack、MaxStackCount、SellPrice、Value、Weight
- 用途：所有物品的基础信息

**EquipmentTable**（装备配置表）
- 字段：Id、ItemTableId、EquipmentQuality（白/蓝/金，对应 Rarity）、MainAttrType、MainAttrValue、SecondaryAttrType、SecondaryAttrValue、SpecialEffect、DropProbability
- 用途：装备的特化配置（品质、主副属性、特殊效果、掉落概率）

## 3.3 装备掉落池与合成配方（备忘录）

### 掉落池规则

#### 普通敌人掉落池
- 掉落概率：100% 白装（60% 概率）
- 掉落数量：1-2 件
- 可掉落装备：剑、盾、靴、手套

#### 精英敌人掉落池
- 掉落概率：白装 60% + 蓝装 30% + 金装 10%
- 掉落数量：1-3 件
- 可掉落装备：剑、盾、靴、手套及其强化版

#### Boss 掉落池
- 掉落概率：白装 30% + 蓝装 50% + 金装 20%
- 掉落数量：2-4 件
- 特殊机制：10% 概率掉落特殊装备（合成产物）

### 合成配方

#### 一级合成（白装小件 → 中件）
```
剑(401) + 盾(402)       → 剑盾(413)
剑(401) + 手套(404)     → 破甲刀(414)
盾(402) + 靴(403)       → 防御靴(415)
靴(403) + 手套(404)     → 速度手套(416)
```

#### 二级合成（蓝装特殊效果）
```
强化剑(405) + 靴(403)    → 急速剑(417)
强化盾(406) + 冻结buff   → 寒冰甲(418)
强化剑(405) + 手套(404)  → 吸血剑(419)
```

#### 三级合成（大件）
```
剑盾(413) + 破甲刀(414) → 不死之刃(420)
```

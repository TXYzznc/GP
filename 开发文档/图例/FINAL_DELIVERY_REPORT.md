## 📐 每个规范的内容结构

### 用例图 (UC) 规范
```
- 图表结构（ASCII UML用例图）
- 参与者定义表
- 用例详解（每个用例的操作、条件、结果）
- 用例间关系（扩展/包含/关联）
- 系统组件映射表
- 触发流程图示
```

### 类图 (CD) 规范
```
- 图表设计规范（ASCII UML类图）
- 关键类详解（属性、方法、职责）
- 类间关系表
- 可见性说明
- 设计模式与原则
- 输出要求（分辨率、格式等）
```

### 活动图 (AD) 规范
```
- 完整活动流程（ASCII活动流程图）
- 决策点分析（条件判定）
- 子流程详解
- 流程优化方案
- 特殊情况处理
- 性能注意事项
```

### 时序图 (SD) 规范
```
- 对象交互时序（ASCII时序图）
- 调用关键时间表
- 多目标场景处理
- 异步处理方案
- 错误处理路径
- 性能关键点
```

### 程序流程图 (FD) 规范
```
- 状态转移图（ASCII流程图）
- 状态详解（条件、动作）
- 转移条件表
- 关键判定点
- 优先级决策树
- 调试模式说明
```

### 功能层次图 (FHD) 规范
```
- 系统分层架构
- 模块划分
- 接口定义
- 数据流向
- 依赖关系
- 实现状态
```

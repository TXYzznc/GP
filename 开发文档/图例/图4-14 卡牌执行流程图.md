## 📊 关键类说明

| 类/接口 | 职责 |
|---------|------|
| **CardEffectExecutor** | 统一调度卡牌效果执行，维护效果类型映射表 |
| **ICardEffect** | 效果接口，定义 Init(CardData) 和 Execute(Vector3) |
| **GenericCardEffect** | 通用效果实现，组合 ICardTargetSelector + ICardEffectApplier[] |
| **ICardTargetSelector** | 目标选择策略接口，8种实现对应8种 CardTargetType |
| **ICardEffectApplier** | 效果应用策略接口，包括 DamageApplier、HealApplier、BuffApplier 等 |
| **CardEffectHelper** | 静态工具类，封装 DealDamage、HealTarget、ApplyBuff、PlayEffect |

### CardTargetType 枚举

| 枚举值 | 说明 | 对应选择器 |
|--------|------|-----------|
| Self = 1 | 自身（召唤师） | SelfSelector |
| AllAllyExcludeSummoner = 2 | 全体友方（不含召唤师） | AllAllyExcludeSummonerSelector |
| AllAlly = 3 | 全体友方（含召唤师） | AllAlliesSelector |
| AllEnemy = 4 | 敌方全体 | AllEnemiesSelector |
| SingleAlly = 5 | 单体友方（就近） | ClosestAllySelector |
| AreaAlly = 6 | 范围内友方 | AlliesInRadiusSelector |
| AreaEnemy = 7 | 范围内敌方 | EnemiesInRadiusSelector |
| SingleEnemy = 8 | 单体敌方（就近） | ClosestEnemySelector |

## 📝 文字介绍

卡牌效果的执行由CardEffectExecutor统一调度，采用命令模式设计。ICardEffect接口定义了统一的执行契约：`Init(CardData cardData)` 负责注入卡牌数据，`Execute(Vector3 targetPosition)` 负责在指定位置触发效果。

当玩家将卡牌拖拽至战场区域释放时，系统首先检查灵力是否充足；满足消耗条件后扣除灵力，随即进入效果执行分支。CardEffectExecutor根据卡牌ID查询内部的效果类型映射表：对于少数具有复杂联动逻辑的特殊卡牌（如生命汲取、不屈意志），通过`Activator.CreateInstance`动态实例化对应的专用效果类；其余卡牌则走通用框架，由`GetTargetSelector`根据`CardTargetType`枚举选取目标选择器，由`GetEffectAppliers`根据配置表字段（DamageType、HealAmount、HitBuffIds等）组装效果应用器列表，最终构建`GenericCardEffect`实例执行。

效果执行时，各效果类通过CardEffectHelper工具类访问底层战斗系统，该工具类提供`DealDamage`（伤害计算）、`HealTarget`（生命恢复）、`ApplyBuff`（Buff施加）、`PlayEffect`（特效播放）四个标准化静态接口，屏蔽了底层系统的调用细节。效果执行完成后，从CardManager中移除已使用的卡牌。

目标选择通过CardTargetType枚举的8种类型覆盖全部战斗场景，单体和范围类型结合释放位置与配置表中的AreaRadius参数筛选最近目标。

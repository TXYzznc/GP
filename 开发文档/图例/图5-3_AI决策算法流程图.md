## 📊 AI决策算法流程表

| 步骤 | 操作 | 判定条件 | 真分支 | 假分支 |
|------|------|---------|--------|--------|
| 1 | 获取搜索范围 | 无 | - | - |
| 2 | 搜索可见目标 | 存在可见敌人 | 进入决策 | 执行随机动作 |
| 3 | 遍历技能列表 | 逐一检查每个技能 | - | - |
| 4 | 检查技能冷却 | 技能可用 | 进入评分 | 跳过该技能 |
| 5 | 检查能量 | 能量充足 | 计算评分 | 跳过该技能 |
| 6 | 判定目标 | 根据技能范围 | 确定有效目标 | 无有效目标 |
| 7 | 计算评分 | 基于伤害、优先级、距离 | - | - |
| 8 | 选择最优技能 | 评分最高 | - | - |
| 9 | 检查有效性 | 至少有一个技能 | 执行该技能 | 执行默认攻击 |
| 10 | 执行行动 | 无 | - | - |

### 评分公式

**AI 技能评分 = 伤害评分 × 优先级权重 - 距离惩罚 + 战术加成**

其中：
- **伤害评分** = 预计伤害 / 敌人最大HP（0-1范围）
- **优先级权重** = 技能的战术重要性（如CC技能权重高）
- **距离惩罚** = 距离 / 最大追击距离（鼓励近距离技能）
- **战术加成** = 根据战局动态调整（如低血量时治疗加成）

## 📝 文字介绍

### AI决策算法实现

AI决策算法（如图5-3所示）采用**评分系统**进行决策，综合考虑技能伤害、战术优先级、距离等多个因素，为敌人选择最优的行动。

#### 算法的核心步骤

**目标搜索**  
首先搜索视野范围内的可见敌人。若无目标，敌人执行随机动作（巡逻或待命）。这个步骤确保了敌人的感知能力。

**技能遍历与过滤**  
遍历敌人可用的所有技能，进行两层过滤：检查技能冷却状态和能量消耗。只有满足条件的技能才进入评分环节。这个过滤避免了无谓的计算。

**目标判定与评分**  
对于每个可用的技能，根据其范围类型（单体/群体）判定有效目标。然后根据伤害、优先级、距离等因素计算技能的评分。评分越高表示该技能的选择价值越大。

**最优选择**  
从所有可用技能中选择评分最高的，作为当前回合的行动。若无可用技能，执行默认攻击。

**行动执行与反馈**  
执行选定的技能，消耗能量，触发技能冷却，计算行动结果，发送完成事件通知战斗系统。

#### 设计的平衡特性

**多维度决策**  
评分系统综合考虑伤害、战术、距离等多个因素，使得AI的决策更加合理和有趣。单纯追求高伤害的AI往往显得呆板，多维度评分能产生更多样化的行为。

**可调参数**  
评分公式中的权重和加成都是可调的，策划人员可以通过调整这些参数来改变AI的战斗风格（激进/防守/平衡）。

**性能考虑**  
算法在每个敌人的每个回合执行一次，评分计算都是简单的数学操作，不涉及复杂的AI搜索，确保了实时性能。

## 🎯 使用场景

- **AI难度调整**：通过修改评分权重改变AI强度
- **战术风格设计**：为不同敌人类型设计不同的AI参数
- **性能分析**：AI决策是战斗中的CPU密集操作
- **行为调试**：观察AI的决策过程，诊断异常行为

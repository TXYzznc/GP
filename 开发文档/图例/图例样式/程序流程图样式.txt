【图形元素规范】
起始/结束  → 圆角矩形（胶囊形，圆角半径=高度/2），内写"开始"或"结束"
处理      → 直角矩形，内写操作步骤名称
判定      → 菱形，内写判断条件（如"正确?"），
            各出口旁标注 Y / N 或具体条件名
控制流    → 实线 + 实心箭头，表示流向
连接框    → 小圆圈，用于跨页或跨区域连接（可选）

【禁止事项】
× 起始/结束不能用直角矩形（必须用胶囊圆角形）
× 多条路径汇入同一步骤时，必须用直角折线汇合，
  不能多箭头同时直接指向同一方框
× 菱形出口必须标注条件（Y/N 或具体分支名）

【多条件 case 画法】
→ 用一个菱形，标注"用户操作?"，
  多个出口横向展开，每条出口标分支名（插入/删除/查询……）

【流程内容】

顺序结构：
  开始 → [步骤A] → [步骤B] → 结束

单分支判定：
  [步骤] → ◇[条件?] → Y: [步骤B]
                      → N: [步骤C]
  → 两路汇合（直角折线）→ 结束

嵌套/回路判定：
  [步骤A] → ◇[条件1?] → N → ◇[条件2?] → N → 折线回到[步骤A]
                        Y                   Y
                     [步骤B]             [步骤C]
  → 汇合 → 结束

【整体样式】
- 纯黑白，无任何颜色填充
- 背景：纯白色 #FFFFFF
- 字体：宋体或微软雅黑，字号14px
- 线宽：1px，实线+实心箭头
- 所有转折用直角折线（不用曲线）
- 无阴影、无装饰

## 图表绘制规范总结

### 统一样式指南

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **背景** | 纯白色 #FFFFFF | 所有图表统一背景 |
| **线条** | 1px 黑色 | 所有线条均为细线，无渐变 |
| **字体** | 微软雅黑或宋体 | 中文字体，支持加粗 |
| **字号** | 14-16px（标题）<br/>11-13px（内容） | 根据层级调整 |
| **填充** | 白色 | 节点背景为白色 |
| **边框** | 直角 | 所有节点均为直角，无圆角（流程图除外） |
| **阴影** | 无 | 不使用阴影效果 |
| **颜色** | 黑白 | 纯黑白风格，无彩色 |

### 图表类型特殊规范

| 图表类型 | 特殊要求 |
|---------|---------|
| 功能层次图 | 树形结构，直角折线，父子关系清晰 |
| 类图 | 三格矩形，加粗标题，多种关系线 |
| 用例图 | 椭圆用例，系统边界矩形，关系标注 |
| 活动图 | 圆角活动框，菱形决策，泳道分隔 |
| 时序图 | 生命线虚线，消息水平线，控制焦点窄矩形 |
| E-R 图 | 实体矩形，联系菱形，属性椭圆，无直接连线 |
| 程序流程图 | 胶囊开始/结束，直角处理，菱形判定 |

## 图表使用注意事项

### ✅ 推荐做法
- 图表与文字相互补充，不应重复
- 使用图表说明复杂概念
- 标注关键元素，便于理解
- 在文字中明确引用图表位置

### ❌ 避免问题
- 图表过度复杂，难以理解
- 图表与文字完全重复
- 字体过小，难以阅读
- 颜色混乱，不符合规范

# 论文图表 AI 绘图提示词库

## 概述
本文档包含论文所需的 **8 个主要图表**的详细 AI 绘图提示词。
- **绘图工具**: Gemini 或其他 AI 绘图工具（Canvas 风格）
- **输出格式**: PNG 高分辨率（300 DPI，宽度 ≥ 15cm）
- **风格统一**: 所有图表采用同一配色和线条风格

### 用途

### 内容描述

**顶层架构**：
- **Layer 1 (游戏引擎层)**: Unity Engine + GameFramework
- **Layer 2 (核心系统层)**: 包含以下 5 个主要系统
  - 📊 游戏状态管理系统 (Game State Management)

  - 配置表系统 (Data Table System)

## 图表 2：战斗系统架构细节图

### 用途
论文第三章"战斗系统设计" - 展示战斗系统的内部组件和流程

### 内容描述

**战斗系统的 6 个核心组件**：
1. **战斗管理器** (CombatManager)
   - 职责：初始化战斗、管理战斗状态
   - 输入：场景配置、敌人数据
   - 输出：战斗状态事件

2. **AI 决策系统** (CombatAISystem)
   - 职责：敌人行动决策
   - 包含：行为树、优先级评估
   - 输出：行动指令

3. **技能系统** (SkillSystem)
   - 职责：技能释放、效果计算
   - 包含：技能索引、技能参数
   - 输出：伤害/治疗数据

4. **伤害计算系统** (DamageCalculation)
   - 职责：计算伤害值
   - 包含：11 套伤害公式
   - 输出：最终伤害数据

5. **Buff 系统** (BuffSystem)
   - 职责：Buff 应用与管理
   - 生命周期：应用→持续→移除
   - 输出：属性修改

6. **UI 反馈系统** (CombatUISystem)
   - 职责：显示战斗信息
   - 包含：伤害飘字、状态显示
   - 输出：视觉反馈

### 组件关系
```
CombatManager (中心)
├─ 调用 → CombatAISystem
├─ 调用 → SkillSystem
│  └─ 调用 → DamageCalculation
│  └─ 调用 → BuffSystem
├─ 调用 → BuffSystem
└─ 通知 → CombatUISystem
```

## 图表 3：伤害计算流程图

### 用途
论文第三章"伤害系统设计" - 展示伤害计算的完整流程

### 内容描述

**伤害计算的 11 套公式体系**：

1. **物理伤害** (Physical Damage)
   - 公式：基础伤害 × (1 + 攻击加成) - 防御减免
   - 考虑破甲机制

2. **法术伤害** (Magical Damage)
   - 公式：基础伤害 × (1 + 法伤加成) - 法防减免

3. **真实伤害** (True Damage)
   - 公式：基础伤害 × (1 + 真伤加成)
   - 不受防御影响

4. **治疗量** (Healing)
   - 公式：基础治疗 × (1 + 治疗加成)
   - 受治疗减免影响

5-11. **特殊伤害类型**（护盾伤害、持续伤害等）

### 流程步骤

```
1. 技能触发
    ↓
2. 获取攻击者属性 (攻击力、加成)
    ↓
3. 获取防御者属性 (防御、血量、状态)
    ↓
4. 判断伤害类型（物理/法术/真实等）
    ↓
5. 选择对应公式
    ↓
6. 计算基础伤害
    ↓
7. 应用加成系数
    ↓
8. 应用减免系数
    ↓
9. 应用 Buff 修饰
    ↓
10. 计算最终伤害 (确保 ≥ 0)
    ↓
11. 应用伤害（减血、触发事件）
    ↓
12. 显示反馈（飘字、特效）
```

```
  ↓
```

2. **加载** (Loading)
3. **探索** (Exploration)
4. **战斗准备** (CombatPreparation)

### 状态转换

```
MainMenu
├─ → Loading → Exploration
├─ → Settings

Exploration
├─ → CombatPreparation (遇到敌人)
├─ → Inventory (打开背包)
```

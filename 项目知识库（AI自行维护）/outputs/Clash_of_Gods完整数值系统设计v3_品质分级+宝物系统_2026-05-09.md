## 第一部分：棋子品质分级系统

### 1.1 品质等级定义

基于阴阳师的评级体系，Clash of Gods 采用四个品质等级：

| 品质 | 名称 | 属性点和 | 稀有度 | 获取方式 | 建议上场数 |
|------|------|---------|--------|---------|----------|
| 🔵 | 蓝色 | 2.4 | 普通 | 初始赠送/常规掉落 | 不建议 |
| 🟣 | 紫色 | 2.7 | 稀有 | 普通抽取 | 1-2队 |
| 🟡 | 金色 | 3.0 | 稀有 | 高级抽取 | 主队伍 |
| ✨ | 炫彩 | 3.3+ | 传说 | 史诗抽取/充值 | 核心输出 |

### 1.2 属性标准模型（三维属性点）

**核心原则**：不同品质的棋子，三维属性点总和固定，但因职业定位不同而分配不同

```
蓝色棋子示例（点和 2.4）：
- 输出型后羿：攻击 1.0 + 攻速 0.6 + 生命 0.8 = 2.4
- 防守型嫦娥：生命 1.2 + 防御 0.8 + 法强 0.4 = 2.4
- 法系型恶魂：法强 1.0 + 生命 1.0 + 防御 0.4 = 2.4

紫色棋子示例（点和 2.7）：
- 输出型后羿：攻击 1.1 + 攻速 0.7 + 生命 0.9 = 2.7
- 防守型嫦娥：生命 1.4 + 防御 0.9 + 法强 0.4 = 2.7
- 法系型恶魂：法强 1.2 + 生命 1.1 + 防御 0.4 = 2.7

金色棋子示例（点和 3.0 ← 标准模型）：
- 输出型后羿：攻击 1.2 + 攻速 0.8 + 生命 1.0 = 3.0
- 防守型嫦娥：生命 1.5 + 防御 1.0 + 法强 0.5 = 3.0
- 法系型恶魂：法强 1.3 + 生命 1.2 + 防御 0.5 = 3.0

炫彩棋子示例（点和 3.3+，"超模"）：
- 输出型黑暗杨戬：攻击 1.3 + 攻速 0.9 + 生命 1.1 = 3.3
- 支援型：生命 1.6 + 防御 1.1 + 法强 0.6 = 3.3
```

**优势**：
- ✅ 快速判断新棋子是否平衡
- ✅ 职业特色清晰（输出 > 防守 > 法系 > 混合）
- ✅ 品质差异明确（蓝0.6差 → 紫0.3差 → 金0 → 炫彩+0.3）

## 第二部分：棋子进阶 + 星级系统

### 2.1 现有进阶系统改进

**当前**：一阶 → 二阶 → 三阶（简单）

**改进方案**（对标阴阳师的星级概念）：

```
进阶等级 vs 星级对照：
一阶 = 1-2星  （最初级，属性倍数 1.0x）
二阶 = 3-4星  （进阶，属性倍数 1.6x）
三阶 = 5-6星  （满级，属性倍数 2.4x）

例：后羿升级过程
一阶一星：攻击 1.2 × 1.0 = 1.2
一阶二星：攻击 1.2 × 1.2 = 1.44
二阶三星：攻击 1.2 × 1.6 = 1.92
二阶四星：攻击 1.2 × 1.8 = 2.16
三阶五星：攻击 1.2 × 2.2 = 2.64
三阶六星：攻击 1.2 × 2.4 = 2.88
```

### 2.2 升星所需资源

**改进**（参考阴阳师）：

```
升星资源表：
一阶一星 → 一阶二星：
  成本：100 灵石 + 50 金币
  时间：即时

二阶三星 → 二阶四星：
  成本：200 灵石 + 150 金币
  时间：即时

三阶五星 → 三阶六星（满级）：

```

## 第三部分：宝物系统（= 御魂系统）

### 3.1 宝物系统概述

**宝物是 Clash of Gods 中的"御魂"**，给棋子提供额外属性：

```
宝物的核心机制（对标阴阳师）：
1. 宝物可以装备在棋子身上（1棋子配1宝物）
2. 宝物可升级强化（消耗金币和经验）
3. 宝物有品质和星级（稀有度影响属性上限）
4. 套装效果（如：3件火系宝物，全队攻击+15%）
5. 宝物主属性 + 副属性系统
```

### 3.2 宝物星级与属性

| 宝物星级 | 宝物品质 | 主属性上限 | 副属性条数 | 获取方式 |
|---------|---------|---------|----------|---------|
| ⭐ | 普通 | +200 | 0个 | 普通副本掉落 |
| ⭐⭐ | 精良 | +350 | 1个 | 普通副本掉落 |
| ⭐⭐⭐ | 稀有 | +500 | 2个 | 宝物副本困难 |
| ⭐⭐⭐⭐ | 史诗 | +750 | 3个 | 宝物副本地狱 |
| ⭐⭐⭐⭐⭐ | 传说 | +1000 | 4个 | 宝物副本王者 |

### 3.3 宝物强化机制

**强化成本公式**（参考阴阳师）：

```
ENLS = (1000 + 当前等级×500) × (1 + 0.5×星级)

例：
★★宝物 从Lv1→Lv2：
  成本 = (1000 + 1×500) × (1 + 0.5×2) = 1500 × 2 = 3000金币

★★★宝物 从Lv5→Lv6：
  成本 = (1000 + 5×500) × (1 + 0.5×3) = 3500 × 2.5 = 8750金币

★★★★宝物 从Lv15→Lv16：
  成本 = (1000 + 15×500) × (1 + 0.5×4) = 8500 × 3 = 25500金币
```

**每级宝物属性增长**：

```
主属性增长 = 基础值 × (当前等级 / 15)

例：
★★宝物 主属性为"攻击+350"
  Lv1：350 × 1/15 = 23.3 → 350
  Lv5：350 × 5/15 = 116.7 → 466
  Lv10：350 × 10/15 = 233 → 583
  Lv15：350 × 15/15 = 350 → 700
```

### 3.4 宝物主属性与副属性

**6位置宝物，对标阴阳师的1-6号位**：

```
位置分配（棋子的6个位置）：
位置1：主属性固定为 "攻击"
位置2：主属性随机（特殊属性10%：暴击/暴击伤害/速度）
位置3：主属性固定为 "防御"
位置4：主属性随机（特殊属性10%）
位置5：主属性固定为 "生命"
位置6：主属性随机（特殊属性10%）

副属性掉率（参考阴阳师）：
- 攻击类（36%）：攻击、攻击加成、暴击、暴击伤害
- 防御类（36%）：防御、防御加成、生命、生命加成
- 功能类（28%）：命中、抵抗、速度

副属性强化机制（参考阴阳师）：
1. 宝物掉落时，生成星级、主属性、初始1-2条副属性
2. 强化时，每3个等级（3/6/9/12/15），从候选副属性中随机选一条强化
3. 副属性不足4条时，新增副属性；满4条时，只能强化现有属性
4. 同一条副属性强化多次，会增加下次被选中的权重（类似阴阳师的1/56算法）
```

### 3.5 宝物套装效果

```
套装分类（按元素属性，对标阴阳师的5套效果）：

火系套装（3件套）：
- 3件：全队攻击+15%

冰系套装（3件套）：
- 3件：全队防御+15%

木系套装（3件套）：
- 3件：全队生命+20%

雷系套装（3件套）：
- 3件：全队暴击率+25%

光系套装（3件套）：
- 3件：全队伤害减免+10%

混搭套装（5件套，高难度）：
- 5件不同元素：全队所有属性+10%
```

## 第四部分：装备系统（局内一次性）

### 4.1 装备与宝物的区别

| 对比维度 | 宝物系统 | 装备系统 |
|---------|---------|---------|
| 获取时机 | 关卡外（永久） | 战斗中（局内） |
| 强化升级 | 可升级（金币+时间） | 无法升级（一次性） |
| 持久性 | 永久保留 | 战斗结束消失 |
| 功能 | 养成系统（长期投入） | 战术系统（局内策略） |
| 参考 | 阴阳师御魂 | 金铲铲自来水装备 |

### 4.2 装备掉落与获取

**装备掉落流程**：

```
战斗中的关键战利品：
1. 击败敌人时，有概率掉落装备
2. 装备掉落分为3种品质（白/蓝/金）
3. 立即可装备到任意棋子上

装备品质对属性的影响：
白装：基础属性（如攻击+50）
蓝装：加强属性（如攻击+100）
金装：超强属性（如攻击+200）
```

### 4.3 装备效果类型

```
装备类型示例（类似金铲铲）：

攻击装备：
- 剑（攻击+50）→ 蓝剑（攻击+100）→ 黄金剑（攻击+200）
- 暴击刀（攻击+50, 暴击率+15%）
- 破甲刀（攻击+50, 破甲+5）

防御装备：
- 盾（防御+50）→ 蓝盾（防御+100）→ 黄金盾（防御+200）
- 寒冰甲（防御+50, 减速敌人20%）

功能装备：
- 急速靴（移动速度+20%）
- 护目镜（暴击率+25%）
- 夜刃（攻击+50, 暴击伤害+30%）

特殊装备：
- 龙牙（攻击+75, 每3次普攻额外伤害+100）
- 反甲盔（防御+75, 反伤30%）
- 智慧书（法强+100, 技能冷却-1秒）
```

### 4.4 装备合成机制（局内）

```
战斗中的装备合成规则（金铲铲机制）：

小件 + 小件 → 大件
例：
剑 + 盾 → 剑盾（攻击+50, 防御+50）
剑 + 手套 → 破甲刀（攻击+50, 破甲+5）

大件 + 大件 → 终极装备
例：
剑盾 + 龙牙 → 不死之刃（攻击+125, 防御+50, 反伤15%）
```

## 第五部分：完整数值对标表

### 5.1 棋子品质与战斗力对标

```
FC = HP × DPS 验证（在无宝物、无装备情况下）

蓝色棋子后羿一阶（1.0x）：
FC = 400 × (10 × 0.5) = 2000

紫色棋子后羿一阶：
FC = 500 × (12 × 0.6) = 3600

金色棋子后羿一阶（标准）：
FC = 600 × (14 × 0.7) = 5880

炫彩棋子后羿一阶（超模）：
FC = 700 × (16 × 0.8) = 8960

结论：品质梯度合理 ✓
```

### 5.2 宝物对战斗力的影响

```
计算宝物加成的战斗力提升：

不装宝物：FC = 5880
装备★★★宝物（Lv15）：
  - 攻击+500（来自位置1的主属性）
  - 生命+200（来自副属性）
  新FC = (600+200) × (14+10)×0.7 = 800 × 16.8 = 13440

提升幅度：13440 / 5880 = 2.28倍 ✓（宝物系统激励充分）
```

### 5.3 装备对战斗力的瞬间提升

```
战斗中捡到装备：

仅有基础宝物的棋子：FC = 8000
捡到金装剑（攻击+200）：
  新FC = 800 × (14+10)×0.7 = ... （根据具体宝物和装备计算）

装备可提升战斗力 20-40%，足以改变战局 ✓
```

## 第六部分：系统整合流程

### 6.1 玩家养成路线

```
第一阶段：初入游戏
- 获得蓝色棋子3-4个（基础队伍）
- 完成教学，理解宝物系统
- 获得1-2个普通宝物

第二阶段：日常推图（1-2周）
- 升级蓝色棋子到二阶
- 推图掉落紫色棋子，逐步替换蓝色
- 升级普通宝物到★★

第三阶段：小R期（2-4周）
- 积累抽取，获得金色棋子2-3个
- 升级棋子到三阶满星
- 获得稀有宝物，开始装备搭配

第四阶段：深度养成（4周+）
- 拥有金色队伍（5个金色棋子）
- 宝物升到★★★以上
- 研究套装效果和阵容搭配
- 冲刺竞技排名

第五阶段：大R期（特定玩家）
- 抽取炫彩棋子
- 宝物升到满级★★★★★
- 追求极限配置和阵容创新
```

### 6.2 配置表关联关系

```
涉及修改的配置表（优先级）：

🔴 必修改：
- SummonChessTable：加入品质字段 + 三维属性点 + 星级上限
- ChessAdvanceTable：升星成本 + 属性倍数
- TreasureBoxTable：宝物掉落配置（品质、星级、副属性）

🟠 重要修改：
- BuffTable：宝物套装效果（作为特殊Buff）
- ItemTable：装备配置（品质、效果、合成公式）
- CombatRuleTable：战斗中的装备合成逻辑

🟡 可选修改：
- PlayerDataTable：新增宝物背包容量字段
- ResourceRuleTable：宝物强化的金币消耗比例
```

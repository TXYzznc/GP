## 第二部分：棋子进阶系统（简化版）

### 2.1 三阶制（保持现有）

```
现有机制（不变）：
一阶 ──[升阶1]──> 二阶 ──[升阶2]──> 三阶

属性倍数（线性增长）：
一阶 = 1.0x （基础）
二阶 = 1.6x （增长 60%）
三阶 = 2.4x （增长 140%）
```

### 2.2 升阶所需经验（改进）

**当前问题**：EXP 过低（10/20），击败一个棋子就能升级  
**改进方案**：

```
一阶 → 二阶：85 棋子 EXP
  （击败 3 阶敌方棋子约 1.4 次）
  
二阶 → 三阶：150 棋子 EXP
  （击败 3 阶敌方棋子约 2.5 次）

总计：235 EXP 完成全部进阶
  = 击败约 4 个三阶棋子
  = 保证需要多场战斗（成就感 ✓）
```

## 第三部分：宝物系统（简化版）

### 3.1 宝物概况

```
宝物 = 棋子的永久装备（对标阴阳师的御魂）

核心机制：
- 1 个棋子可装备 2 件宝物
- 宝物可升级强化（金币投入，属性递增）（保留这个设计，但是暂时不做实现）
- 宝物可卸下，装备给其他棋子
- 宝物有初始品质（掉落时决定）
```

### 3.2 宝物品质与等级上限

| 宝物品质 | 主属性上限 | 副属性条数 | 获取方式 | 最高等级 |
|---------|---------|----------|---------|---------|
| ⭐ | +200 | 0个 | 普通副本 | Lv10 |
| ⭐⭐ | +350 | 1个 | 普通副本 | Lv15 |
| ⭐⭐⭐ | +500 | 2个 | 困难副本 | Lv20 |
| ⭐⭐⭐⭐ | +750 | 3个 | 地狱副本 | Lv25 |
| ⭐⭐⭐⭐⭐ | +1000 | 4个 | 王者副本 | Lv30 |

对于获取方式对宝物强度的影响，这部分设计先保留，但是暂时不实现。（宝物强度对属性和副属性条数等的影响可以进行具体设计和实现）

### 3.3 宝物强化成本（参考阴阳师）

**强化需要金币和经验**

这部分也是先做配置表，然后标记一下目前暂不进行实现。
```
公式：强化成本 = (1000 + 当前等级×500) × (1 + 0.5×品质星级)

例：
★★宝物 从 Lv1→Lv2：
  成本 = (1000 + 1×500) × (1 + 0.5×2) = 1500 × 2 = 3000金币

★★★宝物 从 Lv5→Lv6：
  成本 = (1000 + 5×500) × (1 + 0.5×3) = 3500 × 2.5 = 8750金币

★★★★宝物 从 Lv15→Lv16：
  成本 = (1000 + 15×500) × (1 + 0.5×4) = 8500 × 3 = 25500金币
```

### 3.4 宝物主属性

**6 位置设计（对标阴阳师，但简化）**

```
位置 1：主属性 = 攻击（固定）
位置 2：主属性 = 随机（特殊属性 10%：暴击/暴击伤害）
位置 3：主属性 = 防御（固定）
位置 4：主属性 = 随机（特殊属性 10%）
位置 5：主属性 = 生命（固定）
位置 6：主属性 = 随机（特殊属性 10%）

示例：
后羿装备位置 1 的宝物
  主属性："攻击+500"（位置 1 固定为攻击）
  副属性：可能有 1-2 条（如暴击率+10%、速度+5）

  这部分无需这么复杂，不需要位置设计。
```

### 3.5 宝物副属性掉率（参考阴阳师）

```
副属性类型掉率：
- 攻击类（36%）：攻击、攻击加成、暴击、暴击伤害
- 防御类（36%）：防御、防御加成、生命、生命加成
- 功能类（28%）：命中、抵抗、速度

副属性强化机制：
1. 宝物初始掉落时，生成 1-2 条副属性
2. 强化时（每次升级），副属性不足 4 条时，有概率增加新副属性
3. 副属性满 4 条后，只能强化现有属性，不再新增
4. 选中权重递增：同一属性强化次数越多，下次被选中概率越高

副属性这部分我待会会自己再设计一下。
```

## 第四部分：装备系统（战斗中的一次性装备）

### 4.1 装备概况

```
装备 = 战斗中掉落的一次性属性提升
参考：金铲铲自来水装备

关键特性：
- 只能局内掉落（不是关卡奖励）
- 装备后立即生效
- 回到局外消失
- 棋子可装备多件装备（最多3件）
- 可在战斗中合成（暂不实现）
```

### 4.2 装备品质与属性

| 装备品质 | 属性提升 | 掉落概率 | 示例 |
|---------|---------|---------|------|
| 白装 | 基础 | 60% | 攻击+50、防御+40 |
| 蓝装 | 加强 | 30% | 攻击+100、防御+80 |
| 金装 | 超强 | 10% | 攻击+200、防御+150 |

### 4.3 装备类型示例

```
基础装备：
- 剑：攻击+50
- 盾：防御+50
- 靴：移动速度+20%
- 手套：暴击率+15%

特殊装备（带复合效果）：
- 破甲刀：攻击+75, 护甲减少 5
- 寒冰甲：防御+75, 减速敌人 15%
- 急速靴：攻击速度+20%
- 吸血剑：攻击+100, 吸血 20%
```

### 4.4 装备合成（局内）

```
小件 + 小件 = 大件

示例组合：
剑 + 盾 → 剑盾（攻击+50, 防御+50）
剑 + 手套 → 破甲刀（攻击+75, 护甲-5）
盾 + 靴 → 防御靴（防御+50, 移速+10%）

大件合成：
剑盾 + 破甲刀 → 不死之刃（攻击+125, 防御+50, 护甲-5）

这部分需要新加一个合成系统，先设计配置表，后续再设计系统实现。
```

## 第五部分：数值对标与平衡验证

### 5.1 品质间的战斗力差异

```
使用 FC = HP × DPS 验证

后羿一阶对比（无宝物、无装备）：
- 蓝色（2.4 点）：FC = 400 × (10 × 0.5) = 2000
- 紫色（2.7 点）：FC = 480 × (12 × 0.6) = 3456
- 金色（3.0 点）：FC = 560 × (14 × 0.7) = 5488
- 炫彩（3.3 点）：FC = 640 × (16 × 0.8) = 8192

结论：品质差异清晰，金色约为蓝色的 2.74 倍 ✓
```

### 5.2 宝物对战斗力的提升

```
后羿三阶（无宝物）：
FC = 560×2.4 × (14×2.4×0.7) = 1344 × 23.52 = 31,633

装备★★★宝物（Lv20）：
- 攻击+500（主属性）
- 副属性提升等效 +150 攻击
- 新 FC = (560+200)×2.4 × ((14+10)×2.4×0.7) 
        ≈ 1824 × 28.22 ≈ 51,505

提升幅度：51,505 / 31,633 = 1.63 倍 ✓（宝物系统激励充分）
```

### 5.3 装备对战局的即时提升

```
局内探索或者获取奖励时获得金装：
- 金装攻击+200：瞬间提升 20-30% 战力
- 足以改变战局走向 ✓
```

Buff 系统的设计模式与实现

【模式框架：组件模式】

核心思想：每个 Buff 是一个独立的组件，可以动态挂载到需要 Buff 效果的对象上。

架构示意：
```
GameObject (棋子/敌人)
├─ StatComponent（基础属性）
├─ BuffComponent（Buff管理器）
│  ├─ FireBuff（燃烧 Buff 组件）
│  ├─ FreezeBuff（冰冻 Buff 组件）
│  └─ ShieldBuff（护盾 Buff 组件）
└─ CombatComponent（战斗组件）
```

【配置表范例】

BuffTable（Excel 配置表示例）：

| BuffId | BuffName | EffectType | Duration | Damage/Param1 | Interval/Param2 | IconId |
|--------|----------|-----------|----------|---------------|-----------------|--------|
| 001 | 燃烧 | DOT | 3 | 10 | 0.5 | icon_fire |
| 002 | 冰冻 | DEBUFF | 2 | 减速30% | - | icon_ice |
| 003 | 增伤 | BUFF | 5 | +20% | - | icon_buff |
| 004 | 流血 | DOT | 4 | 15 | 1.0 | icon_bleed |

【应用流程】

1. 技能触发 Buff → 调用 `ApplyBuff(targetEntity, buffId=001)`
2. BuffComponent 在 BuffTable 查询配置
3. 根据 EffectType 创建对应的 Buff 实例
4. Buff.OnApply() → 显示特效、应用初始效果
5. 每帧更新 → Buff.OnUpdate() → 判断是否触发周期效果
6. 时间到期 → Buff.OnRemove() → 移除特效、清理状态
7. 返回事件 → UI 显示"Buff 移除"通知

【代码伪码】

```csharp
class BuffComponent {
    List<BaseBuff> activeBuff = new List<BaseBuff>();
    
    public void ApplyBuff(int buffId) {
        BuffData data = BuffTable.Get(buffId);  // 从配置表读取
        BaseBuff buff = BuffFactory.Create(data);
        activeBuff.Add(buff);
        buff.OnApply(this);  // 初始化
        
        // 触发事件，UI 显示 "获得 Buff"
        EventManager.Fire(new BuffAppliedEvent(buffId));
    }
    
    public void Update() {
        for (int i = activeBuff.Count - 1; i >= 0; i--) {
            var buff = activeBuff[i];
            buff.OnUpdate();
            
            if (buff.IsExpired()) {
                buff.OnRemove(this);
                activeBuff.RemoveAt(i);
                EventManager.Fire(new BuffRemovedEvent(buff.BuffId));
            }
        }
    }
}

class FireBuff : BaseBuff {
    public override void OnUpdate() {
        elapsedTime += Time.deltaTime;
        
        // 每隔 Param2（0.5秒）造成一次伤害
        if (elapsedTime >= nextTriggerTime) {
            int damage = (int)Param1;  // 10 点伤害
            owner.TakeDamage(damage);
            nextTriggerTime += Param2;
        }
    }
}
```

【设计优势】

1. 模块化：每个 Buff 独立实现，易于添加新 Buff
2. 可配置：通过表格调整参数，无需改代码
3. 易测试：可单独测试每个 Buff 的效果
4. 易维护：Bug 修复只影响相关 Buff 组件

【其他应用】

类似的组件模式在项目中还被应用于：
- 技能系统（SkillComponent）
- 装备系统（EquipmentComponent）
- 状态系统（StatusComponent）

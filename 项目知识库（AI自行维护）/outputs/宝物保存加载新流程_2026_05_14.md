## 设计变更

原来的问题：背包中有宝物，但 CharacterBagUI 显示为空

**根本原因**：
- 背包物品存储在 InventoryManager（临时）
- CharacterBagUI 只查询 PlayerAccountDataManager.CurrentSaveData.Treasures（持久化）
- 两者没有同步

## 实现细节

### 1. SaveTreasuresFromInventory() 方法

**位置**：`PlayerAccountDataManager.cs`

**功能**：
- 从 InventoryManager 获取所有 Treasure 类型物品
- 转换为 TreasureInstanceData（包含词条信息）
- 保存到 CurrentSaveData.Treasures
- 自动调用 SaveCurrentSave() 持久化

**代码流程**：
```csharp
public void SaveTreasuresFromInventory()
{
    // 1. 获取背包中的宝物
    var treasureItems = inventoryManager.GetAllItems()
        .Where(item => item is TreasureItem);
    
    // 2. 清空旧数据
    m_CurrentSaveData.Treasures.Clear();
    m_CurrentSaveData.ChessTreasureSlots.Clear();
    
    // 3. 转换并保存
    foreach (var treasure in treasureItems)
    {
        var instanceData = ItemManager.CreateTreasureInstanceData(
            treasure, 
            GenerateUniqueInstanceId()
        );
        m_CurrentSaveData.Treasures.Add(instanceData);
    }
    
    // 4. 持久化
    SaveCurrentSave();
}
```

## 工作流程时序

### Phase 1: 局内战斗
```
用户战斗 → 宝物掉落
  ↓
ItemManager.CreateItem(treasureId)
  ↓
返回 TreasureItem（包含生成的词条）
  ↓
添加到 InventoryManager（临时存储）
  ↓
玩家继续战斗...
```

### Phase 2: 结算
```
玩家点击"结算"
  ↓
SettlementUIForm 显示
  ↓
用户阅读获取的物品列表...
  ↓
用户点击"关闭"按钮
  ↓
OnCloseButtonClicked() 执行
  ↓
SaveTreasuresFromInventory() 执行
  ├─ InventoryManager.GetAllItems() → 获取所有宝物
  ├─ CreateTreasureInstanceData() → 转换为持久化格式
  └─ SaveCurrentSave() → 持久化到文件
  ↓
CloseWithAnimation() 关闭UI
```

### Phase 3: 返回基地
```
SettlementUIForm 关闭
  ↓
返回局外状态（OutOfGameState）
  ↓
玩家打开 CharacterBagUI
  ↓
LoadTreasureRepositoryAsync() 执行
  ├─ GetInventoryTreasures() 读取 CurrentSaveData.Treasures
  └─ 显示所有宝物（包括词条信息）✅
```

## 关键设计优势

| 优势 | 说明 |
|------|------|
| **时序清晰** | 局内临时数据和局外持久化数据完全分离 |
| **性能优化** | 只在关键时点（离开局内）保存一次，避免频繁 I/O |
| **数据安全** | 异常退出时宝物不会丢失（上次保存数据还在） |
| **逻辑简单** | 背包和仓库位置不影响存档数据 |
| **易于扩展** | 背包特有功能（容量限制、排序等）独立实现 |

## 宝物从获取到显示的完整流程

```
1. 局内掉落
   ItemManager.CreateItem(treasureId)
   → TreasureItem + 生成词条 (AffixEffect)
   → 添加到 InventoryManager

2. 结算保存
   SaveTreasuresFromInventory()
   → ItemManager.CreateTreasureInstanceData()
   → AffixEffect → AffixData (持久化格式)
   → 保存到 CurrentSaveData.Treasures
   → JsonUtility.ToJson 序列化到文件

3. 存档加载
   LoadSave(saveId)
   → LoadTreasureData() 反序列化 JSON
   → 恢复 CurrentSaveData.Treasures
   → 包含所有 Affixes 数据

4. UI 显示
   CharacterBagUI.LoadTreasureRepositoryAsync()
   → GetInventoryTreasures() / GetWarehouseTreasures()
   → 读取 CurrentSaveData.Treasures
   → 显示宝物 + 词条加成信息
```

## 注意事项

1. **不需要手动调用 ObtainTreasure()**
   - 它用于特殊情况（如任务奖励）
   - 普通掉落通过 SaveTreasuresFromInventory() 自动转换

2. **背包移动不修改存档**
   - 宝物在背包/仓库移动时，只改变 Location 字段
   - 无需额外保存（在退出UI时自动保存）

3. **异常退出保护**
   - 如果游戏中途崩溃，上次成功的宝物数据不会丢失
   - 恢复的是上一次正常结算后的数据

# 宝物装备系统与保存/加载实现

> 最后更新: 2026-05-13  
> 状态: 已完成  
> 版本: 1.0

## 概述

实现了完整的宝物装备系统集成和保存/加载功能：
1. **装备系统**：在战斗准备阶段应用装备宝物的词条效果
2. **保存/加载**：词条数据完整地被序列化和反序列化

## 系统架构

```
宝物掉落/获取
  ↓
ItemManager.CreateItem() 
  → AffixGenerator 生成词条列表
  ↓
PlayerAccountDataManager.ObtainTreasure()
  → CreateTreasureInstanceData() 转换为持久化数据
  → 添加到 CurrentSaveData.Treasures
  ↓
保存存档
  → SaveTreasureData() 序列化（含词条）
  ↓
加载存档
  → LoadTreasureData() 反序列化（恢复词条）
  ↓
战斗准备 (CombatPreparationState)
  → TreasureEquipmentManager.ApplyPlayerEquippedTreasures()
  → 应用词条效果到棋子属性
```

## 新增和修改的文件

### 1. TreasureEquipmentManager.cs (新建)

**位置**：`Assets/AAAGame/Scripts/Game/Item/TreasureEquipmentManager.cs`

**核心方法**：
- `ApplyPlayerEquippedTreasures(ChessAttribute chessAttribute, int chessId)`
  - 获取棋子装备的所有宝物
  - 遍历词条列表，应用每条词条的属性加成
  - 自动处理固定值和百分比类型

**特点**：
- 单例模式
- 自动初始化，无需手动创建
- 对标准属性修改方法的完整映射（11个属性类型）

### 2. CombatPreparationState.cs (修改)

**修改位置**：`InitializeSummonerChessForCombat()` 方法

**新增调用**：
```csharp
// ⭐ 应用装备的宝物效果（词条、基础属性等）
TreasureEquipmentManager.Instance.ApplyPlayerEquippedTreasures(attribute, summonChessId);
```

**时序**：在 `chessEntity.InitializeAsSummoner()` 之后，向战斗追踪系统注册之前

### 3. PlayerAccountDataManager.cs (扩展)

**新增方法**：

#### `ObtainTreasure(TreasureItem treasureItem)`
- **用途**：宝物获取入口（掉落、宝箱、任务奖励等）
- **流程**：
  1. 生成唯一 InstanceId
  2. 调用 `ItemManager.CreateTreasureInstanceData()` 转换数据
  3. 添加到 `CurrentSaveData.Treasures`
- **返回**：`TreasureInstanceData`（包含已生成的词条）

#### `GenerateUniqueInstanceId()`
- **用途**：为宝物实例生成全局唯一ID
- **算法**：时间戳 + 随机数异或

## 工作流程详解

### Phase 1: 宝物生成与获取

```csharp
// 创建运行时宝物（包含词条）
var treasureItem = ItemManager.Instance.CreateItem(treasureId);
// → ItemManager.CreateItem 自动调用 AffixGenerator.Generate()

// 添加到玩家存档（转换为持久化数据）
var instanceData = PlayerAccountDataManager.Instance.ObtainTreasure(treasureItem);
// → 自动调用 ItemManager.CreateTreasureInstanceData()
// → Affixes 字段被 GetAffixDataForPersistence() 填充
```

### Phase 2: 保存存档

```csharp
PlayerAccountDataManager.Instance.SaveCurrentSave();
// → SaveTreasureData(saveData)
//   ├─ 序列化 saveData.Treasures 列表
//   ├─ 每个 TreasureInstanceData 包含 List<AffixData> Affixes
//   └─ 转换为 JSON 存储在 saveData.TreasureData
//
// → JsonUtility.ToJson() 自动处理嵌套的 List<AffixData>
```

**序列化结构**：
```json
{
  "TreasureData": "{\"Items\":[{\"InstanceId\":1001,\"TreasureId\":101,\"Affixes\":[{\"Id\":5,\"Name\":\"暴击率\",\"AttributeType\":4,\"ValueType\":2,\"ValueMax\":16.1}]}]}"
}
```

### Phase 3: 加载存档

```csharp
var saveData = PlayerAccountDataManager.Instance.LoadSave(saveId);
// → LoadTreasureData(saveData)
//   ├─ 反序列化 JSON 字符串
//   └─ 恢复 saveData.Treasures（包括所有 Affixes）
//
// → 生成的 TreasureInstanceData 包含完整的词条信息
```

### Phase 4: 战斗准备应用

```csharp
// 在 CombatPreparationState.InitializeSummonerChessForCombat() 中
var attribute = chessEntity.Attribute; // ChessAttribute 组件
TreasureEquipmentManager.Instance.ApplyPlayerEquippedTreasures(attribute, summonChessId);

// → GetChessEquipments(summonChessId)
//   └─ 获取所有 EquippedChessId == summonChessId 的宝物
//
// → 对每个宝物的每条词条 (AffixData)
//   └─ 使用 ValueMax（已滚出的实际数值）应用属性加成
```

## 关键设计决策

### 1. 词条数据的持久化方案

**设计**：使用 `AffixData.ValueMin = ValueMax = 生成的实际值`

**原理**：
- AffixEffect 是运行时对象（含生成的具体数值）
- GetAffixDataForPersistence() 将其转换为持久化格式
- ValueMin 和 ValueMax 都存储实际值，方便加载时直接使用

**优势**：
- 简单直观，无需额外的值存储字段
- 加载时无需重新计算，直接使用 ValueMax

### 2. InstanceId 生成策略

**方案**：`(timestamp / 100000) % int.MaxValue ^ randomPart`

**优势**：
- 跨游戏会话全局唯一
- 时间戳保证顺序性
- 随机数避免碰撞

### 3. 装备槽系统

**现有机制**：
- `PlayerSaveData.ChessTreasureSlots` - Dictionary<ChessId, List<InstanceId>>
- 每个棋子最多3个装备位
- `TreasureInstanceData.EquippedChessId` - 冗余存储，用于快速查询

**应用流程**：
- `GetChessEquipments(chessId)` - 通过 EquippedChessId 过滤
- `ApplyPlayerEquippedTreasures()` - 对过滤结果应用词条效果

| AttributeType | 枚举值 | 修改方法 | 数值类型 |

| Attack | 1 | ModifyAtkDamage() | 固定值 |
| MaxMP | 2 | ModifyMp() | 固定值 |
| AttackSpeed | 3 | ModifyAtkSpeed() | 固定值 |
| CritRate | 4 | ModifyCritRate() | 百分比 → /100 |
| CritDamage | 5 | ModifyCritDamage() | 百分比 → /100 |
| Defense | 6 | ModifyArmor() | 固定值 |
| MagicResist | 7 | ModifyMagicResist() | 固定值 |
| SpellPower | 8 | ModifySpellPower() | 固定值 |
| MoveSpeed | 9 | ModifyMoveSpeed() | 固定值 |

## 数据流示例

### 示例1：宝物获取与保存

```
1. 掉落出品质为 Rare 的宝物 ID=101
   ↓
2. ItemManager.CreateItem(101)
   ├─ 创建 TreasureItem
   ├─ AffixGenerator.Generate(Rare) → 生成 2-3 条词条
   │  例如：暴击率+16%, 攻击力+63
   └─ 返回带词条的 TreasureItem

3. PlayerAccountDataManager.ObtainTreasure(treasureItem)
   ├─ 生成 InstanceId = 1001
   ├─ ItemManager.CreateTreasureInstanceData(treasureItem, 1001)
   │  └─ GetAffixDataForPersistence() 返回 [
   │     {Id:3, Name:"暴击率", AttributeType:4, ValueMax:16},
   │     {Id:1, Name:"攻击力", AttributeType:1, ValueMax:63}
   │    ]
   └─ 添加到 CurrentSaveData.Treasures

4. SaveCurrentSave()
   └─ SaveTreasureData() 序列化为 JSON
      ↓
   JSON 存储包含 Affixes 字段
```

### 示例2：存档加载与应用

```
1. LoadSave(saveId)
   └─ LoadTreasureData() 反序列化 JSON
      └─ 恢复 Treasures[InstanceId=1001] 的 Affixes 字段

2. CombatPreparationState 初始化召唤师棋子
   └─ TreasureEquipmentManager.ApplyPlayerEquippedTreasures(attr, SummonChessId)
      ├─ GetChessEquipments(SummonChessId) 
      │  └─ 返回 [Treasures[1001], ...]
      ├─ 对每个宝物的 Affixes 迭代
      │  └─ Affixes[0] = {AttributeType:4, ValueMax:16}
      │     → attr.ModifyCritRate(16 / 100.0) = 0.16
      │
      └─ Affixes[1] = {AttributeType:1, ValueMax:63}
         → attr.ModifyAtkDamage(63)

3. 棋子属性已应用所有装备宝物的词条效果
   ✅ 进入战斗
```

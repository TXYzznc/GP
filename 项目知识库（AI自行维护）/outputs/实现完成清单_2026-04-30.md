## 📝 关键设计细节

### 数据读取规则

```csharp
// 使用扩展方法读取等级相关数据
double hp = row.GetMaxHp(rank);  // rank = 1-3
// 内部实现：array[rank - 1]，超出范围用 array[0]
```

### 棋子初始化流程

```csharp
1. 进入局内 → ChessEntity.Initialize() 
   ↓
2. Rank = 1 （初始等级）
   ↓
3. 后续根据 Rank 读取配置表数据
   ↓
4. 击败敌方获得经验 → 可能升级（Rank++）
```

### 等级系统约束

- Rank 范围：1-3
- 每局开始时重置为 1
- 升级通过 ChessEXPManager 触发
- 配置表中数组长度应 ≥ 3（对应三个等级）

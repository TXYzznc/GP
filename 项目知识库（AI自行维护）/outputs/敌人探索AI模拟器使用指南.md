# 敌人探索AI模拟器 - 使用指南

> **参考**：CombatSimulatorPanel  
> **创建时间**：2026-05-08  
> **完全自动化**：无需手动搭建场景  

---

## 快速开始（2分钟）

### Step 1：创建Test场景

在 `Assets/AAAGame/Scenes/` 创建 `ExploreAITestScene.unity`

### Step 2：场景最小配置

```
场景中只需放置一个GameObject：
├─ Bootstrapper (空GameObject)
│  └─ 添加脚本：ExploreAITestBootstrapper
```

**仅此而已！** 不需要：
- ❌ GameFrameworkInitializer
- ❌ Player预制体
- ❌ 敌人预制体  
- ❌ NavMesh烘焙（框架自动处理）

### Step 3：运行测试

1. **在ExploreAITestScene中Play**
2. **Unity菜单** → `战斗工具` → `敌人AI模拟器`
3. 配置玩家ID和敌人列表
4. 点击 **生成** 按钮

---

## 界面说明

### 玩家配置
- **玩家ID**：从 SummonerTable 选择（1001=狂战士、2001=术士等）
- **生成位置**：玩家初始位置（默认 0,0,-3）

### 敌人配置
- **生成范围**：中心位置 + 半径（敌人随机生成在该范围内）
- **敌人列表**：支持添加多个敌人配置
  - 每条配置包含：敌人ID + 数量
  - 敌人ID对应 EnemyEntityTable

**示例**：
```
敌人1：ID=1, 数量=1    (一个敌人)
敌人2：ID=2, 数量=3    (三个敌人)
敌人3：ID=4, 数量=2    (两个敌人)
```

### 生成和清除

- **生成**：创建玩家和所有配置的敌人
- **清除**：销毁已生成的所有对象（可重复生成）

### AI监控

实时显示每个敌人的状态：
```
[敌人名称] 状态:Chase | 警觉:0.85 | 距离:5.2m
```

## 运行时操作

Play后在Game窗口：
- 玩家不能自动移动
- 查看Console输出敌人AI状态变化

在Scene窗口观察Gizmo：
- 🟢 绿色圆：圆形视野范围
- 🔴 红色线：扇形视野方向
- 🔵 蓝色圆：玩家位置
- 🟡 黄线：警觉度可视化

## 与框架的区别

| 特性 | 旧方案 | 新方案 |
|-----|-------|--------|
| 框架初始化 | 手动放GameFrameworkInitializer | 自动（Bootstrapper） |
| 玩家创建 | 手动搭建Prefab | 自动生成 |
| 敌人创建 | 手动搭建 + SetEntityConfigId | 自动生成 |
| NavMesh烘焙 | 手动烘焙 | 自动加载 |
| 场景搭建 | 5+ 个GameObject | 1 个 Bootstrapper |
| 配置修改 | 需要Stop重新Play | 可直接在面板改参数 |

## 调试技巧

### 查看敌人视野范围

1. Scene窗口右上角：确保Gizmo打开
2. 运行时会自动显示：
   - 敌人位置（橙色圆）

## FAQ

**Q: 生成后玩家看不到敌人？**

A: 敌人在随机范围内生成（可能被遮挡或太远）。调整：
- 减小 `范围半径`（如改为3）
- 调整 `生成范围中心` 的Z值

**Q: Console没有输出？**

A: 确认：
1. Console窗口打开（Window → General → Console）
2. 敌人是否成功生成（面板中显示敌人数量）
3. DataTable是否加载完成（环境状态显示OK）

**Q: 提示敌人ID不存在？**

A: 检查 EnemyEntityTable.txt 中是否有该ID的敌人配置

# 敌人生成模块架构分析

> **最后更新**: 2026-04-30  
> **涵盖范围**: 敌人生成的完整流程、模块架构、数据流向

---

## 核心模块概览

敌人生成系统由**3个核心模块**组成，协作流程如下：

```
EnemySpawnManager（敌人生成管理器）
    ├─ 从 EnemyTable 加载配置（EnemyTableId）
    ├─ 根据 MinPopulation/MaxPopulation 随机敌人数量
    ├─ 生成敌人波次配置（EnemyWaveConfig）
    └─ 批量生成敌人
        │
        ├─ 调用 EnemyFormationManager.CalculateFormation()
        │   └─ 根据阵型类型计算站位
        │
        ├─ 为每个敌人调用 SummonChessManager.SpawnChessAsync()
        │   ├─ 加载棋子预制体
        │   ├─ 实例化至战场
        │   ├─ 初始化棋子属性
        │   └─ 返回 ChessEntity
        │
        └─ 通过 EnemyChessDataManager 恢复历史 HP
            └─ 注册 enemy key 到 BattleChessManager
```

## 模块详解

### 1. EnemySpawnManager（敌人生成管理器）

**路径**: `Assets/AAAGame/Scripts/Game/Combat/Enemy/EnemySpawnManager.cs`  
**职责**: 敌人波次的配置加载、生成管理、生命周期清理

#### 关键字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `m_CurrentWave` | `EnemyWaveConfig` | 当前波次配置（包含棋子ID列表、阵型、间距） |
| `m_SpawnedEnemies` | `List<ChessEntity>` | 已生成的敌人实例列表 |
| `m_CurrentEnemyGuid` | `string` | 当前战斗敌人实体GUID（用于恢复历史HP） |
| `ENEMY_CAMP` | `const int = 1` | 敌人阵营ID |

#### 核心流程

##### 1️⃣ 加载配置

```csharp
// 从 EnemyTable 加载配置
public void LoadFromEnemyTable(int enemyTableId, string enemyGuid = null)
{
    // 1. 读取 EnemyTable 数据
    var enemyData = dataTable.GetDataRow(enemyTableId);
    
    // 2. 根据 MinPopulation/MaxPopulation 随机敌人数量
    int targetCount = Random.Range(minPopulation, maxPopulation + 1);
    
    // 3. 从 ChessIds 中随机选择敌人（可重复）
    List<int> randomizedChessIds = new List<int>();
    for (int i = 0; i < targetCount; i++)
    {
        int randomIndex = Random.Range(0, enemyData.ChessIds.Length);
        randomizedChessIds.Add(enemyData.ChessIds[randomIndex]);
    }
    
    // 4. 创建波次配置
    m_CurrentWave = new EnemyWaveConfig { ... };
}
```

**关键点**:
- 敌人数量在 `[MinPopulation, MaxPopulation]` 范围内随机
- 敌人类型从 `ChessIds` 数组中完全随机选择（支持重复）
- 保存 `enemyGuid` 用于后续恢复HP

##### 2️⃣ 生成敌人波次

```csharp
// 根据配置生成所有敌人
public async UniTask SpawnWaveAsync()
{
    // 1. 获取敌方区域中心点
    Vector3 enemyZoneCenter = BattleArenaManager.Instance.GetEnemyZoneCenter();
    
    // 2. 计算站位
    List<Vector3> positions = EnemyFormationManager.CalculateFormation(
        enemyZoneCenter,
        m_CurrentWave.EnemyChessIds.Count,
        m_CurrentWave.FormationType,
        m_CurrentWave.Spacing
    );
    
    // 3. 逐个生成敌人
    for (int i = 0; i < m_CurrentWave.EnemyChessIds.Count; i++)
    {
        int chessId = m_CurrentWave.EnemyChessIds[i];
        Vector3 position = positions[i];
        
        // 生成敌人
        var entity = await SpawnEnemyAsync(chessId, position);
        if (entity != null)
        {
            m_SpawnedEnemies.Add(entity);
            
            // 恢复历史HP并注册到BattleChessManager
            ApplyHistoricalHp(entity, chessId, i);
        }
    }
}
```

**关键点**:
- 使用 `async UniTask` 并行加载多个敌人
- 调用 `EnemyFormationManager.CalculateFormation()` 计算阵型
- 为每个敌人调用 `SummonChessManager.SpawnChessAsync()`

##### 3️⃣ 生成单个敌人

```csharp
public async UniTask<ChessEntity> SpawnEnemyAsync(int chessId, Vector3 position)
{
    // 通过 SummonChessManager 生成棋子
    var entity = await SummonChessManager.Instance.SpawnChessAsync(
        chessId, 
        position, 
        ENEMY_CAMP  // 阵营 = 1
    );
    return entity;
}
```

##### 4️⃣ 恢复历史HP

```csharp
private void ApplyHistoricalHp(ChessEntity entity, int chessId, int slotIndex)
{
    // 生成 enemy key
    string enemyKey = EnemyChessDataManager.BuildKey(m_CurrentEnemyGuid, slotIndex);
    
    // 注册到 BattleChessManager（战斗中查询敌人数据）
    BattleChessManager.Instance.SetEnemyKeyForChess(chessId, enemyKey);
    
    // 从 EnemyChessDataManager 读取历史HP
    var state = EnemyChessDataManager.Instance.GetState(enemyKey);
    if (state != null)
    {
        entity.Attribute.SetHp(state.CurrentHp);
    }
}
```

**关键点**:
- **Enemy Key 格式**: `{EnemyGuid}_{SlotIndex}` 唯一标识一个敌人实例
- **历史HP恢复**: 如果敌人在前一回合被击伤，本回合继承其当时的HP
- **注册BattleChessManager**: 战斗中需要通过 enemy key 快速查询敌人数据

#### 公共方法

| 方法 | 说明 |
|------|------|
| `LoadFromEnemyTable(int, string)` | 从EnemyTable加载波次配置 |
| `SetEnemyData(List<int>, int, float)` | 手动设置敌人数据 |
| `SpawnWaveAsync()` | 异步生成敌人波次 |
| `SpawnEnemyAsync(int, Vector3)` | 生成单个敌人 |
| `DestroyAllEnemies()` | 销毁所有敌人 |
| `GetSpawnedEnemies()` | 获取已生成的敌人列表 |
| `GetAliveEnemyCount()` | 获取存活的敌人数量 |
| `Cleanup()` | 战斗结束时清理数据 |

### 2. EnemyFormationManager（敌人阵型管理器）

**路径**: `Assets/AAAGame/Scripts/Game/Combat/Enemy/EnemyFormationManager.cs`  
**职责**: 根据敌人数量和阵型类型计算站位

#### 阵型类型

| 常量 | 值 | 描述 |
|------|-----|------|
| `FORMATION_HORIZONTAL` | 1 | 横排（一字排开） |
| `FORMATION_VERTICAL` | 2 | 竖排（纵向排列） |
| `FORMATION_RECTANGLE` | 3 | 矩形（尽量接近正方形） |

#### 站位计算

```csharp
public static List<Vector3> CalculateFormation(
    Vector3 centerPosition,  // 敌方区域中心点
    int enemyCount,          // 敌人数量
    int formationType,       // 阵型类型
    float spacing)           // 间距（米）
{
    // 根据阵型类型调用不同的计算方法
    return formationType switch {
        FORMATION_HORIZONTAL => CalculateHorizontalFormation(...),
        FORMATION_VERTICAL => CalculateVerticalFormation(...),
        FORMATION_RECTANGLE => CalculateRectangleFormation(...),
        _ => CalculateHorizontalFormation(...) // 默认横排
    };
}
```

##### 横排阵型

```
中心点为 (0, 0, 0)，5个敌人，间距=2

Enemy1  Enemy2  Enemy3  Enemy4  Enemy5
 -4      -2       0       2       4

总宽度 = (count - 1) * spacing = 4 * 2 = 8
起始X = centerX - 8/2 = -4
```

##### 矩形阵型

```
5个敌人，最接近正方形：

cols = ceil(sqrt(5)) = 3
rows = ceil(5/3) = 2

Layout:
Enemy1  Enemy2  Enemy3
Enemy4  Enemy5
```

#### 关键点

- **中心对齐**: 所有阵型都基于中心点计算，敌人均匀分布在中心两侧
- **Y轴固定**: 所有敌人高度相同（与中心点Y坐标一致）
- **间距计算**: 敌人之间的距离由 `spacing` 参数控制
- **矩形阵型优化**: 自动计算最接近正方形的行列数，避免过长过窄

### 3. SummonChessManager（棋子管理器）

**路径**: `Assets/AAAGame/Scripts/Game/SummonChess/Manager/SummonChessManager.cs`  
**职责**: 棋子的生成、销毁、生命周期管理

#### 生成流程

```csharp
public async UniTask<ChessEntity> SpawnChessAsync(int chessId, Vector3 position, int camp)
{
    // 1. 获取棋子配置
    if (!ChessDataManager.Instance.TryGetConfig(chessId, out var config))
        return null;
    
    // 2. 加载预制体
    int prefabId = config.GetPrefabId(1);  // Rank 1
    GameObject prefab = await LoadPrefabAsync(prefabId);
    if (prefab == null)
        return null;
    
    // 3. 实例化
    GameObject chessObj = Instantiate(prefab, position, Quaternion.identity);
    chessObj.name = $"Chess_{config.Name}_{m_NextInstanceId}";
    
    // 4. 对齐到地面
    float bottomOffset = EntityPositionHelper.CalculateBottomOffset(chessObj);
    chessObj.transform.position = new Vector3(
        position.x,
        position.y + bottomOffset,
        position.z
    );
    
    // 5. 初始化棋子实体
    var entity = chessObj.GetComponent<ChessEntity>();
    // 初始化各项系统...
    
    return entity;
}
```

#### 关键点

- **预制体加载**: 使用Rank 1的预制体（由 `config.GetPrefabId(1)` 返回）
- **地面对齐**: 通过 `EntityPositionHelper.CalculateBottomOffset()` 计算底部偏移，防止浮空
- **阵营参数**: 敌人传入 `camp = 1`，友方传入 `camp = 0`
- **异步加载**: 使用 `async UniTask` 异步加载资源，避免帧率卡顿

## 数据流向

### 敌人表配置

```
EnemyTable（敌人配置表）
    ├─ Id: 敌人配置ID
    ├─ EnemyName: 敌人名称
    ├─ ChessIds: 可用棋子ID数组 [101, 102, 103]
    ├─ MinPopulation: 最少敌人数 (e.g., 1)
    ├─ MaxPopulation: 最多敌人数 (e.g., 5)
    ├─ FormationType: 阵型类型 (1=横排, 2=竖排, 3=矩形)
    ├─ Spacing: 敌人间距 (e.g., 2.0)
    └─ ...
```

### 敌人HP数据持久化

```
探索场景
    ↓ 进入战斗前保存敌人状态
EnemyChessDataManager（内存缓存）
    ├─ Key: "{EnemyGuid}_{SlotIndex}"
    └─ Value: { CurrentHp, MaxHp, ... }
        ↓
战斗进行中
    ├─ 敌人受伤
    └─ 状态更新到 EnemyChessDataManager
        ↓
战斗结束/逃跑
    ├─ 状态保存到本地存档
    └─ 下次进入战斗时恢复
```

## 常见问题

**Q: 如何修改敌人数量？**  
A: 通过 EnemyTable 的 `MinPopulation` 和 `MaxPopulation` 字段，或直接调用 `SetEnemyData()` 手动指定。

**Q: 如何改变敌人阵型？**  
A: 在调用 `LoadFromEnemyTable()` 或 `SetEnemyData()` 时指定 `formationType` 参数。

**Q: 敌人HP如何恢复？**  
A: 通过 `EnemyChessDataManager` 保存敌人状态，战斗时通过 enemy key 恢复历史HP。

**Q: 如何添加新的阵型？**  
A: 在 `EnemyFormationManager` 中添加新的 `CalculateXxxFormation()` 方法，并在 `CalculateFormation()` 的 switch 中处理。

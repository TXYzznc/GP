## 核心发现：网易数值理论

### 1. 战斗力守恒定律

**最关键的数学模型**：

```
战斗力 (FC) = 承受 × 输出
或：FC = HP × DPS（单位伤害/秒）

任何战斗中，双方战斗力之差恒定不变
```

**应用到 Clash of Gods**：

```
棋子战斗力 = MaxHP × AttackDPS
           = MaxHP × (AtkDamage × AtkSpeed)

玩家方总战斗力 = Σ(棋子1到5的FC)
敌方总战斗力 = Σ(敌人1到N的FC)

战斗结果 = 玩家FC - 敌方FC（差值不变）
```

### 2. 属性标准模型（来自阴阳师）

阴阳师的核心设计：**所有式神的三维属性点总和固定为 3**

```
例：书翁 = 攻击1.0 + 生命1.0 + 防御1.0 = 3.0
   SP玉藻前 = 攻击1.3 + 生命1.3 + 防御0.69 = 3.29 (超模)
```

**推荐为 Clash of Gods 实施**：

```
棋子标准属性模型 = 3.0 点数
分配方式：
- 输出型（后羿）：攻击1.2 + 攻速0.8 + 生命1.0 = 3.0
- 防守型（嫦娥）：生命1.5 + 防御1.0 + 法强0.5 = 3.0
- 法系型（恶魂）：法强1.2 + 生命1.0 + 防御0.8 = 3.0
- 混合型（黑暗杨戬）：攻击1.0 + 生命1.2 + 防御0.8 = 3.0

特殊情况（超模）：
- Boss棋子允许 3.5-4.0 点（如黑暗杨戬可为3.5）
```

**优势**：
- ✅ 确保不同品质棋子总体平衡
- ✅ 便于快速评估新棋子是否超强
- ✅ 清晰的职业定位边界

## 第一部分：战斗力系统重设（基于FC守恒）

### 1.1 棋子基础属性规范化

**当前问题分析**（使用 FC 公式验证）：

```
后羿一阶：FC = 400 × (10 × 0.5) = 2000
嫦娥一阶：FC = 30 × (8 × 1.0) = 240 ← 严重不平衡！

建议修复：
后羿一阶：FC = 400 × (10 × 0.5) = 2000
嫦娥一阶：FC = 300 × (8 × 1.0) = 2400 ← 接近平衡
```

### 1.2 三阶系数标准化（线性增长）

**网易理论**：属性应该按**线性倍数**增长，不是指数

```
推荐方案（线性）：
一阶 = 1.0x （基础）
二阶 = 1.6x （增长 60%）
三阶 = 2.4x （增长 140%）

验证：
后羿一阶：400HP → 640HP（二阶）→ 960HP（三阶）
嫦娥一阶：300HP → 480HP（二阶）→ 720HP（三阶）

FC 验证：
后羿：2000 → 5120 → 11520 ✓ （线性增长）
嫦娥：2400 → 6144 → 11520 ✓ （线性增长）
```

## 第二部分：防御与减伤系统（基于网易公式）

### 2.1 防御减伤公式

**选用：乘法递减模式**（参考魔兽世界）

```
伤害减伤率 = Armor / (Armor + K值)

推荐 K 值范围：250-300
目标：Armor = K值 时，减伤率 = 50%

例：K=250
- 0护甲   → 0% 减伤    → 100% 伤害通过
- 250护甲 → 50% 减伤   → 50% 伤害通过
- 500护甲 → 66% 减伤   → 34% 伤害通过
- 750护甲 → 75% 减伤   → 25% 伤害通过
```

**优势**：
- ✅ 防御收益递减（防御力越高效果越弱）
- ✅ 永远无法完全免伤（上限 75-80%）
- ✅ 参数简单清晰

### 2.2 破甲机制

```
目标防御 = max(0, 原防御 - 破甲值)

破甲应用在减伤前：
实际减伤率 = 目标防御 / (目标防御 + 250)
```

## 第三部分：经验与成长系统

### 3.1 棋子升阶经验（重要调整）

**当前问题**：升阶 EXP 过低（10/20），击败一个三阶棋子就能升级

**改进方案**（参考阴阳师的三次函数原理）：

```
升阶所需 EXP：
1升2: 80 EXP  （击败3阶棋子1.33次）
2升3: 150 EXP （击败3阶棋子2.5次）
总计: 230 EXP （需要多场战斗，有成就感）

推导公式：
升阶EXP(n) = 50 + 30n + 5n² 
1升2: 50 + 30 + 5 = 85 ✓
2升3: 50 + 60 + 20 = 130 ✓（调整到 150 为好）
```

### 3.2 玩家经验曲线

**改进：使用二次函数设计**

```
基础公式：RequiredExp(Lv) = Base + (Lv-1) × Coefficient × Lv

参考数值：
Lv1:   100
Lv10:  2000
Lv20:  8000
Lv30:  20000
Lv40:  40000
Lv60:  120000

特性：
- 前期快速升级（爽快感）
- 中期逐步加速（保持挑战）
- 后期大幅增长（避免无限刷怪）
```

## 第四部分：Buff 系统规范化

### 4.1 属性修改 Buff（参考阴阳师）

**标准范围**：

```
普通Buff（消耗少）：
- 攻击力：+15-25%  持续：6-8s  堆叠：1层
- 防御：+10-15%    持续：8-10s 堆叠：1层
- 移速：+15%       持续：8s    堆叠：1层

强化Buff（消耗中）：
- 攻击力：+30-40%  持续：10-15s 堆叠：1层
- 防御：+20-30%    持续：12-15s 堆叠：1层
- 法强：+20-30%    持续：10s    堆叠：1层

终极Buff（消耗大）：
- 攻击力：+60-80%  持续：永久(0)  堆叠：1层
- 防御：+40-50%    持续：永久(0)  堆叠：1层
- 法强：+50%       持续：永久(0)  堆叠：1层
```

### 4.2 周期伤害 Buff

```
标准公式：
单次伤害 = (基础伤害值 + 伤害系数×攻击力) × (1-目标减伤率)
总伤害 = 单次伤害 × (持续时间 / 触发间隔)

灼烧：固定5点/次  间隔1s  持续10s  = 50点总伤害  堆叠10层
流血：1%MaxHP/次  间隔0.5s 持续4s   = 8%总HP伤害 堆叠1层
```

## 第五部分：难度与奖励系统

### 5.1 难度系数重设（参考 Lanchesters 定律）

**问题**：当前难度 1-4 跨度太小（0.4→1.0 线性）

**改进**：指数增长

```
难度   敌难系数  敌人数(min-max)  奖励倍率  说明
1      0.4x     2-2              1.0x    学习
2      0.7x     1-3              1.15x   容易
3      1.2x     2-3              1.3x    普通
4      2.0x     2-4              1.5x    困难
5      3.5x     3-5              2.0x    噩梦
6      6.0x     3-6              2.5x    地狱

验证（Lanchesters）：
难度1 vs 难度5：
敌军方0.4×(5-5)² = 0
玩家方 vs 敌军：战斗力平方差 = 玩家方平方 - 0
玩家可战胜 sqrt(玩家FC²) ≈ 玩家FC / 难度系数
```

### 5.2 奖励计算

```
奖励数量 = floor(基础(1-2) × 奖励倍率)

例：
难度1：1-2 × 1.0 = 1-2个物品
难度3：1-2 × 1.3 = 1-2个物品（偶尔3个）
难度5：1-2 × 2.0 = 2-4个物品
```

## 第六部分：卡牌系统平衡

### 6.1 灵力消耗与伤害对应

**建立消耗-收益模型**：

```
灵力效率 = (平均伤害 + 控制价值) / 灵力消耗

标准：
普通卡（25灵力）：伤害50+控制20 = 70价值  效率2.8
稀有卡（40灵力）：伤害80+控制40 = 120价值 效率3.0
史诗卡（60灵力）：伤害150+控制50 = 200价值 效率3.33

检查不平衡：
护甲破碎：消耗45，伤害50，破甲价值30 = 80价值 效率1.78 ← 太弱
雷霆一击：消耗60，伤害200，真伤价值80 = 280价值 效率4.67 ← 太强
```

**调整建议**：
- 护甲破碎改为：消耗35，伤害60，破甲30 = 90价值 效率2.57
- 雷霆一击改为：消耗70，伤害200，真伤60 = 260价值 效率3.71

## 关键公式速查

### 战斗力公式
```
FC = HP × DPS = MaxHP × (AtkDamage × AtkSpeed)

多单位战斗（Lanchesters平方定律）：
FC(多) = n² × (单位输出 × 单位承受) / 2
```

### 防御减伤
```
伤害减伤率 = Armor / (Armor + 250)
最终伤害 = 基础伤害 × (1 - 减伤率) × 暴击倍数
```

### 经验成长
```
RequiredExp(Lv) = Base + (Lv-1) × Coefficient × (Lv-1)
```

### 属性标准模型
```
攻击型：Atk1.2 + Speed0.8 + HP1.0 = 3.0
防守型：HP1.5 + Def1.0 + Speed0.5 = 3.0
法系型：MagicPower1.2 + HP1.0 + Def0.8 = 3.0
```

## 常见问题 FAQ

**Q: 为什么使用战斗力守恒定律？**  
A: 这是网易等大厂验证的**最核心的数值平衡理论**，避免了复杂的多参数平衡问题。

**Q: 属性标准模型 3.0 是否太严格？**  
A: 可以允许 ±0.2 波动。超强角色允许 3.3-3.5（"超模"）。

**Q: 棋子升阶 EXP 85/150 会不会太多？**  
A: 对标产业标准。阴阳师式神升级也需要多场战斗才能完成。

**Q: 何时运用这个方案？**

# 棋子等级绑定架构修复方案

**架构设计**: 棋子实例等级绑定 + 配置表等级数据数组化

---

## 架构变更总结

### 1. 棋子实体数据生命周期
- ✅ 每次进入局内（战斗/探索）时初始化，**初始等级 = 1**
- ✅ 在一整局游戏中保持这个棋子数据（等级可能升级）
- ✅ 离开局内（返回基地/主菜单）时销毁
- ✅ ChessEntity 需要添加 **Rank** 属性（范围 1-3）

### 2. 配置表数据结构

#### SummonChessTable
**等级相关字段（数组）**：
- `PrefabId[]` - 棋子预制体（按等级）
- `IconId[]` - UI 图标（按等级）
- `MaxHp[]` - 最大生命值
- `MaxMp[]` - 最大法力值
- `InitialMp[]` - 初始法力值
- `AtkDamage[]` - 攻击力
- `AtkSpeed[]` - 攻击速度
- `AtkRange[]` - 攻击距离
- `Armor[]` - 护甲
- `MagicResist[]` - 魔抗
- `CritRate[]` - 暴击率
- `CritDamage[]` - 暴击伤害
- `SpellPower[]` - 法术强度
- `PassiveIds[]` - 被动技能
- `NormalAtkId[]` - 普攻技能
- `Skill1Id[]` - 技能1
- `Skill2Id[]` - 技能2
- `Description[]` - 描述文本

**非等级字段（标量）**：
- `Id` - 棋子ID
- `Name` - 名称
- `Quality` - 品质
- `PopCost` - 人口消耗
- `Races[]` - 种族（不受等级影响）
- `Classes[]` - 职业（不受等级影响）
- `MoveSpeed` - 移动速度
- `Shield` - 护盾值
- `CooldownReduce` - 冷却缩减

**移除字段**：
- ~~`StarLevel`~~ （不再需要）
- ~~`NextStarId`~~ （不再需要）
- ~~`AIType`~~ （如果有的话）

#### ChessAdvanceTable
**字段**（长度为 2）：
- `RequiredEXP[2]` - 升级所需经验（[1→2, 2→3]）
- `ConditionEventId[2]` - 升级条件事件（[1→2, 2→3]）
- `AdvanceEffectId` - 升级特效

### 3. 数据读取规则

```
GetValue(array[], rank) {
    if (rank <= 0 || rank > array.length) return array[0]
    return array[rank - 1]
}

示例：
- Rank=1 → array[0]
- Rank=2 → array[1]
- Rank=3 → array[2]
```

```csharp
/// <summary>
/// 根据等级读取配置表数据
/// rank: 1-3（超出范围使用默认值 rank[0]）
/// </summary>
public static class SummonChessTableHelper
{
    public static T GetByRank<T>(T[] array, int rank) where T : struct
    {
        if (array == null || array.Length == 0) 
            return default;
        
        if (rank <= 0 || rank > array.Length)
            return array[0];
        
        return array[rank - 1];
    }
    
    public static int GetPrefabId(this DRSummonChessTable row, int rank)
        => GetByRank(row.PrefabId, rank);
    
    public static int GetIconId(this DRSummonChessTable row, int rank)
        => GetByRank(row.IconId, rank);
    
    // ... 其他等级相关字段的扩展方法
}
```

#### 3.5 SummonChessStateUI.cs 修改
**位置**: L293-317

```csharp
private void UpdateEXPDisplay()
{
    if (m_Owner == null) return;
    
    if (varChessName != null)
    {
        string chessName = m_Owner.Config?.Name ?? string.Empty;
        if (m_Owner.Rank > 0 && m_Owner.Rank < RankNames.Length)
            varChessName.text = $"{chessName}·{RankNames[m_Owner.Rank]}阶";
        else
            varChessName.text = chessName;
    }
    
    int currentEXP = m_EXPComp?.CurrentEXP ?? 0;
    
    // 获取升到下一级所需的经验值
    int requiredEXP = 0;
    var dt = GF.DataTable.GetDataTable<ChessAdvanceTable>();
    var dr = dt?.GetDataRow(m_Owner.ChessId);
    if (dr != null && m_Owner.Rank > 0 && m_Owner.Rank < 3)
    {
        int rankIndex = m_Owner.Rank - 1;
        if (rankIndex >= 0 && rankIndex < dr.RequiredEXP.Length)
            requiredEXP = dr.RequiredEXP[rankIndex];
    }
    
    if (varChessEXP != null)
        varChessEXP.fillAmount = requiredEXP > 0 ? Mathf.Clamp01((float)currentEXP / requiredEXP) : 1f;
    
    if (varChessEXPText != null)
        varChessEXPText.text = requiredEXP > 0 ? $"{currentEXP}/{requiredEXP}" : $"{currentEXP}/--";
}
```

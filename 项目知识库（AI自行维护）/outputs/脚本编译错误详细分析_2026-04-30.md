## 问题详细分析

### 问题 1: 数据表字段读取错误（26 条）

**文件**: CombatManager.cs、ChessDataManager.cs、DictionaryManager.cs、EnemyEntity.cs

**错误现象**:
```
Cannot implicitly convert type 'double[]' to 'double'
Cannot implicitly convert type 'int[]' to 'int'
```

**根本原因**:
数据表 `SummonChessTable` 中的以下字段被定义为数组，但代码中作为标量使用：
- `MaxHp: double[]` → 应为 `double`
- `MaxMp: double[]` → 应为 `double`
- `InitialMp: double[]` → 应为 `double`
- `AtkDamage: double[]` → 应为 `double`
- `AtkSpeed: double[]` → 应为 `double`
- `AtkRange: double[]` → 应为 `double`
- `Armor: double[]` → 应为 `double`
- `MagicResist: double[]` → 应为 `double`
- `CritRate: double[]` → 应为 `double`
- `CritDamage: double[]` → 应为 `double`
- `SpellPower: double[]` → 应为 `double`
- `PrefabId: int[]` → 应为 `int`
- `IconId: int[]` → 应为 `int`
- `NormalAtkId: int[]` → 应为 `int`
- `Skill1Id: int[]` → 应为 `int`
- `Skill2Id: int[]` → 应为 `int`
- `StarLevel: int[]` → 应为 `int`

**错误位置**:
- ChessDataManager.cs: L89-115（初始化 SummonChessConfig）
- CombatManager.cs: L101-111（创建召唤师配置）
- DictionaryManager.cs: L364-365（读取棋子数据）
- EnemyEntity.cs: L349（敌方实体初始化）

**解决方案**:
1. ✅ **数据表本身正确**，问题在脚本中错误地声明了数组
2. 需要检查 `SummonChessTable.cs`（自动生成文件）中这些字段的类型定义
3. 要么修改数据表（如果这些字段真的应该是数组），要么修改脚本

> **关键问题**: 这些字段到底应该是数组还是标量？
> - 如果棋子每个阶级有不同的属性（1阶、2阶、3阶），则应该是数组
> - 如果棋子只有一个属性值，则应该是标量
> - 从当前数据看，Excel 中是逗号分隔的数据（如 `400,580,800`），这意味着**确实是数组**

## 根本原因总结

### A. 数据表字段定义不一致（26 条错误）

**问题**: 数据表字段被定义为数组，但在代码中作为标量使用

**三种可能性**:
1. **数据表正确，代码错误** → 应该接收数组，不应该作为标量赋值
2. **数据表错误，代码正确** → 这些字段在 Excel 中定义错了
3. **设计有误** → 需要重新理解棋子属性系统

**建议**: 用户确认这些字段（如 MaxHp）在棋子系统中的含义

---

3. 与 GlobalChessState.Level 的关系？

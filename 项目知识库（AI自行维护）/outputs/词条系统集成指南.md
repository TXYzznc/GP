# 词条系统集成指南

## 概述

词条系统已经完整实现并集成到宝物系统中。宝物在生成时会根据品质等级随机生成词条，词条会对棋子属性产生加成效果。

## 系统组成

### 1. 配置表

| 表名 | 位置 | 说明 |
|------|------|------|
| AffixRuleTable | `Assets/AAAGame/DataTable/AffixRuleTable.txt` | 品质到词条规则的映射（词条数量、数值范围） |
| AffixTable | `Assets/AAAGame/DataTable/AffixTable.txt` | 词条模板库（冷却缩减已改为百分比 5%-40%） |

### 2. 核心类

| 类 | 位置 | 功能 |
|----|------|------|
| AffixGenerator | Scripts/Game/Item/Effect/AffixGenerator.cs | 静态词条生成器 |
| AffixEffect | Scripts/Game/Item/Effect/AffixEffect.cs | 运行时词条实例 |
| AffixData | Scripts/Game/Item/Data/AffixData.cs | 词条配置/持久化数据 |
| TreasureItem | Scripts/Game/Item/Core/TreasureItem.cs | 宝物类（包含词条逻辑） |
| TreasureInstanceData | Scripts/DataModel/PlayerAccountData.cs | 宝物实例持久化数据 |

## 工作流程

### 宝物生成流程

```
ItemManager.CreateItem(treasureItemId)
  ↓
创建 TreasureItem 实例
  ↓
根据 ItemRarity 调用 AffixGenerator.Generate(rarity)
  ↓
生成 List<AffixEffect> 并设置到 TreasureItem
  ↓
返回带有词条的 TreasureItem
```

### 宝物持久化流程

```
宝物掉落 / 获取
  ↓
ItemManager.CreateTreasureInstanceData(treasureItem, instanceId)
  ↓
转换 List<AffixEffect> → List<AffixData>
  ↓
保存到 PlayerSaveData.Treasures
  ↓
存档到本地文件
```

### 属性应用流程

```
宝物装备到棋子
  ↓
调用 TreasureItem.ApplyAffixesToChess(chessAttribute)
  ↓
遍历词条，根据 AttributeType 调用对应的 Modify 方法
  ↓
棋子属性增加
```

## 数值设计

### 品质规则表

| 品质 | 词条数范围 | 数值缩放范围 | 说明 |
|------|-----------|-----------|------|
| Common(1) | 0-1 | 0%-25% | 最多0-1条，属性较弱 |
| Uncommon(2) | 1-2 | 15%-45% | 1-2条，属性中等 |
| Rare(3) | 2-3 | 35%-65% | 2-3条，属性较强 |
| Epic(4) | 2-4 | 55%-85% | 2-4条，属性很强 |
| Legendary(5) | 3-5 | 75%-100% | 3-5条，属性最强 |

### 示例：Common 品质的暴击率词条

- AffixTable: 暴击率 (8% ~ 20%)
- Legendary 品质缩放: 75% ~ 100%
- 实际范围: 8% + (20%-8%) × 0.75~1.0 = **17%~20%**

## 常见操作示例

### 1. 创建并保存宝物实例

```csharp
// 创建运行时宝物
var treasure = ItemManager.Instance.CreateItem(treasureItemId);

if (treasure is TreasureItem treasureItem)
{
    // 生成唯一实例 ID（可用时间戳 + 随机数）
    int instanceId = GenerateUniqueInstanceId();
    
    // 转换为持久化数据
    var instanceData = ItemManager.Instance.CreateTreasureInstanceData(treasureItem, instanceId);
    
    // 保存到玩家存档
    PlayerAccountDataManager.Instance.AddTreasure(instanceData);
}
```

### 2. 显示宝物词条信息

```csharp
// 在 UI 中显示词条加成
var treasure = ItemManager.Instance.CreateItem(treasureItemId);

if (treasure is TreasureItem treasureItem)
{
    var affixBonuses = treasureItem.GetAffixBonusStrings();
    
    foreach (var bonus in affixBonuses)
    {
        // 显示: "攻击力+63", "暴击率+16.1%", 等
        Debug.Log(bonus);
    }
}
```

### 3. 装备宝物到棋子

```csharp
// 获取宝物实例
var treasureData = playerSaveData.Treasures[instanceId];

// 找到对应的棋子属性
var chessEntity = FindChessByChessId(chessId);
if (chessEntity != null && chessEntity.Attribute != null)
{
    // 创建临时 TreasureItem 来应用属性（或保留引用）
    var treasure = ItemManager.Instance.CreateItem(treasureData.TreasureId);
    if (treasure is TreasureItem treasureItem)
    {
        // 恢复词条效果（从 TreasureInstanceData 还原）
        treasureItem.SetAffixes(ConvertAffixDataToAffixEffect(treasureData.Affixes));
        
        // 应用属性
        treasureItem.ApplyAffixesToChess(chessEntity.Attribute);
    }
}
```

## 注意事项

1. **数据转换**：`AffixEffect`（运行时）和 `AffixData`（持久化）的转换需要正确处理
2. **百分比处理**：百分比词条应用时需要除以100（如 16% → 0.16）
3. **属性范围**：`CritRate` 和 `CooldownReduce` 是 0~1 范围，其他属性无限制
4. **权重机制**：词条选择使用加权随机，允许重复选中同一词条

## 性能优化建议

- 词条生成是一次性的（在宝物创建时），不会频繁调用
- 属性应用时遍历词条列表，通常只有 0-5 条词条，性能开销很小
- 可以缓存 `AffixRuleTable` 和 `AffixTable` 来避免重复查询

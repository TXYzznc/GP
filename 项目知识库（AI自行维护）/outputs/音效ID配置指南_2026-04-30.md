## 最佳实践

### 1. 音效命名规范
- BGM: `BGM_[SceneName]` 或 `BGM_[Type][Level]`
- SFX: `SFX_[Category]_[Effect]` 或 `SFX_[Action]`

### 2. 音量设置
- **BGM**: 0.7-0.8（不要太大声，给 SFX 空间）
- **UI SFX**: 0.9-1.0（清晰反馈）
- **战斗 SFX**: 0.8-1.0（逐个音效调整）
- **环境音**: 0.4-0.6（底层）

### 3. 优先级设置
- **BGM**: 128（中等）
- **战斗 SFX**: 64（高优先级）
- **UI SFX**: 64
- **环境音**: 192（低优先级）

### 4. 资源路径
- 相对于 `Assets/AAAGame/Resources/Audio/` 开始
- 示例: `Audio/BGM/MainMenu` → `Assets/AAAGame/Resources/Audio/Audio/BGM/MainMenu.mp3`
- **建议**: 简化路径为 `BGM/MainMenu`

### 5. 3D 音效
- 需要定位的音效设置 `Is3D=1`
- 设置合理的 `MaxDistance`（通常 100-300）
- 例如脚步声、环境音

## 常见问题

### Q: 如何新增音效？
**A**: 
1. 在 `AudioClipIds.cs` 中定义常量
2. 在配置表中新增一行
3. 执行 DataTableGenerator 生成
4. 在代码中使用常量调用

### Q: 视频如何处理？
**A**: 
1. 放入 `Assets/AAAGame/Resources/Audio/` 目录
2. 在配置表中指定路径
3. 使用 AudioManager API 播放

### Q: 如何调试音效？
**A**: 
使用 AudioClipIds 常量 + Console 日志查看是否播放成功

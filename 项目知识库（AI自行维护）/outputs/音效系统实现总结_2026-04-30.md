## 🎯 核心特性

### 1. BGM 系统 ✅
- **淡入淡出**: 0.5-2s 可配置
- **队列管理**: 支持连续播放多个 BGM
- **平滑切换**: 自动淡出→停止→加载→淡入
- **暂停恢复**: 方便菜单场景处理

### 2. SFX 系统 ✅
- **对象池**: 自动创建和复用 AudioSource
- **即时播放**: 延迟 < 50ms
- **延迟播放**: 支持指定延迟（同步动作和音效）
- **3D 定位**: 支持空间音效（可选）
- **音量缩放**: 灵活控制单个音效音量

### 3. 音量管理 ✅
- **4 轨独立**: BGM/SFX/环境音/语音
- **主音量控制**: 全局音量倍数
- **持久化**: 自动保存和恢复
- **平滑过渡**: 音量变化无突变

### 4. 资源管理 ✅
- **配置表驱动**: 零硬编码
- **BGM 流式加载**: 节省内存
- **SFX 预缓存**: 避免延迟
- **Tag 索引**: 快速分类查询
- **智能卸载**: 手动或自动释放

### 5. 系统集成 ✅
- **GF.Event 集成**: 事件驱动
- **Procedure 支持**: 自动切换 BGM
- **UI 扩展**: 快速为按钮添加音效
- **错误处理**: 完善的异常捕获和日志

## 🔧 API 参考

### AudioManager 主要 API

```csharp
// BGM
AudioManager.Instance.PlayBGM(audioId, fadeInTime);
AudioManager.Instance.StopBGM(fadeOutTime);
AudioManager.Instance.PauseBGM();
AudioManager.Instance.ResumeBGM();

// SFX
AudioManager.Instance.PlaySFX(audioId, volumeScale);
AudioManager.Instance.PlaySFX3D(audioId, worldPos, volumeScale);
AudioManager.Instance.PlaySFXDelayed(audioId, delay, volumeScale);
AudioManager.Instance.StopSFX(audioId);
AudioManager.Instance.StopAllSFX();

// 音量
AudioManager.Instance.SetMasterVolume(volume);
AudioManager.Instance.SetTrackVolume(trackType, volume);
AudioManager.Instance.GetTrackVolume(trackType);
AudioManager.Instance.SetMute(isMuted);

// 资源
AudioManager.Instance.PreloadAudioClip(audioId);
AudioManager.Instance.UnloadAudioClip(audioId);
AudioManager.Instance.UnloadAllAudioClips();
```

### UI 扩展 API

```csharp
// 为按钮添加音效
button.AddAudioClick(audioId);

// 为滑块添加音效
slider.AddAudioSlider(audioId);

// 为开关添加音效
toggle.AddAudioToggle(audioId);
```

## 💡 设计亮点

### 1. 高度解耦
- AudioManager 完全独立
- 各模块职责清晰
- 易于扩展（如后续加入语音系统）

### 2. 性能优化
- **对象池**: 避免频繁创建销毁
- **流式加载**: BGM 不占用内存
- **预缓存**: SFX 延迟 < 50ms

### 3. 易用性
- **常量定义**: 代码提示和类型安全
- **扩展方法**: 一行代码给按钮添加音效
- **自动持久化**: 音量设置无需手动保存

### 4. 可维护性
- **日志完善**: DebugEx 记录所有关键操作
- **配置驱动**: 修改参数无需改代码
- **事件驱动**: 松耦合的系统集成

## ⚠️ 注意事项

### 编译阶段
- 所有代码使用 `AAAGame.Audio` 命名空间
- 依赖 GF 框架的 Event 和 DataTable 系统
- 需要 UnityEngine 和 GameFramework 引用

### 运行阶段
- AudioManager 需要在 DontDestroyOnLoad 中
- 配置表必须在 AudioManager 初始化前加载
- 所有音效必须在 Resources/Audio 目录下

### 配置表
- ResourcePath 必须相对于 Assets/AAAGame/Resources/Audio/
- ID 必须在定义的范围内
- 音频文件格式支持 MP3、WAV、OGG、AIFF

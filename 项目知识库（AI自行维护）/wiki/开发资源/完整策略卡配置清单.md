## 六、卡牌功能详细说明

### 功能维度分析

#### 伤害维度
```
输出卡（12张）→ 伤害提升 20%-50%
应用目标：快速击杀敌人
风险：防守不足
```

#### 防守维度
```
防守卡（10张）→ 防御提升 20%-40% 或免伤
应用目标：延长存活时间
风险：伤害不足
```

#### 效用维度
```
支援卡（8张）→ 属性增强 10%-30%
应用目标：辅助输出或防守
风险：效果有限
```

#### 控制维度
```
控制卡（6张）→ 状态异常或禁用
应用目标：限制敌人行动
风险：对某些敌人无效
```

## 九、使用配置表结构

```csharp
StrategyCardTable
├─ ID (int) - 卡牌ID
├─ Name (string) - 卡牌名称
├─ Description (string) - 效果描述
├─ Cost (int) - 使用成本 (1-10)
├─ Rarity (int) - 稀有度 (1-5)
├─ Category (int) - 分类 (1=输出, 2=防守, 3=支援, 4=控制)
├─ EffectType (int) - 效果类型
├─ EffectValue (float) - 效果数值
├─ Duration (int) - 持续回合数
└─ IconPath (string) - 图标路径
```

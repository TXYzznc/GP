## 问题详细分析与修复方案

### 问题 1️⃣: SummonChessTable 字段类型定义错误（26 条 CS0029 错误）

**严重性**: 🔴 **关键** - 会导致项目无法编译

**根本原因**:  
数据表 `SummonChessTable.xlsx` 中将以下属性错误地定义为数组类型，但代码期望的是标量值。

**错误字段清单**:

| 字段名 | 当前类型 | 应改为 | 说明 | 错误位置 |
|--------|---------|--------|------|---------|
| `MaxHp` | `double[]` | `double` | 单个棋子的最大生命值 | ChessDataManager.cs:89-115 |
| `MaxMp` | `double[]` | `double` | 单个棋子的最大法力值 | ChessDataManager.cs:89-115 |
| `InitialMp` | `double[]` | `double` | 初始法力值 | ChessDataManager.cs:89-115 |
| `AtkDamage` | `double[]` | `double` | 攻击力 | ChessDataManager.cs:89-115 |
| `AtkSpeed` | `double[]` | `double` | 攻击速度 | ChessDataManager.cs:89-115 |
| `AtkRange` | `double[]` | `double` | 攻击距离 | ChessDataManager.cs:89-115 |
| `Armor` | `double[]` | `double` | 护甲 | ChessDataManager.cs:89-115 |
| `MagicResist` | `double[]` | `double` | 魔抗 | ChessDataManager.cs:89-115 |
| `CritRate` | `double[]` | `double` | 暴击率 | ChessDataManager.cs:89-115 |
| `CritDamage` | `double[]` | `double` | 暴击伤害倍率 | ChessDataManager.cs:89-115 |
| `SpellPower` | `double[]` | `double` | 法术强度 | ChessDataManager.cs:89-115 |
| `PrefabId` | `int[]` | `int` | 预制体 ID | ChessDataManager.cs:89-115 |
| `IconId` | `int[]` | `int` | 图标 ID | ChessDataManager.cs:89-115 |
| `NormalAtkId` | `int[]` | `int` | 普攻技能 ID | ChessDataManager.cs:89-115 |
| `Skill1Id` | `int[]` | `int` | 技能 1 ID | ChessDataManager.cs:89-115 |
| `Skill2Id` | `int[]` | `int` | 技能 2 ID | ChessDataManager.cs:89-115 |
| `StarLevel` | `int[]` | `int` | 星级 | ChessDataManager.cs:89-115 |
| `NextStarId` | ❌ 不存在 | ❌ 移除 | 不在 Excel 表中，代码中不应引用 | ChessDataManager.cs:93 |

**应保持为数组的字段**:
- ✅ `PassiveIds` - 一个棋子可有多个被动技能
- ✅ `Races` - 一个棋子可有多个种族标签（羁绊）
- ✅ `Classes` - 一个棋子可有多个职业标签（羁绊）

**修复步骤**:

```
第 1 步: 打开 AAAGameData/DataTables/SummonChessTable.xlsx
第 2 步: 查看第 3 行（字段类型行），逐个修改：
        - double[] → double (MaxHp, MaxMp, InitialMp, AtkDamage, AtkSpeed, AtkRange, Armor, MagicResist, CritRate, CritDamage, SpellPower)
        - int[] → int (PrefabId, IconId, NormalAtkId, Skill1Id, Skill2Id, StarLevel)
        - 删除 NextStarId 列（如果存在）
第 3 步: 保存 Excel 文件
第 4 步: 在 Unity Editor 中执行:
        GameFramework → DataTable → Generate
第 5 步: 确认生成的 SummonChessTable.cs 中字段类型正确
```

**验证**: 修复后，ChessDataManager、CombatManager、DictionaryManager、EnemyEntity 中涉及这些字段的赋值应不再报错。

### 问题 2️⃣: ChessEntity 缺少 Rank 属性（9 条 CS1061 错误）

**严重性**: 🔴 **关键** - 会导致经验系统无法工作

**错误信息**:
```
'ChessEntity' does not contain a definition for 'Rank'
```

**错误位置**:

| 文件 | 行号 | 代码示例 | 影响 |
|------|------|---------|------|
| SummonChessStateUI.cs | 293 | `if (m_Owner.Rank > 0)` | 棋子状态 UI 显示 |
| SummonChessStateUI.cs | 294 | `varChessName.text = $"{chessName}·{RankNames[m_Owner.Rank]}阶"` | 棋子名称显示 |
| SummonChessStateUI.cs | 305 | `if (m_Owner.Rank > 0)` | 经验条显示 |
| SummonChessStateUI.cs | 307 | 经验条相关逻辑 | - |
| ChessEXPManager.cs | 30 | `int expReward = GetEXPReward(deadChess.Rank)` | 击杀奖励计算 |
| ChessEXPManager.cs | 39 | `ChessEntity.Rank` 相关操作 | 经验获取 |

**根本原因分析**:

需要确认 Rank 的含义和来源：
1. **Rank 是什么?** 棋子的阶级/等级？与 StarLevel 的关系？
2. **应如何存储?** 在 ChessEntity 中? 还是从其他组件获取?
3. **初始化时机?** 何时为棋子设置 Rank 值?

**可能的修复方案**:

**方案 A: 添加 Rank 属性到 ChessEntity**（推荐）
```csharp
public class ChessEntity : Entity
{
    public int Rank { get; private set; }
    
    public void Initialize(SummonChessConfig config, ...)
    {
        // ... 其他初始化代码
        Rank = config.StarLevel;  // 或其他来源
    }
}
```

**方案 B: 从 GlobalChessState 或 Config 中获取**
```csharp
// 在使用处改为:
int rank = chess.Config.StarLevel;  // 如果 Rank = StarLevel
// 或
int rank = GlobalChessState.GetState(chess.ChessId).Rank;
```

**修复步骤**:

```
第 1 步: 确认 Rank 的含义
        - 检查 ChessEXPManager.GetEXPReward() 方法的参数
        - 检查 SummonChessStateUI 中 RankNames 数组的长度
        - 确认 Rank 与 StarLevel 的关系

第 2 步: 选择修复方案
        推荐方案 A: 在 ChessEntity 中添加 Rank 属性

第 3 步: 修改 ChessEntity.cs
        - 添加: public int Rank { get; private set; }
        - 在 Initialize() 方法中设置值

第 4 步: 修改 ChessEXPManager.cs 和 SummonChessStateUI.cs
        - 确认所有 deadChess.Rank、m_Owner.Rank 的使用都正确

第 5 步: 重新编译检查
```

**验证**: 修复后，SummonChessStateUI 和 ChessEXPManager 中的 Rank 访问应不再报错。

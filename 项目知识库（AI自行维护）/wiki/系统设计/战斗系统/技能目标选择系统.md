## 一、问题诊断

### 症状表现

敌人棋子（邪灵）表现出奇怪的行为：
1. AI 锁定目标是**召唤师棋子**（朝其移动）
2. 但释放大招时，法阵生成在**嫦娥棋子**位置
3. 到达召唤师附近后，开始攻击时又切换目标回到**嫦娥棋子**
4. 然后再次朝嫦娥棋子移动

**从测试日志对比**：
```
[14:39:32.561] [Log] [FSMMeleeAI] 邪灵 找到目标: 召唤师-狂战士
[14:39:32.561] [Log] [FSMMeleeAI] 邪灵 决策: 使用技能
[14:39:32.577] [Log] [ChessCombatController] 邪灵 释放大招

[14:39:32.917] [Log] [EvilSpiritUltimate] 腐蚀法阵已生成: center=(16.51, 19.48, -3.57), radius=4
  └─ 这是嫦娥的位置！不是召唤师的位置 ❌
```

### 根本原因

#### 问题代码

**文件**：`Assets/AAAGame/Scripts/Game/SummonChess/Chess/邪灵/EvilSpiritUltimate.cs`  
**行数**：第56行

```csharp
// ❌ 错误做法：重新查找最近的敌人，不使用 AI 的锁定目标
ChessEntity targetEnemy = FindNearestEnemy(caster);
```

#### 问题过程

```
时间轴：
├─ T1: AI 索敌（距离权重为0.3）
│  └─ 召唤师 17m 远 → 得分 25.20
│  └─ 嫦娥 8m 远  → 得分 18.00
│  └─ 选择目标：召唤师 ✓
│
├─ T2: AI 决策使用大招
│  └─ 记录 m_CurrentTarget = 召唤师
│
├─ T3: 释放大招，EvilSpiritUltimate.ExecuteSkill()
│  └─ 调用 FindNearestEnemy() 重新查找
│     ├─ 此时 AI 已经朝召唤师移动了几帧
│     ├─ 距离变化：
│     │  ├─ AI 位置 ≈ (14.0, 20.0, -15.0)
│     │  ├─ 召唤师  ≈ (7.7, 20.6, -11.9)  → 距离 ≈ 7-8m
│     │  ├─ 嫦娥    ≈ (16.5, 19.5, -3.6)  → 距离 ≈ 13-14m
│     │  └─ 最近的是嫦娥（因为移动后相对位置变化）
│  └─ ❌ 选择了嫦娥作为技能目标
│
└─ T4: AI 从 UsingSkill 返回
   └─ m_CurrentTarget 仍是召唤师
   └─ 但法阵已经生成在嫦娥位置了
   └─ 造成视觉上的混乱
```

#### 为什么会出现这种情况

1. **距离评分不同**
   - AI 索敌使用加权评分：距离权重 0.3 + 血量权重 0.5 + 威胁度权重 0.2
   - FindNearestEnemy() 仅按直线距离排序

2. **时序问题**
   - 决策时 AI 在地图上游，敌人分布较散
   - 释放时 AI 已经移动了数米，相对距离改变

3. **缺乏一致性**
   - 技能不应该重新评估目标
   - 应该使用 AI 已经决定的目标

#### 修改 2：技能使用 AI 的目标

**文件**：`Assets/AAAGame/Scripts/Game/SummonChess/Chess/邪灵/EvilSpiritUltimate.cs`

修改 `CreateMagicCircleAsync()` 方法：

```csharp
// ⭐ 使用 AI 已锁定的目标，而非重新查找
// 这样能确保技能和移动目标保持一致
var aiBase = caster.CombatController?.AI as ChessAIBase;
```

### 2.2 完整系统设计

#### 2.2.1 区分两个目标概念

**普攻目标 vs 技能目标**

```csharp
public class ChessAIBase : IChessAI
{
    /// <summary>当前普攻目标（在 Idle 状态确定）</summary>
    protected ChessEntity m_CurrentTarget;

    /// <summary>当前技能目标（由技能释放策略确定）</summary>
    protected ChessEntity m_SkillTarget;

    public ChessEntity CurrentTarget => m_CurrentTarget;  // 普攻目标
    public ChessEntity SkillTarget => m_SkillTarget;      // 技能目标
}
```

**为什么需要两个目标**：
- 普攻目标：AI 决策"我要和谁打"
- 技能目标：AI 决策"我这个技能要作用在谁身上"
- 例如：回血技能目标是最低血量的友方，不是敌人

#### 2.2.2 扩展 ISkillReleaseStrategy

**新增方法**：

```csharp
public interface ISkillReleaseStrategy
{
    // ... 现有方法 ...
    
    /// <summary>
    /// 为技能选择目标
    /// </summary>
    /// <param name="skillIndex">技能索引（1或2）</param>
    /// <returns>
    /// - ChessEntity：锁定的目标棋子
    /// - null：不需要锁定目标（自我技能、全体技能、位置策略）
    /// </returns>
    ChessEntity SelectSkillTarget(int skillIndex);
}
```

**职责**：
- 技能1和大招可以有不同的目标选择策略
- 允许返回 null（技能自己处理位置选择）
- 由各棋子的专用策略类实现

#### 2.2.3 扩展 ChessTargetFinder 工具类

**新增工具方法**：

```csharp
/// <summary>综合状态最好的敌人</summary>
/// 综合状态 = (当前HP / 最大HP) + (当前MP / 最大MP)
/// 应用场景：后羿大招锁定综合状态最好的敌人
public static ChessEntity FindBestStateEnemy(ChessEntity self);

/// <summary>敌人最密集的位置</summary>
/// 计算所有敌人的质心（XZ平面）
/// 应用场景：嫦娥大招、邪灵大招选择范围内最密集的位置
public static Vector3 FindMostDensePosition(ChessEntity self, float searchRadius);

/// <summary>方向向量</summary>
/// 计算从 self 指向 target 的单位方向向量
/// 应用场景：恶魂大招确定冲击方向
public static Vector3 GetDirectionToTarget(ChessEntity self, ChessEntity target);
```

#### 2.2.4 改进 ChessAIBase 的决策逻辑

**Idle 状态选择技能目标**：

```csharp
protected virtual void TickIdle(float dt)
{
    // ... 搜索普攻目标 ...
    
    if (m_CurrentTarget != null)
    {
        if (ShouldUseSkill())
        {
            // ⭐ 让技能释放策略选择技能目标
            m_SkillTarget = m_SkillStrategy.SelectSkillTarget(m_PendingSkillIndex);
            
            DebugEx.Log(GetType().Name,
                $"决策: 使用技能{m_PendingSkillIndex}, 目标={m_SkillTarget?.Config?.Name ?? "null"}");
            ChangeState(ChessAIState.UsingSkill);
            return;
        }
    }
}
```

**Moving 中检查技能条件**：

```csharp
protected override void TickMoving(float dt)
{
    // ... 目标有效性检查 ...
    
    // ⭐ 在 Moving 中检查技能条件（满足则立即回到 Idle）
    if (CanMakeSkillDecision() && ShouldUseSkill())
    {
        ChangeState(ChessAIState.Idle);
        return;
    }
}
```

**UsingSkill 状态使用技能目标**：

```csharp
protected virtual void TickUsingSkill(float dt)
{
    // ⭐ 检查技能目标死亡（未开始释放时中断）
    if (m_SkillTarget != null && m_SkillTarget.Attribute.IsDead)
    {
        if (!m_IsUsingSkill)
        {
            ChangeState(ChessAIState.Idle);
            return;
        }
    }
    
    if (!m_IsUsingSkill)
    {
        // ⭐ 使用技能目标检查范围
        if (m_SkillTarget != null && !IsSkillInRange(m_PendingSkillIndex, m_SkillTarget))
        {
            ChangeState(ChessAIState.Moving);
            return;
        }
        
        // 面向技能目标或普攻目标
        FaceTarget(m_SkillTarget ?? m_CurrentTarget);
        
        // 触发技能释放
        if (m_PendingSkillIndex == 2)
            m_Context.Entity.CombatController?.TriggerSkill2FromAI();
        else if (m_PendingSkillIndex == 1)
            m_Context.Entity.CombatController?.TriggerSkill1FromAI();
        
        m_IsUsingSkill = true;
    }
}
```

**状态退出清理**：

```csharp
protected virtual void OnExitState(ChessAIState state)
{
    switch (state)
    {
        case ChessAIState.UsingSkill:
            m_IsUsingSkill = false;
            m_ShouldUseSkillAfterAttack = false;
            m_PendingSkillIndex = 0;
            m_SkillTarget = null;  // ⭐ 清除技能目标
            break;
    }
}
```

## 六、性能考虑

### 目标查找成本

- **快速修复**：O(1) 直接读取 AI 的 CurrentTarget
- **完整系统**：O(n) 遍历所有敌人找最密集位置（仅在决策时执行，不是每帧）

### 优化建议

- 目标选择仅在进入 Idle 状态时执行
- 技能目标缓存到 m_SkillTarget，整个技能释放过程中不变
- Moving 中不重复计算目标

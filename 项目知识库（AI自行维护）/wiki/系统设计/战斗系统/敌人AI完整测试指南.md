## 方案 1️⃣: 基础测试环境（手动搭建）

### 快速启动（5 分钟）

#### Step 1: 创建测试场景

在 `Assets/AAAGame/Scenes/` 创建新场景 `ExploreAITestScene.unity`

#### Step 2: 场景搭建

添加以下对象到场景：

```
场景层级：
├─ SceneEnvironment
│  ├─ Plane (地面，Scale 10×1×10，Material 设为简单灰色)
│  └─ Lighting (Directional Light)
├─ GameFrameworkInitializer (初始化GF框架)
├─ PlayerObject (Player)
│  ├─ 添加 CharacterController (Height: 2, Radius: 0.5)
│  ├─ 设置 Tag = "Player"
│  └─ 添加简单Capsule视觉表示（蓝色材质）
├─ TestManager (空GameObject)
│  └─ 添加脚本 ExploreAITestController
│      └─ Inspector 配置:
│         - Player Object: [拖拽PlayerObject]
│         - Enemy Entity Config ID: [1001]
│         - Enemy Spawn Position: [5, 0, 0]
│         - Show Vision Gizmo: ☑️
└─ Main Camera (Position: 0,2,-5 / Rotation: 20,0,0)
```

#### Step 3: 烘焙 NavMesh（关键步骤）

```
Unity菜单: Window → AI → Navigation
1. 选择地面 Plane GameObject
2. 在Inspector中勾选 "Walkable"
3. 点击 "Bake" 按钮
4. 确认绿色覆盖整个地面
```

#### Step 4: 运行和控制

```
1. Click Play
2. 在 Inspector 中点击 "生成敌人" 按钮
3. 使用按键控制：
   - W/A/S/D: 移动玩家
   - Q/E: 旋转玩家视角
   - 观察 Console 输出和 Scene 中的 Gizmo
```

### 运行时观察

#### Console 输出示例

```
✓ 敌人生成成功: 普通敌人
敌人信息 - 类型:Normal | 状态:Idle

[普通敌人] 状态:Patrol | 警觉:0.00 | 距离:5.0m
[普通敌人] 状态:Patrol | 警觉:0.15 | 距离:4.5m
[普通敌人] 状态:Alert | 警觉:0.35 | 距离:4.2m
[普通敌人] 状态:Chase | 警觉:1.00 | 距离:3.5m
```

#### Gizmo 可视化（Scene 窗口）

- 🟠 **橙色圆**: 敌人位置
- 🟢 **绿色圆**: 圆形检测范围（VisionCircleRadius，默认 8m）
- 🔴 **红色线**: 扇形视野方向（VisionConeDistance，默认 12m）
- 🟡 **黄线**: 警觉度可视化（上方黄线高度表示警觉度 0-1）
- 🔵 **蓝色圆**: 玩家位置
- 🔷 **青色线**: 敌人到玩家连线

### 配置参数说明

#### 视野相关参数（EnemyEntityTable）

| 字段 | 默认值 | 说明 | 用途 |
|-----|-------|------|------|
| `VisionCircleRadius` | 8.0 | 圆形检测范围（米） | 初始警觉检测距离 |
| `VisionConeAngle` | 60.0 | 扇形视野角度（度） | 加速检测的视野范围 |
| `VisionConeDistance` | 12.0 | 扇形检测范围（米） | 正前方加速检测距离 |
| `AlertIncreaseRate` | 0.5 | 警觉增长速率（/秒） | 基础警觉增长速度 |
| `AlertDecreaseRate` | 0.2 | 警觉衰减速率（/秒） | 失去目标后警觉下降速度 |
| `AlertThreshold` | 1.0 | 警觉阈值（0-1） | 进入追击状态的阈值 |
| `ChaseDistance` | 15.0 | 追击最大距离（米） | 超出此距离自动放弃追击 |

## 方案 2️⃣: 编辑器工具测试（推荐快速验证）

### 快速启动（3 分钟）

#### Step 1: 使用编辑器菜单

```
Unity菜单栏 → Test → AI → 快速启动AI测试场景
```

系统会自动加载 `AITestScene.unity`（第一次需要手动创建）

#### Step 2: 打开测试控制面板

```
Unity菜单栏 → Test → AI → 打开AI测试控制面板
```

出现编辑器窗口，显示以下区域：


```
1. 配置敌人ID（如1001）
2. 点击 [生成敌人]
3. WASD 移动玩家靠近敌人
4. 观察 Console 和 Scene 中的 Gizmo
```

### 运行时操作

| 按键 | 功能 |
|-----|------|
| **W** | 向前移动 |
| **A/D** | 左右移动 |
| **S** | 向后移动 |
| **Q** | 左转 |
| **E** | 右转 |

### AI 状态说明

```
Idle           - 休息状态
Patrol         - 巡逻状态
Alert          - 警戒状态（玩家在视野范围内）
Chase          - 追击状态（警觉度达到阈值）
AlertedByBroadcast - 被其他敌人警告
Rest           - 深度休息（不易被惊醒）
```

## 方案 3️⃣: AI 模拟器（完整自动化）

### 快速启动（2 分钟）

#### Step 1: 创建最小测试场景

在 `Assets/AAAGame/Scenes/` 创建 `ExploreAITestScene.unity`

**仅需放置一个 GameObject**：

```
Bootstrapper (空GameObject)
└─ 添加脚本：ExploreAITestBootstrapper
```

**不需要**:
- ❌ GameFrameworkInitializer
- ❌ Player 预制体
- ❌ 敌人预制体
- ❌ NavMesh 烘焙（框架自动处理）

#### Step 2: 打开 AI 模拟器

```
1. 在 ExploreAITestScene 中 Play
2. Unity菜单 → 战斗工具 → 敌人AI模拟器
3. 配置参数后点击 [生成]
```

#### Step 3: 配置参数

```
玩家配置:
  - 玩家ID: 1001 (从SummonerTable选择)
  - 生成位置: (0, 0, -3)

敌人配置:
  - 生成范围中心: (0, 0, 5)
  - 生成范围半径: 8 (米)
  
敌人列表:
  - 敌人1: ID=2, 数量=1
  - 敌人2: ID=4, 数量=2

[生成] [清除]
```

## 测试场景与预期行为

### 场景 1: 普通敌人视野检测

**目标**: 测试警觉度增长和状态转换

**操作步骤**:
1. 敌人配置ID改为 1001（普通敌人）
2. 生成敌人
3. 从敌人 8m 外缓慢靠近

**预期行为**:
```
✓ 敌人初始状态: Patrol（巡逻）
✓ 距离 < 8m: 警觉缓慢增长 (0.5/秒)
✓ 警觉度 > 阈值: Alert（警戒）
✓ 继续靠近: Chase（追击，警觉达到1.0）
```

### 场景 2: 视野锥测试

**目标**: 测试扇形视野（60 度、12m）的加速检测

**操作步骤**:
1. **正前方靠近**: 从敌人正前方接近（在 60 度视锥内）
2. **侧面靠近**: 从敌人侧面接近（在圆形范围内但视锥外）
3. **对比警觉增长速度**

**预期结果**:
```
✓ 正前方: 警觉增长 1.5倍速 (0.75/秒)
✓ 侧面: 警觉增长正常速 (0.5/秒)
```

### 场景 3: 警觉衰减测试

**目标**: 测试玩家逃脱时的警觉衰减

**操作步骤**:
1. 惹怒敌人（让其进入 Chase 状态）
2. 快速远离，离开视野范围
3. 观察警觉度下降速度

**预期行为**:
```
✓ 离开视野: 警觉缓慢衰减 (0.2/秒)
✓ 衰减到 0: 敌人回到 Patrol 状态
```

### 场景 4: 多敌人协作测试

**目标**: 测试敌人间的警戒广播

**配置**:
```
敌人列表:
  - ID: 2, 数量: 2  (两个普通敌人，间距 5m)
```

**操作**:
1. 靠近第一个敌人，让其进入 Chase
2. 观察第二个敌人是否进入 AlertedByBroadcast

**预期**:
```
✓ 敌人1: Chase → 广播警告
✓ 敌人2: Alert/AlertedByBroadcast
```

## 常见问题排查

### Q1: 敌人不动/无法移动？

**检查清单**:
- [ ] NavMesh 是否烘焙成功（绿色覆盖地面）
- [ ] 地面是否标记为 Walkable
- [ ] 敌人是否卡在地形缝隙中（检查 Spawn 位置）
- [ ] Animator 是否正确初始化

### Q2: 没有 Console 输出？

**检查清单**:
- [ ] Console 窗口是否打开（Window → General → Console）
- [ ] 敌人是否成功初始化（Inspector 看到 Config 信息）
- [ ] `Show AI Debug Log` 或 `输出AI状态日志` 是否勾选
- [ ] LogLevel 是否设置正确

### Q3: Gizmo 不显示？

**检查清单**:
- [ ] `Show Vision Gizmo` 是否勾选
- [ ] Scene 窗口右上角 Gizmo 按钮是否打开
- [ ] 敌人是否成功生成（生成失败时无 Gizmo）

### Q4: 玩家控制无反应？

**检查清单**:
- [ ] PlayerObject 是否有 CharacterController 组件
- [ ] PlayerObject 的 Tag 是否为 "Player"
- [ ] TestController 中是否正确赋值了 PlayerObject
- [ ] 是否已进入 Play 模式

## 与战斗系统的联动

敌人探索 AI 和战斗系统的连接点：

```
EnemyEntityAI.Chase 状态
    ↓ （玩家触发战斗）
CombatTriggerManager（检测触发类型）
    ├─ SneakAttack（偷袭）
    ├─ Encounter（遭遇战）
    └─ EnemyInitiative（敌方先手）
        ↓
CombatState（进入战斗）
```

**测试建议**: 在方案 3（AI 模拟器）中，进行敌人追击 → 战斗转换的完整流程测试

## 进阶调试技巧

### 技巧 1: 实时修改 AI 参数

```csharp
// 在 ExploreAITestController 中，可临时修改：
m_TestEnemy.Config.VisionCircleRadius = 10f;  // 加大检测范围
m_TestEnemy.Config.AlertIncreaseRate = 1.0f;  // 加快警觉增长
```

### 技巧 2: 添加多敌人压力测试

```csharp
public async void SpawnMultipleEnemies(int count)
{
    for (int i = 0; i < count; i++)
    {
        m_EnemySpawnPosition.x += 3f;  // 横向间隔
        await SpawnTestEnemyAtPosition(m_EnemySpawnPosition);
    }
}
```

### 技巧 3: 屏幕录制演示

1. 在 Inspector 中勾选 "Show Vision Gizmo"
2. 在 Scene 窗口按 G 隐藏 UI
3. 按 Record 录制玩家靠近敌人的过程

### 技巧 4: 性能分析

```
Window → Analysis → Profiler
监测 CPU 占用和内存使用
多敌人场景下观察性能表现
```

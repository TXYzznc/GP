## 一、装备品质体系

### 品质等级表

| 品质 | 稀有度 | 属性倍数 | 出现率 | 配置表倍数 | 特殊效果 |
|------|-------|---------|-------|-----------|---------|
| 普通 | ★ | 1.0x | 40% | 1.0 | 无 |
| 稀有 | ★★ | 1.3x | 30% | 1.3 | 小概率特效 |
| 史诗 | ★★★ | 1.6x | 20% | 1.6 | 中等特效 |
| 传说 | ★★★★ | 2.0x | 8% | 2.0 | 强力特效 |
| 神话 | ★★★★★ | 2.5x | 2% | 2.5 | 超强特效 |

### 品质差异说明

#### 属性倍数计算

```
装备当前属性 = 配置表基础值 × 品质倍数 + 等级加成
```

**示例**：
```
基础ATK = 100（配置表）
品质 = 传说（2.0x）
等级加成 = 20

当前ATK = 100 × 2.0 + 20 = 220
```

#### 出现率说明

```
掉落装备时：
- 普通品质：40% 概率
- 稀有品质：30% 概率
- 史诗品质：20% 概率
- 传说品质：8% 概率
- 神话品质：2% 概率
```

## 二、怪物分级体系

### 分级等级表

| 分级 | 名称 | 血量倍数 | 伤害倍数 | 掉落倍数 | 难度评价 | 推荐等级 |
|------|------|---------|---------|---------|---------|---------|
| 1 | 普通 | 1.0x | 1.0x | 1.0x | 容易 | 等级-5~-1 |
| 2 | 精英 | 1.5x | 1.3x | 1.5x | 困难 | 等级-2~+2 |
| 3 | BOSS | 3.0x | 2.0x | 3.0x | 很难 | 等级+3~+5 |
| 4 | 世界BOSS | 5.0x | 3.0x | 5.0x | 极难 | 等级+8+ |

### 分级影响说明

#### 血量倍数计算

```
怪物当前HP = 配置表基础HP × 分级倍数
```

**示例**：
```
基础HP = 100
分级 = BOSS（3.0x）
当前HP = 100 × 3.0 = 300
```

#### 伤害倍数计算

```
怪物当前伤害 = 配置表基础伤害 × 分级倍数
```

**示例**：
```
基础伤害 = 50
分级 = 精英（1.3x）
当前伤害 = 50 × 1.3 = 65
```

#### 掉落倍数计算

```
掉落物数量 = 配置表基础数量 × 分级倍数
掉落金币 = 配置表基础金币 × 分级倍数
掉落经验 = 配置表基础经验 × 分级倍数
```

**示例**：
```
基础掉落金币 = 100
分级 = BOSS（3.0x）
当前掉落 = 100 × 3.0 = 300
```

## 三、难度评价系统

### 等级压制说明

```
推荐等级 = 玩家等级 + 等级差
```

**等级差影响**：
- -5 级：极易（怪物基本无威胁）
- -2 ~ +2 级：正常难度（适合大多数玩家）
- +3 ~ +5 级：挑战难度（需要精确操作）
- +8 级以上：极限难度（仅限高手）

### 难度指标

| 分级 | 预期赢率 | 平均耗时 | 危险程度 |
|------|---------|---------|---------|
| 普通 | >90% | 1-2分钟 | 极低 |
| 精英 | 70-80% | 3-5分钟 | 中等 |
| BOSS | 40-60% | 5-10分钟 | 高 |
| 世界BOSS | <30% | 10分钟+ | 极高 |

## 四、配置表集成

### 怪物配置表结构

```
MonsterTable
├─ ID（怪物ID）
├─ Name（名称）
├─ Grade（分级：1-4）
├─ BaseHP（基础血量）
├─ BaseDamage（基础伤害）
├─ DropCount（基础掉落数量）
├─ DropGold（基础掉落金币）
├─ DropExp（基础掉落经验）
└─ LootTable（掉落物列表）
```

### 装备配置表结构

```
EquipmentTable
├─ ID（装备ID）
├─ Name（名称）
├─ Rarity（品质：1-5）
├─ BaseATK（基础攻击）
├─ BaseDEF（基础防御）
├─ BaseSPD（基础速度）
├─ SpecialEffect（特殊效果）
└─ SpecialParam（特效参数）
```

## 五、游戏内表现示例

### 场景1：普通怪物 vs 精英怪物

```
配置表数据：
  基础HP = 100
  基础伤害 = 50

普通怪物（分级1）：
  HP = 100 × 1.0 = 100
  伤害 = 50 × 1.0 = 50
  掉落金币 = 100

精英怪物（分级2）：
  HP = 100 × 1.5 = 150
  伤害 = 50 × 1.3 = 65
  掉落金币 = 150

对比：
  精英怪物血量多 50%，伤害高 30%，掉落多 50%
  难度提升明显，奖励也更丰厚
```

### 场景2：装备品质对比

```
配置表：
  基础ATK = 100
  基础DEF = 50

普通品质（1.0x）：
  ATK = 100 × 1.0 = 100
  DEF = 50 × 1.0 = 50

传说品质（2.0x）：
  ATK = 100 × 2.0 = 200
  DEF = 50 × 2.0 = 100

对比：
  传说品质攻防都翻倍，性能差异巨大
  稀有装备出现率是传说的 3.75 倍，但属性相差 54%
```

## 六、平衡性设计原则

### 6.1 难度递进原则

```
普通 → 精英 → BOSS → 世界BOSS
1.0x    1.3-1.5x   3.0x    5.0x
```

**设计考虑**：
- 普通：新手和打金副本
- 精英：正常主线进度
- BOSS：故事关键战斗
- 世界BOSS：公会/多人挑战

### 6.2 品质差异原则

```
普通 → 稀有 → 史诗 → 传说 → 神话
1.0x   1.3x   1.6x   2.0x   2.5x
```

**出现率逆向分布**：
```
普通品质最容易出现，神话品质最稀少
这激励玩家继续升级和收集
```

### 6.3 掉落平衡原则

```
同级怪物掉落数量相同
高级怪物掉落倍增
品质装备掉落率稳定
```

## 七、扩展系统

### 7.1 精英属性强化

精英怪物除了倍数提升外，还可以：
- 获得额外 Buff（护盾、减伤等）
- 增加 AI 智能度
- 获得特殊技能
- 增加行动频率

### 7.2 BOSS 特殊机制

BOSS 怪物可以有：
- 分阶段血量（第二阶段攻击力提升）
- 特殊技能（群体攻击、治疗等）
- 护盾机制（护盾破碎才能伤害）
- 逃离机制（等待时间过长会跑掉）

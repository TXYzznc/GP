## 一、宝物获取途径

### 1.1 掉落获取
- **战斗掉落**：怪物死亡时随机掉落（基于分级和品质）
- **概率设置**：
  - 普通怪物：5% 概率掉落宝物
  - 精英怪物：15% 概率掉落宝物
  - BOSS：50% 概率掉落宝物
  - 世界BOSS：100% 概率掉落宝物

### 1.2 宝箱开启
- **探索宝箱**：探索场景中发现的宝箱
- **掉落概率**：基于宝箱等级
- **数量**：每个宝箱 1-3 件宝物

### 1.3 任务奖励
- **特定任务**：特定任务完成后固定获得
- **任务等级**：高等级任务掉落高品质宝物
- **必定掉落**：任务奖励的宝物品质有保证

### 1.4 商店购买
- **用货币购买**：消耗金币购买常见宝物
- **用钻石购买**：消耗钻石购买稀有宝物
- **每日限额**：防止玩家过度氪金

## 二、宝物效果系统

### 2.1 效果类型分类

#### 被动属性型
```
无需激活，自动生效

属性加成：+ATK, +DEF, +SPD, +HP 等
触发方式：自动激活
冷却时间：无
伤害提升：5%-30%
防御提升：5%-30%
```

**配置示例**：
```
宝物ID: 5001
名称: 攻击宝物
效果类型: 被动属性
数值: +30 ATK
触发: 自动
冷却: 无
```

#### 主动技能型
```
需要玩家手动释放，进行一次性伤害或治疗

基础伤害：200-500
触发条件：手动释放
冷却时间：5-10秒
消耗资源：MP或能量
```

**配置示例**：
```
宝物ID: 5002
名称: 火球宝物
效果类型: 主动技能
基础伤害: 300
冷却时间: 5秒
消耗: 50MP
范围: 单体
```

#### 触发型效果
```
特定条件触发的被动效果

触发概率：20%-50%
触发条件：战斗事件（击中、受伤、击杀等）
冷却时间：3-5秒
效果：各种特殊效果（吸血、反伤、冰冻等）
```

**配置示例**：
```
宝物ID: 5003
名称: 吸血宝物
效果类型: 触发型
触发事件: 造成伤害
触发概率: 30%
效果: 恢复伤害量的20%
冷却: 3秒
```

#### 光环型效果
```
持续激活的范围效果

范围：5-15m（周围单位）
作用对象：友方或敌方
持续激活：战斗中始终激活
无冷却时间
```

**配置示例**：
```
宝物ID: 5004
名称: 防御光环
效果类型: 光环
范围: 10m
作用: 友方受伤-10%
持续: 战斗中始终激活
冷却: 无
```

## 四、宝物效果实现

### 4.1 被动属性实现

```csharp
public class PassiveAttributeEffect : ITreasureEffect
{
    public void Apply(ChessEntity owner, TreasureConfig config)
    {
        // 添加永久属性加成
        owner.Attribute.AddModifier(new AttributeModifier(
            config.EffectValue,
            AttributeType.ATK
        ));
    }

    public void Remove(ChessEntity owner)
    {
        // 移除属性加成
    }
}
```

### 4.2 主动技能实现

```csharp
public class ActiveSkillEffect : ITreasureEffect
{
    public void Execute(ChessEntity caster, Vector3 targetPos)
    {
        // 消耗MP
        if (caster.Attribute.CurrentMp < config.CostMp)
            return;
        
        caster.Attribute.ConsumeMp(config.CostMp);
        
        // 造成伤害
        float damage = config.BaseDamage;
        CastResult.ApplyDamage(target, damage);
        
        // 播放效果
        EffectManager.Play(config.EffectId, targetPos);
    }
}
```

### 4.3 触发型效果实现

```csharp
public class TriggerEffect : ITreasureEffect
{
    public void OnDealDamage(ChessEntity dealer, ChessEntity target, float damage)
    {
        // 检查概率
        if (Random.value > config.TriggerProbability)
            return;
        
        // 检查冷却
        if (!cooldownTimer.IsReady())
            return;
        
        // 执行效果（如吸血）
        float healAmount = damage * config.EffectValue;
        dealer.Attribute.Heal(healAmount);
        
        // 重置冷却
        cooldownTimer.Reset(config.CooldownTime);
    }
}
```

## 五、品质系统

### 5.1 品质与掉落的关系

| 品质 | 稀有度 | 出现率 | 优化难度 | 效果强度 |
|------|-------|-------|--------|---------|
| 普通 | ★ | 60% | 易 | 基础 |
| 稀有 | ★★ | 25% | 中 | 增强 |
| 史诗 | ★★★ | 10% | 难 | 强力 |
| 传说 | ★★★★ | 4% | 很难 | 极强 |
| 神话 | ★★★★★ | 1% | 极难 | 超强 |

### 5.2 品质影响效果数值

```
实际效果数值 = 基础数值 × (1 + (品质等级 - 1) × 0.3)

普通（1）：× 1.0
稀有（2）：× 1.3
史诗（3）：× 1.6
传说（4）：× 1.9
神话（5）：× 2.2
```

**示例**：
```
攻击宝物 基础数值 = 30 ATK

普通品质：30 × 1.0 = 30 ATK
稀有品质：30 × 1.3 = 39 ATK
史诗品质：30 × 1.6 = 48 ATK
传说品质：30 × 1.9 = 57 ATK
神话品质：30 × 2.2 = 66 ATK
```

## 六、宝物槽位与装备

### 6.1 装备槽位
```
单个棋子可装备 1-3 个宝物（根据等级提升）
等级1-20：1个槽位
等级21-40：2个槽位
等级41+：3个槽位
```

### 6.2 效果叠加规则
```
相同宝物不能同时装备（防止过度堆叠）
不同宝物效果可以叠加
光环型效果在范围内对友方生效
```

## 九、平衡性考虑

### 9.1 获取难度
```
- 普通宝物：随处可得，快速积累
- 稀有宝物：中等难度，需要有目标地刷
- 史诗宝物：较难获取，鼓励玩家探索
- 传说/神话：极难获取，激励长期游玩
```

### 9.2 效果强度限制
```
- 单个宝物不能超过总加成的 20%
- 宝物效果与装备效果平衡
- 高品质宝物同步提高成本
```

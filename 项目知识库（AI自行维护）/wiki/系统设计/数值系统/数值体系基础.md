## 一、基础数值模型

### 1.1 棋子属性体系

**基础属性**：
- **HP**（生命值）：当前血量
- **MP**（魔法值）：释放技能消耗
- **ATK**（攻击力）：物理伤害基础
- **DEF**（防御力）：物理伤害减免
- **SPD**（速度）：行动顺序和频率

**衍生属性**：
- 命中率 = 基础 + 装备加成 - 敌方闪避率
- 暴击率 = 基础 + 装备加成
- 闪避率 = 基础 + 装备加成
- 抗性 = 基础 + Buff加成

### 1.2 属性初始化

```
棋子属性 = 配置表基础值 + 等级加成 + 装备加成 + Buff加成
```

**等级加成公式**：
```
属性增长 = 基础值 × (等级 - 1) × 增长率
```

**示例**（以ATK为例）：
```
基础ATK = 100（配置表）
等级 = 5
增长率 = 0.1（10%）

当前ATK = 100 + 100 × (5-1) × 0.1 = 140
```

## 二、伤害体系（11套公式）

### 2.1 物理伤害系列（2套）

#### 公式1：基础物理伤害
```
伤害 = 基础伤害 + 施法者ATK × 系数
伤害_浮动 = 伤害 ± (伤害 × 浮动比例)
```

**参数**：
- 基础伤害：固定值（如 50）
- 系数：通常 0.5-2.0
- 浮动比例：5%-15%

**示例**：
```
技能伤害 = 50 + 100 × 1.0 = 150
浮动 = ±(150 × 0.1) = ±15
最终伤害范围 = 135-165
```

#### 公式2：暴击伤害
```
暴击伤害 = 基础伤害 × (1 + 暴击倍数)
触发概率 = 暴击率 - 敌方抗暴
```

**参数**：
- 暴击倍数：1.5-3.0（通常 2.0）
- 暴击率：配置表 + 装备 + Buff
- 抗暴率：某些敌人或Buff提供

### 2.2 法术伤害系列（3套）

#### 公式3：基础法伤
```
伤害 = 基础伤害 + 施法者INT × 系数
```

#### 公式4：抗性递减法伤
```
最终伤害 = 基础伤害 × (1 - 目标法抗)
```

**示例**：
```
基础伤害 = 200
目标法抗 = 0.3（30%）
最终伤害 = 200 × (1 - 0.3) = 140
```

#### 公式5：等级压制
```
最终伤害 = 基础伤害 × (1 + (施法者等级 - 目标等级) × 0.05)
```

**示例**：
```
基础伤害 = 100
施法者等级 = 10，目标等级 = 8
压制倍数 = 1 + (10-8) × 0.05 = 1.1
最终伤害 = 100 × 1.1 = 110
```

### 2.3 真实伤害系列（2套）

#### 公式6：固定真伤
```
伤害 = 固定值（无法被防御或护甲减免）
```

**特点**：
- 忽视所有防御值
- 忽视所有抗性
- 用于特殊技能

#### 公式7：百分比真伤
```
伤害 = 目标最大HP × 百分比
```

**示例**：
```
目标最大HP = 1000
百分比 = 0.1（10%）
伤害 = 1000 × 0.1 = 100
```

### 2.4 治疗与护盾系列（2套）

#### 公式8：治疗
```
治疗量 = 基础治疗值 + 施法者INT × 系数
```

#### 公式9：护盾
```
护盾值 = 基础护盾值 + 施法者ATK × 系数
护盾数值 = min(护盾值, 目标最大HP × 200%)
```

**说明**：护盾不能超过目标最大HP的200%

### 2.5 复合伤害系列（2套）

#### 公式10：连击伤害
```
总伤害 = 单次伤害 × 连击次数 × (1 + 连击加成)
```

**示例**：
```
单次伤害 = 50
连击次数 = 3
连击加成 = 0.2（20%）
总伤害 = 50 × 3 × (1 + 0.2) = 180
```

#### 公式11：群体伤害
```
总伤害 = 单次伤害 × 目标数 × (1 - 群体衰减 × (目标数-1))
```

**示例**：
```
单次伤害 = 100
目标数 = 3
群体衰减 = 0.1（每增加1个目标衰减10%）
总伤害 = 100 × 3 × (1 - 0.1 × 2) = 240
```

## 三、伤害减免流程

```
原始伤害（从伤害公式计算得出）
  ↓
[减免1] 防御值减免
  计算式：伤害 × (1 - DEF / (DEF + 100))
  例：防御100，原伤害200 → 伤害200 × (1 - 100/200) = 100
  ↓
[减免2] 护甲减免
  计算式：伤害 × (1 - 护甲值 / 500)
  例：护甲200，伤害100 → 伤害100 × (1 - 200/500) = 60
  ↓
[减免3] Buff加成（护盾、减伤Buff等）
  例：有"减伤50%"的Buff → 伤害 × (1 - 0.5) = 伤害 × 0.5
  ↓
[减免4] 最终最小伤害保证
  计算式：max(最终伤害, 原始伤害 × 0.1)
  例：原伤害100，最终伤害5 → 取max(5, 10) = 10
  ↓
最终伤害（应用到当前HP）
  当前HP = max(当前HP - 最终伤害, 0)
```

## 四、具体伤害计算示例

### 场景1：嫦娥攻击邪灵

```
基础信息：
- 嫦娥 ATK = 100
- 邪灵 DEF = 50, 护甲 = 100

步骤1：计算基础伤害
  伤害 = 100 + 100 × 1.0 = 200

步骤2：防御值减免
  减免比例 = 50 / (50 + 100) = 33.3%
  减免后 = 200 × (1 - 0.333) = 133

步骤3：护甲减免
  减免比例 = 100 / 500 = 20%
  减免后 = 133 × (1 - 0.20) = 106

步骤4：Buff加成
  邪灵有"减伤10%" Buff
  减免后 = 106 × (1 - 0.10) = 95

步骤5：最小伤害保证
  最小值 = 200 × 0.1 = 20
  最终 = max(95, 20) = 95

结果：嫦娥对邪灵造成95点伤害
```

### 场景2：救赎之光治疗

```
基础信息：
- 施法者INT = 80
- 治疗基础值 = 150

步骤1：计算基础治疗
  治疗量 = 150 + 80 × 1.0 = 230

步骤2：应用Buff加成
  有"治疗加成20%" Buff
  最终 = 230 × (1 + 0.20) = 276

结果：救赎之光恢复276点生命值
```

## 五、属性相关性分析

### 5.1 攻击力与防御的平衡

```
设置建议：
- 平均防御 ≈ 平均攻击力 × 0.5
- 纯防御队伍应能减免 50% 以上伤害
- 纯输出队伍应突破防御，造成有效伤害
```

### 5.2 生命值与恢复的平衡

```
设置建议：
- 每秒恢复 ≤ 最大HP × 5%
- 单次治疗 ≤ 最大HP × 30%
- 护盾值 ≤ 最大HP × 200%
```

### 5.3 速度与行动频率的平衡

```
SPD 差值 影响
10 → 战斗中多出 1 次行动
20 → 战斗中多出 2-3 次行动
30 → 战斗中多出 4-5 次行动
```

## 六、配置表集成

### 对应的配置表

| 配置表 | 字段 | 说明 |
|--------|------|------|
| ChessTable | BaseDamage, DamageType, Coeff | 技能伤害配置 |
| SkillTable | BaseDamage, Coefficient, HitCount | 技能参数 |
| BuffTable | EffectType, Value, Duration | Buff效果 |
| EquipmentTable | ATK, DEF, SPD | 装备属性加成 |

### 使用流程

```
Excel配置表（如 ChessTable.xlsx）
  ↓ 运行 DataTableGenerator
  ↓
生成 ChessTable.cs（自动生成，不要手改）
  ↓
游戏代码读取：var config = ChessTable.Instance.GetConfig(chessId)
  ↓
获取伤害公式参数：
  - BaseDamage = config.BaseDamage
  - DamageType = config.DamageType
  - Coefficient = config.Coefficient
  ↓
代入伤害公式计算
```

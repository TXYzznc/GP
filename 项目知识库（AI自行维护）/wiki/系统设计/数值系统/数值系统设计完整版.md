## 一、实战设计方案

### 1.1 基础数值模型

**棋子属性体系**：
- 基础属性：HP、MP、ATK、DEF、SPD
- 衍生属性：命中率、暴击率、闪避率、抗性
- 临时属性：当前HP、当前MP、临时加成

### 1.2 伤害体系（11套公式）

#### 物理伤害（2套）
1. **基础物理伤害** = 基础伤害 + 施法者ATK × 系数
2. **伤害浮动** = 基础伤害 ± (基础伤害 × 浮动比例)

#### 法术伤害（3套）
3. **基础法伤** = 基础伤害 + 施法者INT × 系数
4. **抗性递减** = 基础伤害 × (1 - 目标法抗)
5. **等级压制** = 基础伤害 × (1 + (施法者等级 - 目标等级) × 0.05)

#### 真实伤害（2套）
6. **固定真伤** = 固定伤害值（无法抵抗）
7. **百分比真伤** = 目标最大HP × 百分比

#### 护盾和治疗（2套）
8. **护盾值** = 护盾基础值 + 施法者ATK × 系数
9. **治疗量** = 治疗基础值 + 施法者INT × 系数

#### 复合伤害（2套）
10. **连击伤害** = 单次伤害 × 连击次数 × (1 + 连击加成)
11. **群体伤害** = 单次伤害 × 目标数 × (1 - 群体衰减)

### 1.3 伤害减免流程

```
原始伤害
  ↓
[减免1] 防御值减免 = 原始伤害 × (1 - DEF / (DEF + 100))
  ↓
[减免2] 护甲减免 = 减免后伤害 × (1 - 护甲值 / 500)
  ↓
[减免3] Buff加成（护盾、减伤Buff等）
  ↓
[减免4] 最终最小伤害保证 = max(最终伤害, 原始伤害 × 0.1)
  ↓
最终伤害
  ↓
当前HP = max(当前HP - 最终伤害, 0)
```

## 二、理论基础

### 2.1 数值设计原则

#### 平衡性原则
- 任何单一属性不应超过总伤害的 50%
- Buff 加成不超过基础值的 200%
- 防御系数不超过伤害的 30%

#### 可扩展性原则
- 新增伤害类型时，遵循 base + 系数 + 修正的模式
- 新增减免机制时，按顺序处理，避免重复

#### 玩家感知原则
- 暴击、浮动等概率事件给予清晰反馈
- 大招伤害应至少 2-3 倍普攻伤害
- 治疗效果应与伤害成正比

### 2.2 属性相关性分析

**攻击力与防御的关系**：
- 纯防御队伍应能抵抗 50% 以上伤害
- 纯输出队伍应突破防御

**生命值与回复的关系**：
- 每秒回复不超过最大HP的 5%
- 单次治疗不超过最大HP的 30%

**速度与行动次数的关系**：
- SPD 差 10 = 1 轮战斗中多出 1 次行动
- 最快速度不超过最慢速度的 2 倍

## 五、完整流程示例

### 5.1 战斗中的伤害计算

**场景**：嫦娥（ATK 100）攻击邪灵（DEF 50）

```
步骤1：基础伤害计算
  基础伤害 = 100 + 100 × 2.0 = 300

步骤2：防御减免
  减免比例 = 50 / (50 + 100) = 33.3%
  减免后伤害 = 300 × (1 - 0.333) = 200

步骤3：护甲减免
  假设邪灵护甲值 = 100
  减免比例 = 100 / 500 = 20%
  减免后伤害 = 200 × (1 - 0.20) = 160

步骤4：Buff加成
  假设邪灵有"减伤50%"的Buff
  减免后伤害 = 160 × (1 - 0.50) = 80

步骤5：最小伤害保证
  最小伤害 = 300 × 0.1 = 30
  最终伤害 = max(80, 30) = 80

结果：嫦娥对邪灵造成 80 点伤害
```

### 5.2 治疗和护盾

**场景**：救赎之光（治疗）恢复最低血量友方

```
步骤1：基础治疗量
  基础治疗 = 150 + 施法者INT × 1.0
  假设施法者INT = 80
  基础治疗 = 150 + 80 = 230

步骤2：Buff加成
  假设施法者有"治疗加成20%"的Buff
  最终治疗 = 230 × (1 + 0.20) = 276

步骤3：应用治疗
  目标当前HP = min(当前HP + 276, 最大HP)
```

## 七、数值调整指南

### 7.1 战斗太容易？

**诊断**：
- [ ] 玩家伤害 > 怪物HP 的 30%
- [ ] 玩家防御 > 怪物伤害 的 50%
- [ ] 战斗耗时 < 30 秒

**调整方案**：
- 降低玩家攻击系数（2.0 → 1.5）
- 提高怪物生命值（1.0x → 1.2x）
- 提高怪物伤害系数（1.0x → 1.2x）

### 7.2 战斗太困难？

**诊断**：
- [ ] 玩家HP < 怪物伤害的 3 倍
- [ ] 玩家防御 < 怪物伤害 的 20%
- [ ] 战斗耗时 > 2 分钟

**调整方案**：
- 提高玩家攻击系数（1.5 → 2.0）
- 降低怪物防御（1.0x → 0.8x）
- 降低怪物速度（1.0x → 0.8x）

**关键代码** (Line 22-37):
```csharp
public void AddEXP(int amount)
{
    if (amount <= 0)
    {
        DebugEx.LogModule("ChessEXPComponent", $"❌ AddEXP 被调用但amount无效: {amount}");
        return;
    }
    int old = CurrentEXP;
    CurrentEXP += amount;
    DebugEx.LogModule("ChessEXPComponent", $"📊 AddEXP 成功: 棋子={gameObject.name}, 增加经验={amount}, {old} → {CurrentEXP}");
    if (OnEXPChanged != null)
    {
        DebugEx.LogModule("ChessEXPComponent", $"✅ OnEXPChanged 触发，订阅者数={OnEXPChanged.GetInvocationList().Length}");
        OnEXPChanged?.Invoke(old, CurrentEXP);
    }
    else
    {
        DebugEx.WarningModule("ChessEXPComponent", $"⚠️ OnEXPChanged 为null，没有订阅者");
    }
}
```

**事件**:
- `OnEXPChanged` — 经验变化事件 (触发 UI 更新)

## 诊断步骤

### 第一步：检查敌方棋子死亡是否触发
查看日志输出 `[ChessEXPManager]` 部分：
```
[1] OnChessDied 被调用: deadChess=后羿, Camp=1
```
- ✅ 如果看到这条日志 → 说明死亡事件正确触发
- ❌ 如果看不到 → 说明 OnChessDied 没有被调用

### 第二步：检查经验奖励查询
```
[3] 获取经验奖励: 10
```
- ✅ 看到具体数值 → 说明表查询成功
- ❌ 看到 0 → 说明表查询失败或配置错误

### 第三步：检查玩家棋子获取
```
[6] 获取所有棋子数量: 3
```
- ✅ 看到数字 > 0 → 说明能获取玩家棋子
- ❌ 看到 0 → 说明没有玩家棋子

### 第四步：检查经验加成功
```
[9] ✅ 给棋子 后羿 加经验: 10
[10] 完成: ... 成功给 1 个玩家棋子 +10 EXP
```
- ✅ 看到这些日志 → 经验加成成功
- ❌ 看到 `❌ 棋子 X 没有 ChessEXPComponent` → 说明组件未初始化

### 第五步：检查 UI 是否收到通知
```
[SummonChessStateUI] [OnEXPChanged] 棋子=后羿, 经验: 0 → 10
```
- ✅ 看到这条日志 → 说明 UI 收到了事件
- ❌ 看不到 → 说明事件没有触发或 UI 没有订阅

## 常见问题排查

| 问题 | 症状 | 原因 | 解决方案 |
|------|------|------|--------|
| 经验组件未初始化 | `❌ 棋子 X 没有 ChessEXPComponent` | ChessEntity.Initialize() 中未创建组件 | ✅ 已在 Line 120-128 修复 |
| 经验表配置缺失 | `[GetEXPReward] ❌ 在 ChessEXPRuleTable 中未找到...` | ChessEXPRuleTable 表中缺少对应等级配置 | 检查 DataTable 是否包含 RuleType=2 且 EnemyRank 匹配的行 |
| 敌方棋子 Rank 错误 | `[GetEXPReward] ❌ 在 ChessAdvanceTable 中未找到敌方棋子` | 敌方棋子没有在 ChessAdvanceTable 中配置 | 确保 EnemyEntityTable 中的敌人 ChessId 在 ChessAdvanceTable 中有对应配置 |
| UI 不显示 | 经验值增加但 UI 无变化 | `⚠️ OnEXPChanged 为null，没有订阅者` | 检查 SummonChessStateUI.Bind() 是否被调用 |
| 玩家棋子无法获得经验 | 没有 `给棋子 X 加经验` 日志 | SummonChessManager.GetAllChess() 返回空列表 | 检查玩家棋子是否被正确注册到 SummonChessManager |

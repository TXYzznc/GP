
```csharp

// 获取所有脚本的启用状态
```

## 使用示例

### 基础使用

```csharp
// 在脚本中输出日志
public class ChessManager : MonoBehaviour
{
    private void Start()
    {
        // 普通日志
        DebugEx.Log("ChessManager", "棋子初始化完成");

        // 带颜色的日志
        DebugEx.LogColor("ChessManager", "初始化成功", DebugEx.Color.Green);

        // 警告日志
        DebugEx.Warning("ChessManager", "缺少某个配置");

        // 错误日志
        DebugEx.Error("ChessManager", "初始化失败，原因：...");

        // 便捷方法
        DebugEx.Success("ChessManager", "棋子加载完成");
        DebugEx.Fail("ChessManager", "棋子加载失败");
    }
}
```

### 编辑器工具使用流程

1. **打开工具箱** - 菜单：Tools > 开发工具箱（ToolHub）
2. **选择日志配置管理器** - 左侧菜单：调试工具 > 日志配置管理器
3. **搜索脚本** - 在搜索框输入脚本名称进行过滤
4. **控制日志输出**
   - 点击复选框启用/禁用某个脚本的日志
   - 使用批量操作快速管理多个脚本
5. **保存配置** - 点击"保存配置"按钮保存当前设置

## 技术细节

### 日志启用状态查询规则
1. 如果 `DebugEx.EnableLog = false` → 所有日志禁用
2. 如果脚本未在字典中 → 默认启用
3. 如果脚本在字典中 → 按字典的值决定

### 配置文件格式
```json
{
  "entries": [
    {
      "scriptName": "ChessManager",
      "isEnabled": true
    },
    {
      "scriptName": "CombatManager",
      "isEnabled": false
    }
  ]
}
```

### 数据流向
```
编辑器窗口
   ↓
DebugEx.SetScriptLogEnabled()  (内存更新)
   ↓
LogConfigManager.SaveConfigToFile()  (文件持久化)
   ↓
log_settings.json

游戏运行时：
LogConfigManager.LoadConfigFromFile()
   ↓
DebugEx.SetAllScriptLogEnabled()
   ↓
日志调用时检查 IsScriptLogEnabled()
```

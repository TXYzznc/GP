## 一、现状分析

### 问题识别
当前12个卡牌效果脚本中，存在大量重复代码：
- 都是 Init + Execute 的简单接口
- 都要获取所有棋子、遍历、筛选、应用效果、播放特效
- 只有**目标选择逻辑**和**效果应用逻辑**差异大

## 二、架构设计

### 2.1 总体框架

采用**策略模式 + 组合模式**：

```
GenericCardEffect（通用效果框架）
├─ ICardTargetSelector（选择器）→ 确定目标
└─ ICardEffectApplier[]（应用器）→ 应用效果

执行流程：
选择目标 → 应用效果 → 播放特效
```

### 2.2 核心类设计

#### 目标选择器接口

```csharp
public interface ICardTargetSelector
{
    List<ChessEntity> SelectTargets(List<ChessEntity> allChess, CardData cardData, Vector3 targetPosition);
}
```

#### 效果应用器接口

```csharp
public interface ICardEffectApplier
{
    void ApplyEffect(List<ChessEntity> targets, CardData cardData);
}
```

#### 通用效果处理器

```csharp
public class GenericCardEffect : ICardEffect
{
    private CardData m_CardData;
    private ICardTargetSelector m_TargetSelector;
    private List<ICardEffectApplier> m_EffectAppliers;

    public void Init(CardData cardData, ICardTargetSelector selector, params ICardEffectApplier[] appliers)
    {
        m_CardData = cardData;
        m_TargetSelector = selector;
        m_EffectAppliers = new List<ICardEffectApplier>(appliers);
    }

    public void Execute(Vector3 targetPosition)
    {
        if (m_CardData == null || m_TargetSelector == null) return;

        var allChess = BattleChessManager.Instance?.GetAllChessEntities();
        if (allChess == null || allChess.Count == 0) return;

        // 1. 选择目标
        var targets = m_TargetSelector.SelectTargets(allChess, m_CardData, targetPosition);
        if (targets == null || targets.Count == 0) return;

        // 2. 应用所有效果
        foreach (var applier in m_EffectAppliers)
        {
            applier.ApplyEffect(targets, m_CardData);
        }

        // 3. 播放特效
        CardEffectHelper.PlayEffect(m_CardData.TableRow.EffectId, targetPosition);
    }
}
```

## 四、已实现的应用器

### 现有应用器

| 应用器 | 功能 | 参数来源 |
|--------|------|---------|
| `DamageApplier` | 基础伤害 | CardData.TableRow.BaseDamage |
| `HealApplier` | 治疗 | CardData.GetParam("healAmount") |
| `BuffApplier` | 命中应用Buff | CardData.HitBuffIds |
| `InstantBuffApplier` | 立即应用Buff | CardData.InstantBuffIds |
| `DamageWithCoefficientApplier` | 伤害系数伤害 | BaseDamage + Coefficient × 攻击力 |

### 应用器实现示例

```csharp
/// <summary>伤害应用器</summary>
public class DamageApplier : ICardEffectApplier
{
    public void ApplyEffect(List<ChessEntity> targets, CardData cardData)
    {
        float damage = cardData.TableRow.BaseDamage;
        int damageType = cardData.TableRow.DamageType;
        foreach (var target in targets)
        {
            if (target != null)
                CardEffectHelper.DealDamage(target, damage, damageType);
        }
    }
}

/// <summary>治疗应用器</summary>
public class HealApplier : ICardEffectApplier
{
    public void ApplyEffect(List<ChessEntity> targets, CardData cardData)
    {
        float healAmount = cardData.GetParam("healAmount", 0f);
        foreach (var target in targets)
        {
            if (target != null)
                CardEffectHelper.HealTarget(target, healAmount);
        }
    }
}
```

## 五、CardEffectExecutor 改造

### 5.1 新增工厂方法

**GetTargetSelector(CardTargetType)**

```csharp
private ICardTargetSelector GetTargetSelector(CardTargetType targetType)
{
    return targetType switch
    {
        CardTargetType.Self => new SelfSelector(),
        CardTargetType.AllAllyExcludeSummoner => new AllAllyExcludeSummonerSelector(),
        CardTargetType.AllAlly => new AllAlliesSelector(),
        CardTargetType.AllEnemy => new AllEnemiesSelector(),
        CardTargetType.SingleAlly => new ClosestAllySelector(),
        CardTargetType.AreaAlly => new AlliesInRadiusSelector(),
        CardTargetType.AreaEnemy => new EnemiesInRadiusSelector(),
        CardTargetType.SingleEnemy => new ClosestEnemySelector(),
        _ => null
    };
}
```

**GetEffectAppliers(CardData)**

自动判断所需应用器：
- 基于 DamageType、DamageCoeff、BaseDamage 判断是否需要伤害应用器
- 基于 ParamsConfig.healAmount 判断是否需要治疗应用器
- 基于 HitBuffIds、InstantBuffIds 判断是否需要 Buff 应用器

```csharp
private ICardEffectApplier[] GetEffectAppliers(CardData cardData)
{
    var appliers = new List<ICardEffectApplier>();
    
    // 伤害应用器
    if (cardData.TableRow.DamageType > 0)
    {
        if (cardData.TableRow.DamageCoeff > 0)
            appliers.Add(new DamageWithCoefficientApplier(GetCasterChess()));
        else if (cardData.TableRow.BaseDamage > 0)
            appliers.Add(new DamageApplier());
    }
    
    // 治疗应用器
    if (cardData.GetParam("healAmount", 0f) > 0)
        appliers.Add(new HealApplier());
    
    // Buff 应用器
    if (cardData.HitBuffIds.Length > 0)
        appliers.Add(new BuffApplier());
    if (cardData.InstantBuffIds.Length > 0)
        appliers.Add(new InstantBuffApplier());
    
    return appliers.ToArray();
}
```

### 5.2 简化 ExecuteCardEffect()

```csharp
public void ExecuteCardEffect(CardData cardData, Vector3 targetPosition)
{
    if (cardData == null) return;

    var selector = GetTargetSelector(cardData.TargetType);
    if (selector == null) return;

    var appliers = GetEffectAppliers(cardData);
    if (appliers.Length == 0) return;

    var effect = new GenericCardEffect();
    effect.Init(cardData, selector, appliers);
    effect.Execute(targetPosition);

    DebugEx.Log("CardEffectExecutor", $"✅ 卡牌 {cardData.Id} 效果执行: 选择器={selector.GetType().Name}, 应用器数={appliers.Length}");
}
```

## 七、完成工作总结

### Phase 1: 新增选择器 ✅

在 `TargetSelectors.cs` 中添加了 3 个缺失的选择器：

1. **SelfSelector** - 自身选择器（获取施法者自身）
2. **AllAllyExcludeSummonerSelector** - 全友（不含召唤师）
3. **AlliesInRadiusSelector** - 范围内友方选择器

现已覆盖全部 8 种目标类型。

### Phase 2: 改造 CardEffectExecutor ✅

- 新增 `GetTargetSelector()` 工厂方法
- 新增 `GetEffectAppliers()` 自动判断应用器
- 简化 `ExecuteCardEffect()` 使用通用框架
- 支持动态组合多个应用器

- CardTable 新增卡牌（1013-1027）的字段正确性

## 一、问题分类与诊断

### 1.1 常见问题类型

| 问题类型 | 数量 | 严重度 | 表现 | 修复难度 |
|---------|------|--------|------|---------|
| 字段缺失 | 15+ | P1 | 数据加载异常 | 低 |
| 数据不一致 | 20+ | P2 | 逻辑混乱 | 中 |
| 引用不存在 | 10+ | P1 | 空指针异常 | 中 |
| 类型错误 | 5+ | P0 | 编译失败 | 低 |
| 范围超限 | 8+ | P2 | 数值异常 | 中 |

### 1.2 问题示例

#### 字段缺失问题
```
问题：ChessTable 缺少 "SkillId" 字段
症状：棋子无法关联到技能
修复：在 ChessTable 中添加 SkillId, SkillId2 字段
```

#### 数据不一致问题
```
问题：BuffTable 和 SkillTable 的 Buff ID 对应不上
症状：释放技能时应用错误的Buff
修复：核对ID映射关系，确保引用正确
```

#### 引用不存在问题
```
问题：SkillTable.EffectId 引用不存在的效果ID
症状：技能无特效或特效错误
修复：删除无效引用或关联到正确的EffectId
```

## 二、修复方案清单

### 2.1 ChessTable 修复

**问题清单**：
```
[P1] 缺少 SkillId（主技能）和 SkillId2（大招）字段
[P1] 缺少 BuffTable ID 列表（初始化时应用的Buff）
[P2] 属性范围不合理（ATK/DEF 超出预期）
[P2] 缺少 NormalAttackDamage（普攻伤害配置）
```

**修复步骤**：
```
1. 打开 AAAGameData/DataTables/ChessTable.xlsx
2. 添加新列：SkillId, SkillId2, InitBuffIds, NormalAttackDamage
3. 填充数据：
   - SkillId: 每个棋子的技能ID
   - SkillId2: 每个棋子的大招ID
   - InitBuffIds: 初始Buff列表（逗号分隔）
   - NormalAttackDamage: 普攻伤害基础值
4. 运行 DataTableGenerator
5. 验证生成的 ChessTable.cs
```

### 2.2 SkillTable 修复

**问题清单**：
```
[P0] 某些 SkillId 重复或缺失（编译错误）
[P1] EffectId 引用不存在
[P1] 缺少 TargetType 字段（目标选择）
[P1] CastRange 范围参数错误
[P2] DamageType 与 BaseDamage 不匹配
```

**修复步骤**：
```
1. 打开 AAAGameData/DataTables/SkillTable.xlsx
2. 检查 ID 列：确保无重复、无间隙
3. 添加/修正字段：
   - TargetType: 1-8（选择器类型）
   - EffectId: 对应特效ID
   - DamageType: 物伤/法伤/真伤
   - BaseDamage: 伤害基础值
4. 验证引用：
   - EffectId → EffectTable
   - TargetType → 有效范围
5. 运行 DataTableGenerator
```

### 2.3 BuffTable 修复

**问题清单**：
```
[P1] ID 重复导致覆盖
[P1] EffectType 无效值
[P2] Duration 超出合理范围（0 或 > 1000）
[P2] Value 与 EffectType 不匹配
[P1] 缺少 Icon 字段
```

**修复步骤**：
```
1. 打开 AAAGameData/DataTables/BuffTable.xlsx
2. 检查 ID 列：无重复、无间隙
3. 清理数据：
   - 删除重复ID
   - 修正 EffectType 值（1-10 范围内）
   - 调整 Duration：1-100（回合数）
   - 验证 Value 范围：-100 到 +500
4. 添加缺失列：Icon（Buff图标路径）
5. 运行 DataTableGenerator
```

### 2.4 其他配置表修复

## 三、验证步骤

### 3.1 编译验证

```
✅ 步骤 1：打开 Unity
✅ 步骤 2：运行 DataTableGenerator（菜单 GameFramework → DataTable → Generate）
✅ 步骤 3：等待生成完成
✅ 步骤 4：检查 Console 是否有错误
✅ 步骤 5：如有错误，回到 Excel 修复，重新运行
```

**错误排查**：
```
错误：Duplicate key 'xxx'
→ 在Excel中查找重复ID，删除或修改

错误：Column not found 'xxx'
→ 生成的代码引用了不存在的列，检查 .xlsx

错误：Invalid enum value
→ 某列的值不在预定义的枚举范围内
```

### 3.2 运行时验证

```csharp
// 验证表数据
void ValidateConfigTables()
{
    // 检查ChessTable
    var chessTable = ChessTable.Instance;
    foreach (var config in chessTable.GetAll())
    {
        if (config.SkillId == 0)
            DebugEx.Error("ConfigTable", $"棋子 {config.ChessId} 缺少 SkillId");
        if (string.IsNullOrEmpty(config.Name))
            DebugEx.Error("ConfigTable", $"棋子 {config.ChessId} 缺少名称");
    }

    // 检查SkillTable
    var skillTable = SkillTable.Instance;
    foreach (var config in skillTable.GetAll())
    {
        if (config.BaseDamage < 0)
            DebugEx.Warning("ConfigTable", $"技能 {config.SkillId} 伤害为负数");
    }

    DebugEx.Success("ConfigTable", "✅ 配置表验证完成");
}
```

## 四、常见修复模式

### 4.1 新增字段

```excel
修复前：
| ID | Name | ATK |
|----|------|-----|
| 1  | 剑  | 100 |

修复后：
| ID | Name | ATK | SkillId | SkillId2 |
|----|------|-----|---------|----------|
| 1  | 剑  | 100 | 101     | 102      |

执行：
1. 在Excel添加新列
2. 填充数据
3. 重新运行 DataTableGenerator
4. 在代码中使用新字段：config.SkillId
```

### 4.2 数据合并

```excel
修复前（表1）：
| ChessId | SkillId |
|---------|---------|
| 1       | 101     |

修复前（表2）：
| ChessId | SkillId2 |
|---------|----------|
| 1       | 102      |

修复后（合并）：
| ChessId | SkillId | SkillId2 |
|---------|---------|----------|
| 1       | 101     | 102      |

执行：
1. 在 ChessTable 中添加 SkillId2 列
2. 从 SkillTable2 复制数据
3. 删除 SkillTable2（或保存备份）
```

### 4.3 ID 重映射

```excel
修复前（ID混乱）：
| ID | Name |
|----|------|
| 1  | Buff1 |
| 3  | Buff2 |（缺少2）
| 5  | Buff3 |（缺少4）

修复后（ID连续）：
| ID | Name |
|----|------|
| 1  | Buff1 |
| 2  | Buff2 |
| 3  | Buff3 |

执行：
1. 删除ID间隙
2. 更新所有引用该ID的表
3. 重新运行 DataTableGenerator
```

```

  ID: 序号式 (1, 2, 3...)

SkillTable:

  ID: 序号式 (1001, 1002...)
```

```
ChessTable:
```

## 七、常见问题解答

### Q：修改Excel后游戏没有生效？
A：需要重新运行DataTableGenerator，生成新的.bytes文件。旧的二进制数据不会自动更新。

### Q：如何添加新的配置表？
A：
1. 在AAAGameData/DataTables/中创建新Excel
2. 按照现有表格格式设计
3. 在DataTableGenerator配置中添加该表
4. 运行生成即可

### Q：ID重复了怎么办？
A：
1. 在Excel中找到重复ID
2. 修改其中一个为新ID
3. 找到所有引用该ID的表并更新
4. 重新运行DataTableGenerator

### Q：数据引用错误怎么调试？
A：添加验证代码，在运行时检查所有引用是否存在

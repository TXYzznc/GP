# 宝物系统数据持久化方案

## 概述

宝物系统的数据（`TreasureInstanceData` 列表和 `ChessEquipmentSlots` 字典）需要持久化保存到玩家存档中，并在游戏加载时恢复。

---

## 📋 任务清单

### 任务 1: 数据序列化方案设计

#### 问题分析
目前 `PlayerSaveData` 中有：
```csharp
public List<TreasureInstanceData> Treasures;  // 包含嵌套的 AffixData 列表
public Dictionary<int, List<int>> ChessEquipmentSlots;  // 字典
```

**JSON 序列化的挑战：**
1. `Dictionary<int, List<int>>` 在 `JsonUtility` 中不直接支持，需要包装类
2. `List<TreasureInstanceData>` 和嵌套的 `List<AffixData>` 需要用 `ListWrapper` 包装
3. 时机：何时触发 JSON 序列化

#### 解决方案

**步骤 1: 创建序列化包装类**

在 `PlayerAccountData.cs` 中添加（在末尾添加）：

```csharp
/// <summary>
/// 用于 JSON 序列化的宝物列表包装类
/// </summary>
[Serializable]
public class SerializedTreasureList
{
    public List<TreasureInstanceData> Items = new();
}

/// <summary>
/// 用于 JSON 序列化的装备槽包装类（将 Dictionary 转换为列表）
/// </summary>
[Serializable]
public class SerializedChessEquipmentSlot
{
    public int ChessId;
    public List<int> InstanceIds = new();
}

[Serializable]
public class SerializedChessEquipmentSlots
{
    public List<SerializedChessEquipmentSlot> Slots = new();
}
```

**步骤 2: 在 `PlayerSaveData` 中添加 JSON 存储字段**

```csharp
public class PlayerSaveData
{
    // ... 现有字段 ...
    
    // 宝物系统
    [System.NonSerialized]
    public List<TreasureInstanceData> Treasures;  // 运行时数据，不直接序列化
    
    [System.NonSerialized]
    public Dictionary<int, List<int>> ChessEquipmentSlots;  // 运行时数据，不直接序列化
    
    /// <summary>
    /// 宝物数据 JSON 字符串（用于实际存储）
    /// </summary>
    public string TreasureData = "";
    
    /// <summary>
    /// 装备槽数据 JSON 字符串（用于实际存储）
    /// </summary>
    public string ChessEquipmentData = "";
}
```

### 任务 2: 存档加载时恢复宝物数据

**位置：** `PlayerAccountDataManager.cs` 的 `LoadSaveData()` 方法（或类似的加载方法）

**逻辑：**

```csharp
private void LoadTreasureData(PlayerSaveData saveData)
{
    if (saveData == null) return;

    // 1. 恢复宝物列表
    if (!string.IsNullOrEmpty(saveData.TreasureData))
    {
        try
        {
            var treasureList = JsonUtility.FromJson<SerializedTreasureList>(saveData.TreasureData);
            saveData.Treasures = treasureList.Items ?? new List<TreasureInstanceData>();
        }
        catch
        {
            DebugEx.Error("PlayerAccountDataManager", "加载宝物数据失败，初始化为空列表");
            saveData.Treasures = new List<TreasureInstanceData>();
        }
    }
    else
    {
        saveData.Treasures = new List<TreasureInstanceData>();
    }

    // 2. 恢复装备槽数据
    if (!string.IsNullOrEmpty(saveData.ChessEquipmentData))
    {
        try
        {
            var equipmentSlots = JsonUtility.FromJson<SerializedChessEquipmentSlots>(saveData.ChessEquipmentData);
            saveData.ChessEquipmentSlots = new Dictionary<int, List<int>>();
            
            foreach (var slot in equipmentSlots.Slots)
            {
                saveData.ChessEquipmentSlots[slot.ChessId] = slot.InstanceIds ?? new List<int>();
            }
        }
        catch
        {
            DebugEx.Error("PlayerAccountDataManager", "加载装备槽数据失败，初始化为空字典");
            saveData.ChessEquipmentSlots = new Dictionary<int, List<int>>();
        }
    }
    else
    {
        saveData.ChessEquipmentSlots = new Dictionary<int, List<int>>();
    }
}
```

**集成点：** 在 `LoadSaveData()` 中调用：
```csharp
public PlayerSaveData LoadSaveData(...)
{
    var saveData = /* 从 JSON 加载 */;
    // ... 其他数据加载 ...
    LoadTreasureData(saveData);  // <- 添加这一行
    return saveData;
}
```

### 任务 3: 存档保存时序列化宝物数据

**位置：** `PlayerAccountDataManager.cs` 的 `SaveSaveData()` 方法（或类似的保存方法）

**逻辑：**

```csharp
private void SaveTreasureData(PlayerSaveData saveData)
{
    if (saveData == null) return;

    // 1. 序列化宝物列表
    if (saveData.Treasures != null && saveData.Treasures.Count > 0)
    {
        try
        {
            var treasureList = new SerializedTreasureList { Items = saveData.Treasures };
            saveData.TreasureData = JsonUtility.ToJson(treasureList, true);
        }
        catch
        {
            DebugEx.Error("PlayerAccountDataManager", "序列化宝物数据失败");
            saveData.TreasureData = "";
        }
    }
    else
    {
        saveData.TreasureData = "";
    }

    // 2. 序列化装备槽数据
    if (saveData.ChessEquipmentSlots != null && saveData.ChessEquipmentSlots.Count > 0)
    {
        try
        {
            var equipmentSlots = new SerializedChessEquipmentSlots();
            foreach (var kvp in saveData.ChessEquipmentSlots)
            {
                equipmentSlots.Slots.Add(new SerializedChessEquipmentSlot
                {
                    ChessId = kvp.Key,
                    InstanceIds = kvp.Value
                });
            }
            saveData.ChessEquipmentData = JsonUtility.ToJson(equipmentSlots, true);
        }
        catch
        {
            DebugEx.Error("PlayerAccountDataManager", "序列化装备槽数据失败");
            saveData.ChessEquipmentData = "";
        }
    }
    else
    {
        saveData.ChessEquipmentData = "";
    }
}
```

**集成点：** 在 `SaveSaveData()` 中调用：
```csharp
public void SaveSaveData(...)
{
    // ... 其他数据保存 ...
    SaveTreasureData(m_CurrentSaveData);  // <- 添加这一行
    
    // 最后保存到文件
    var json = JsonUtility.ToJson(m_CurrentSaveData, true);
    File.WriteAllText(savePath, json);
}
```

## 📌 关键细节

1. **序列化包装类的必要性** - `JsonUtility` 不支持 `Dictionary`，必须转换为列表再序列化
2. **NonSerialized 属性** - `Treasures` 和 `ChessEquipmentSlots` 是运行时数据，不直接序列化，而是通过 JSON 字符串字段存储
3. **加载时机** - 必须在 `LoadSaveData()` 完成后调用 `LoadTreasureData()` 恢复数据
4. **保存时机** - 建议每次操作后立即保存（可选：后期可改为周期性保存优化性能）
5. **错误处理** - 加载失败时初始化空列表，保证游戏不会因为损坏的存档而崩溃

## 📝 实现顺序建议

1. **先做任务 2** (LoadTreasureData) - 确保加载逻辑正确
2. **再做任务 3** (SaveTreasureData) - 确保保存逻辑正确
3. **再做任务 4** (InitializeTreasureData) - 处理新存档
4. **最后做任务 5** (SaveCurrentSaveData 集成) - 在操作方法中调用保存

这样可以逐步验证每个部分的正确性。

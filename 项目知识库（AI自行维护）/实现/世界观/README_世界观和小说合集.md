## 🌍 世界观核心要素

### 地理与政治格局

| 区域 | 属性 | 代表势力 | 特征 |
|------|------|---------|------|
| **北方** | 光明堡垒 | 天庭遗迹 + 大禹 | 秩序与规律 |
| **西方** | 光明圣地 | 西方圣殿 | 救赎与守护 |
| **南方** | 火焰文明 | 南火朝代 | 力量与热烈 |
| **东方** | 月光之地 | 东月塔 + 嫦娥 | 智慧与循环 |
| **中心** | 人类文明 | 中原净土 | 希望的摇篮 |

### 核心角色群

**光明阵营**：
- 后羿 - 东方弓手，日轮守护者
- 嫦娥 - 月宫使者，生命循环象征
- 林晓雨 - 年轻召唤师，星辰之子

**黑暗势力**：
- 虚无之力 - 黑暗源头，无形意识
- 黑暗杨戬 - 堕落神祇，最强武器
- 邪灵与恶魂 - 被污染的生命

**中立与灰色势力**：
- 商队与商人 - 在两极间求生存
- 普通人类 - 战争的承受者与见证者
- 被拯救的邪灵 - 新秩序的参与者

### 核心主题

1. **光与暗的相对性** - 没有绝对善恶，只有选择与坚持
2. **个人力量与集体抗争** - 单个英雄无法改变世界
3. **救赎的可能性** - 即使堕落，仍可被拯救
4. **循环与重生** - 破坏后才能重建
5. **选择的力量** - 未来由无数个选择决定

## 📖 小说特色

### 叙事风格

- **多视角交错叙述** - 每章从不同角色视角讲述
- **非线性时间线** - 时间在各章跳跃，最终汇聚
- **象征主义富厚** - 光、暗、月、星等元素多重含义
- **内心独白深入** - 角色的思想、矛盾、选择得以展现
- **细节刻画真实** - 通过细节营造世界的可信度

### 叙事技巧

1. **伏笔与回应** - 第一章的后羿之箭，在第九章黑暗杨戬的回应
2. **多层含义** - 每个事件都有表面含义和深层含义
3. **因果链条** - 每个人的选择都会影响他人
4. **开放式结局** - 提供多种解读空间

### 非连续性结构的优势

- 避免单一叙述的限制
- 展现不同阶层的经历
- 突出个人选择的重要性
- 创造网状而非线性的因果关系
- 允许读者从多个角度理解世界

# 技能目标选择不一致问题诊断与修复

## 问题表现

敌人棋子（邪灵）表现出奇怪的行为：
1. AI 锁定目标是**召唑师棋子**（朝其移动）
2. 但释放大招时，法阵生成在**嫦娥棋子**位置
3. 到达召唑师附近后，开始攻击时又切换目标回到**嫦娥棋子**
4. 然后再次朝嫦娥棋子移动

从测试日志对比：
```
[14:39:32.561] [Log] [FSMMeleeAI] 邪灵 找到目标: 召唤师-狂战士
[14:39:32.561] [Log] [FSMMeleeAI] 邪灵 决策: 使用技能
[14:39:32.577] [Log] [ChessCombatController] 邪灵 释放大招

[14:39:32.917] [Log] [EvilSpiritUltimate] 腐蚀法阵已生成: center=(16.51, 19.48, -3.57), radius=4
  └─ 这是嫦娥的位置！不是召唑师的位置
```

## 根本原因

### 代码分析

**文件**：`Assets/AAAGame/Scripts/Game/SummonChess/Chess/邪灵/EvilSpiritUltimate.cs`  
**行数**：第56行

```csharp
// ❌ 错误做法：重新查找最近的敌人，不使用 AI 的锁定目标
ChessEntity targetEnemy = FindNearestEnemy(caster);
```

**问题过程**：

```
时间轴：
├─ T1: AI 索敌（距离权重为0.3）
│  └─ 召唑师 17m 远 → 得分 25.20
│  └─ 嫦娥 8m 远  → 得分 18.00
│  └─ 选择目标：召唑师 ✓
│
├─ T2: AI 决策使用大招
│  └─ 记录 m_CurrentTarget = 召唑师
│
├─ T3: 释放大招，EvilSpiritUltimate.ExecuteSkill()
│  └─ 调用 FindNearestEnemy() 重新查找
│     ├─ 此时 AI 已经朝召唑师移动了几帧
│     ├─ 距离变化：
│     │  ├─ AI 位置 ≈ (14.0, 20.0, -15.0)
│     │  ├─ 召唑师  ≈ (7.7, 20.6, -11.9)  → 距离 ≈ 7-8m
│     │  ├─ 嫦娥    ≈ (16.5, 19.5, -3.6)  → 距离 ≈ 13-14m
│     │  └─ 最近的是嫦娥（因为移动后相对位置变化）
│  └─ ❌ 选择了嫦娥作为技能目标
│
└─ T4: AI 从 UsingSkill 返回
   └─ m_CurrentTarget 仍是召唑师
   └─ 但法阵已经生成在嫦娥位置了
   └─ 造成视觉上的混乱
```

### 为什么会出现这种情况

1. **距离评分不同**
   - AI 索敌使用加权评分：距离权重 0.3 + 血量权重 0.5 + 威胁度权重 0.2
   - FindNearestEnemy() 仅按直线距离排序

2. **时序问题**
   - 决策时 AI 在地图上游，敌人分布较散
   - 释放时 AI 已经移动了数米，相对距离改变

3. **缺乏一致性**
   - 技能不应该重新评估目标
   - 应该使用 AI 已经决定的目标

## 解决方案

### 修改 1：在 ChessAIBase 中暴露当前目标

**文件**：`Assets/AAAGame/Scripts/Game/SummonChess/AI/FSM/ChessAIBase.cs`

添加公共属性：

```csharp
#region 属性

/// <summary>
/// 获取当前锁定的目标（供技能和外部系统查询）
/// </summary>
public ChessEntity CurrentTarget => m_CurrentTarget;

#endregion
```

### 修改 2：技能使用 AI 的目标

**文件**：`Assets/AAAGame/Scripts/Game/SummonChess/Chess/邪灵/EvilSpiritUltimate.cs`

修改 `CreateMagicCircleAsync()` 方法：

```csharp
// ⭐ 使用 AI 已锁定的目标，而非重新查找
// 这样能确保技能和移动目标保持一致
var aiBase = caster.CombatController?.AI as ChessAIBase;
ChessEntity targetEnemy = aiBase?.CurrentTarget;
if (targetEnemy == null)
{
    // 如果 AI 没有目标，再尝试查找最近的敌人
    targetEnemy = FindNearestEnemy(caster);
}
```

## 扩展建议

### 1. 其他技能也可能有同样问题

检查其他技能文件，看是否也在调用 `FindNearestEnemy()`：

```bash
grep -r "FindNearestEnemy" Assets/AAAGame/Scripts/Game/SummonChess/Chess/
```

### 2. 统一技能的目标选择接口

可以在 `ChessSkillBase` 中添加一个标准方法：

```csharp
protected ChessEntity GetSkillTarget(ChessEntity caster)
{
    var aiBase = caster.CombatController?.AI as ChessAIBase;
    return aiBase?.CurrentTarget ?? FindNearestEnemy(caster);
}
```

然后所有技能都调用 `GetSkillTarget()` 而非直接 `FindNearestEnemy()`。

### 3. 技能类应该记住决策时的目标

可以在 `ChessSkillBase.TryCast()` 时记录目标：

```csharp
protected ChessEntity m_CachedTarget;

public virtual bool TryCast()
{
    if (!base.TryCast()) return false;
    
    // 记住技能决策时的目标
    var aiBase = m_Context.AI as ChessAIBase;
    m_CachedTarget = aiBase?.CurrentTarget;
    
    return true;
}
```

然后 `ExecuteSkill()` 就使用 `m_CachedTarget`。

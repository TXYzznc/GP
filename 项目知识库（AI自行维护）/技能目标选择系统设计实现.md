# 技能目标选择系统设计实现

> 最后更新：2026-05-07
> 状态：已完成
> 范围：多样化技能目标选择（棋子、区域、方向）

## 背景与需求

### 问题
原先所有技能都使用普攻目标，导致无法实现以下需求：
- 区域型大招需要选择"敌人最密集的位置"而不是单个目标
- 方向型大招需要锁定方向而不是位置
- 自我型技能无需目标
- 不同技能有不同的优先级策略

### 设计原则
- **灵活性**：每个技能可自定义目标选择策略
- **简洁性**：不创建新脚本，扩展现有接口
- **一致性**：普攻目标和技能目标分离，避免混乱

## 核心设计

### 1. ISkillReleaseStrategy 扩展

**新增方法**：
```csharp
public interface ISkillReleaseStrategy
{
    // ... 现有方法 ...
    
    /// <summary>
    /// 为技能选择目标
    /// </summary>
    /// <param name="skillIndex">技能索引（1或2）</param>
    /// <returns>
    /// - ChessEntity：锁定的目标棋子
    /// - null：不需要锁定目标（自我技能、全体技能、位置策略）
    /// </returns>
    ChessEntity SelectSkillTarget(int skillIndex);
}
```

**职责**：
- 技能1和大招可以有不同的目标选择策略
- 允许返回 null（技能自己处理位置选择）
- 由各棋子的专用策略类实现

### 2. ChessTargetFinder 扩展

**新增工具方法**：

#### FindBestStateEnemy - 综合状态最好的敌人
```csharp
/// 综合状态 = (当前HP / 最大HP) + (当前MP / 最大MP)
/// 分数越高 = 能力越强
public static ChessEntity FindBestStateEnemy(ChessEntity self)
```

**应用场景**：
- 后羿大招：锁定综合状态最好的敌人

#### FindMostDensePosition - 敌人最密集的位置
```csharp
/// 计算所有敌人的质心（XZ平面）
/// 返回敌人最聚集的位置
public static Vector3 FindMostDensePosition(ChessEntity self, float searchRadius)
```

**应用场景**：
- 嫦娥大招、邪灵大招：选择范围内最密集的位置

```csharp
/// 计算从 self 指向 target 的单位方向向量
public static Vector3 GetDirectionToTarget(ChessEntity self, ChessEntity target)
```

**应用场景**：
- 恶魂大招：确定冲击方向

### 3. ChessAIBase 改进

#### 区分两个目标

**字段**：
```csharp
/// <summary>当前普攻目标（在 Idle 状态确定）</summary>
protected ChessEntity m_CurrentTarget;

/// <summary>当前技能目标（由技能释放策略确定）</summary>
protected ChessEntity m_SkillTarget;
```

**属性**：
```csharp
public ChessEntity CurrentTarget => m_CurrentTarget;  // 普攻目标
public ChessEntity SkillTarget => m_SkillTarget;      // 技能目标
```

#### Idle 状态选择技能目标

```csharp
protected virtual void TickIdle(float dt)
{
    // ... 搜索普攻目标 ...
    
    if (m_CurrentTarget != null)
    {
        if (ShouldUseSkill())
        {
            // ⭐ 让技能释放策略选择技能目标
            m_SkillTarget = m_SkillStrategy.SelectSkillTarget(m_PendingSkillIndex);
            
            DebugEx.Log(GetType().Name,
                $"决策: 使用技能{m_PendingSkillIndex}, 目标={m_SkillTarget?.Config?.Name ?? "null"}");
            ChangeState(ChessAIState.UsingSkill);
            return;
        }
        // ... 其他优先级 ...
    }
}
```

#### Moving 中检查技能条件

```csharp
protected override void TickMoving(float dt)
{
    // ... 目标有效性检查 ...
    
    // ⭐ 在 Moving 中检查技能条件（满足则立即回到 Idle）
    if (CanMakeSkillDecision() && ShouldUseSkill())
    {
        ChangeState(ChessAIState.Idle);
        return;
    }
    
    // ... 其他逻辑 ...
}
```

#### UsingSkill 状态使用技能目标

```csharp
protected virtual void TickUsingSkill(float dt)
{
    // ⭐ 检查技能目标死亡（未开始释放时中断）
    if (m_SkillTarget != null && m_SkillTarget.Attribute.IsDead)
    {
        if (!m_IsUsingSkill)
        {
            ChangeState(ChessAIState.Idle);
            return;
        }
    }
    
    if (!m_IsUsingSkill)
    {
        // ⭐ 使用技能目标检查范围
        if (m_SkillTarget != null && !IsSkillInRange(m_PendingSkillIndex, m_SkillTarget))
        {
            ChangeState(ChessAIState.Moving);
            return;
        }
        
        // 面向技能目标或普攻目标
        FaceTarget(m_SkillTarget ?? m_CurrentTarget);
        
        // 触发技能释放
        if (m_PendingSkillIndex == 2)
            m_Context.Entity.CombatController?.TriggerSkill2FromAI();
        else if (m_PendingSkillIndex == 1)
            m_Context.Entity.CombatController?.TriggerSkill1FromAI();
        
        m_IsUsingSkill = true;
    }
}
```

#### 状态退出清理

```csharp
protected virtual void OnExitState(ChessAIState state)
{
    // ...
    case ChessAIState.UsingSkill:
        m_IsUsingSkill = false;
        m_ShouldUseSkillAfterAttack = false;
        m_PendingSkillIndex = 0;
        m_SkillTarget = null;  // ⭐ 清除技能目标
        break;
}
```

## 具体实现

### DefaultSkillReleaseStrategy 扩展

所有棋子的策略都继承自 DefaultSkillReleaseStrategy，在此实现默认行为：

```csharp
public class DefaultSkillReleaseStrategy : ISkillReleaseStrategy
{
    public virtual ChessEntity SelectSkillTarget(int skillIndex)
    {
        // 默认策略：所有技能都使用普攻目标
        if (m_Context == null || m_Context.Entity == null)
            return null;

        var aiBase = m_Context.Entity.AI as ChessAIBase;
        return aiBase != null ? aiBase.CurrentTarget : null;
    }
}
```

### 各棋子的技能释放策略

#### 1. 后羿 - HouyiSkillReleaseStrategy

**技能1（神力）**：自我技能 → `return null`  
**大招（分裂箭）**：综合状态最好的敌人

```csharp
public class HouyiSkillReleaseStrategy : DefaultSkillReleaseStrategy
{
    public override ChessEntity SelectSkillTarget(int skillIndex)
    {
        if (m_Context?.Entity == null)
            return null;

        return skillIndex switch
        {
            1 => null,  // 技能1：自我技能
            2 => ChessTargetFinder.FindBestStateEnemy(m_Context.Entity),  // 大招
            _ => null,
        };
    }
}
```

#### 2. 嫦娥 - ChangeSkillReleaseStrategy

**技能1（传送）**：当前普攻目标  
**大招（冰冻）**：敌人最密集位置（返回 null，让技能自己处理）

```csharp
public class ChangeSkillReleaseStrategy : DefaultSkillReleaseStrategy
{
    public override ChessEntity SelectSkillTarget(int skillIndex)
    {
        if (m_Context?.Entity == null)
            return null;

        switch (skillIndex)
        {
            case 1:
                // 技能1：当前普攻目标
                var aiBase = m_Context.Entity.AI as ChessAIBase;
                return aiBase?.CurrentTarget;

            case 2:
                // 大招：返回 null，让技能使用 FindMostDensePosition
                return null;

            default:
                return null;
        }
    }
}
```

#### 3. 邪灵 - EvilSpiritSkillReleaseStrategy

**技能1（腐蚀箭）**：当前普攻目标  
**大招（腐蚀法阵）**：敌人最密集位置

```csharp
public class EvilSpiritSkillReleaseStrategy : DefaultSkillReleaseStrategy
{
    public override ChessEntity SelectSkillTarget(int skillIndex)
    {
        if (m_Context?.Entity == null)
            return null;

        switch (skillIndex)
        {
            case 1:
                var aiBase = m_Context.Entity.AI as ChessAIBase;
                return aiBase?.CurrentTarget;

            case 2:
                return null;  // 让技能自己处理位置

            default:
                return null;
        }
    }
}
```

#### 4. 恶魂 - EvilSoulSkillReleaseStrategy

**技能1（暗影斩）**：当前普攻目标  
**大招（暗影冲击）**：当前普攻目标（用来确定冲击方向）

```csharp
public class EvilSoulSkillReleaseStrategy : DefaultSkillReleaseStrategy
{
    public override ChessEntity SelectSkillTarget(int skillIndex)
    {
        if (m_Context?.Entity == null)
            return null;

        // 两个技能都使用普攻目标（大招用它来确定方向）
        var aiBase = m_Context.Entity.AI as ChessAIBase;
        return aiBase?.CurrentTarget;
    }
}
```

## 技能代码中的使用

### 示例：EvilSpiritUltimate（邪灵大招）

```csharp
private async UniTaskVoid CreateMagicCircleAsync(ChessEntity caster)
{
    if (caster == null || caster.CurrentState == ChessState.Dead)
        return;

    var aiBase = caster.AI as ChessAIBase;

    // 获取法阵位置：有具体目标则用目标位置，否则用最密集位置
    Vector3 targetPosition;
    if (aiBase != null && aiBase.SkillTarget != null)
    {
        targetPosition = aiBase.SkillTarget.transform.position;
    }
    else
    {
        // 使用最密集位置策略（半径 = 施法范围 + 4）
        targetPosition = ChessTargetFinder.FindMostDensePosition(
            caster,
            (float)m_Config.CastRange + 4f
        );
    }

    // ... 加载预制体，生成法阵 ...
}
```

### 示例：EvilSoulUltimate（恶魂大招 - 方向型）

```csharp
public override void ExecuteSkill(ChessEntity caster)
{
    var aiBase = caster.AI as ChessAIBase;
    var skillTarget = aiBase?.SkillTarget;

    // 获取冲击方向
    Vector3 direction = Vector3.forward;
    if (skillTarget != null)
    {
        direction = ChessTargetFinder.GetDirectionToTarget(caster, skillTarget);
    }

    // 在 direction 前方释放范围伤害
    ExecuteDamage(caster, direction);
}
```

## 流程图

### 决策流程

```
Idle 状态
├─ 搜索普攻目标 (m_CurrentTarget)
└─ 优先级1：应该使用技能？
   ├─ 调用 SelectSkillTarget(skillIndex)
   ├─ 获得技能目标 (m_SkillTarget)
   └─ ChangeState(UsingSkill)

或：优先级3：需要移动
├─ ChangeState(Moving)

Moving 状态
├─ 检查技能条件 (每帧)
├─ 满足技能条件？
│  └─ ChangeState(Idle) ← 回到决策
└─ 否则继续移动

UsingSkill 状态
├─ 检查技能目标死亡
├─ 检查是否在施法范围内 (用 m_SkillTarget)
├─ 面向技能目标或普攻目标
├─ 触发技能释放
└─ 等待 AnimEvent_AnimationComplete
   └─ OnSkillComplete() 回调
      └─ ChangeState(Idle)
```

## 时间轴示例：邪灵释放大招

```

├─ m_CurrentTarget = 嫦娥棋子
└─ ShouldUseSkill() = true

T1: SelectSkillTarget(2) 执行
├─ EvilSpiritSkillReleaseStrategy.SelectSkillTarget(2) 返回 null
│  └─ 表示使用"位置策略"而不是"目标棋子"
├─ m_SkillTarget = null
└─ ChangeState(UsingSkill)

T2: UsingSkill 状态
├─ m_SkillTarget == null（不检查范围）

│  └─ targetPosition = FindMostDensePosition()
│     └─ 选择半径(施法范围+4)内的敌人质心
└─ 在该位置生成法阵

T3: 技能动画播放中...

T4: AnimEvent_AnimationComplete 回调
└─ ChangeState(Idle)
```

## 扩展建议

### 新增技能的步骤

如果需要添加新的棋子或修改现有技能的目标策略：

1. **创建策略类**（如无需自定义则继承 DefaultSkillReleaseStrategy）
   ```csharp
   public class NewChessSkillReleaseStrategy : DefaultSkillReleaseStrategy
   {
       public override ChessEntity SelectSkillTarget(int skillIndex)
       {
           // 实现你的逻辑
       }
   }
   ```

2. **在 ChessFactory 注册**
   ```csharp
   public static void RegisterAllSkillStrategies()
   {
       RegisterSkillStrategy(棋子ID, typeof(NewChessSkillReleaseStrategy));
   }
   ```

3. **在技能代码中使用**
   ```csharp
   var aiBase = caster.AI as ChessAIBase;
   var skillTarget = aiBase?.SkillTarget;
   // 使用 skillTarget 或位置策略
   ```

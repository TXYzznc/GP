**右侧：核心代码（仅最关键6行，大字号代码风格）**
```csharp
// ② 缓存目标，播放动画
m_PendingAttackTarget = target;
m_Entity.Animator.PlayAttack();

// ③ 动画命中帧回调
void OnAttackExecute() {
    m_Entity.NormalAttack
        .ExecuteAttack(m_Entity, m_PendingAttackTarget);
}
```

右下角标注：`攻击缓存 → 动画期间目标安全`

### Notes
战斗界面集成了棋子血条、Buff图标列表、伤害飘字、策略卡手牌和召唤师状态条。核心实现机制是攻击缓存——AI决策时将目标缓存到m_PendingAttackTarget，然后播放攻击动画。动画在命中帧触发OnAttackExecute回调，此时才从缓存读取目标执行实际攻击。这样即使动画播放期间目标死亡或移动，逻辑也不会出错。全部异步流程通过UniTask管理。

Animator状态机：

    ↓

### Notes
动画系统是战斗逻辑与视觉表现同步的关键。Animator Controller包含7个状态：Idle和Move使用BlendTree按Speed参数平滑混合；Attack、Skill1、Skill2在动画的40%到60%位置添加Animation Event，事件触发时回调ChessCombatController执行实际攻击或技能逻辑。这种设计确保了伤害判定不会提前或延迟——只有动画播放到武器挥到的那一帧，伤害才真正生效。Hit状态用于受击反馈，Death状态触发溶解着色器效果。

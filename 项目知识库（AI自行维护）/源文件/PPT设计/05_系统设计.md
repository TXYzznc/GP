**上半部分：事件通信示意图**
```
[CombatManager]              [InventoryUI]

     │ Fire(CombatEndEventArgs)   │ Subscribe
     │                            │
     └──────── EventBus ──────────┘
```

**下半部分：核心事件类型表（精选6-8个）**

| 事件类名 | 触发时机 | 主要订阅方 |
|---------|---------|-----------|
| CombatStartEventArgs | 战斗开始 | CombatUI, BuffManager |

### 演讲要点

- Fire vs FireNow 两种触发模式

## 页面4-8：AI决策 + 伤害计算

### 标题
`AI决策系统 & 伤害计算公式`

### 内容布局：左右分栏

**左栏：AI决策流程图（论文图4.9简化版）**
```
每帧Tick
    │
    ├─→ 目标搜索（距离最近的存活敌人）
    │         │
    │         ├─ 无目标 → 待机
    │         │
    │         ▼ 有目标
    ├─→ 冷却检查
    │         │
    │         ├─ 冷却中 → 向目标移动
    │         │
    │         ▼ 冷却完毕
    └─→ 距离判断
              │
              ├─ 超出范围 → 移动靠近
              │
              ▼ 在范围内
          执行攻击（缓存目标+伤害）
```

- 三种AI类型：MeleeAI / RangedAI / SupportAI

**右栏：伤害计算公式**

核心公式（大字展示）：
```
减伤率 = 防御力 / (防御力 + 100)
最终伤害 = 基础伤害 × 暴击倍率 × Buff修正 × (1 - 减伤率)
```

伤害类型：
- 物理伤害：受防御力减伤
- 魔法伤害：受魔法抗性减伤
- 真实伤害：无视防御，直接扣血

底部数据：**11套伤害计算公式**

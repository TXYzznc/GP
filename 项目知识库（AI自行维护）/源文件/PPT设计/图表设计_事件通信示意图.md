## 图表内容设计

### 整体布局：三栏式（左发布者 → 中EventBus → 右订阅者）

```
┌─────────────────────┐                                  ┌─────────────────────┐
│    游戏状态层         │                                  │    UI 表现层          │
│                     │                                  │                     │
│  OutOfGameState     ─┼── Fire ──┐                ┌── Subscribe ─┼→ GamePlayInfoUI  │
│  InGameState        ─┼── Fire ──┤                ├── Subscribe ─┼→ CombatUI        │
│  ExplorationState   ─┼── Fire ──┤                ├── Subscribe ─┼→ PlayerSkillUI   │
│  CombatState        ─┼── Fire ──┤                ├── Subscribe ─┼→ CurrencyUI      │
│                     │           │                │              │→ StarPhoneUI     │
├─────────────────────┤           │  ┌──────────┐  │              │→ OutsiderFuncUI  │
│    战斗系统层         │           │  │          │  │              ├─────────────────────┤
│                     │           ├─→│ GF.Event │─→┤              │    业务逻辑层        │
│  CombatManager      ─┼── Fire ──┤  │          │  │              │                     │
│  ChessManager       ─┼── Fire ──┤  │ 发布-订阅 │  ├── Subscribe ─┼→ CombatPrepState   │
│                     │           │  │  解耦通信 │  ├── Subscribe ─┼→ EnemyEntityMgr    │
├─────────────────────┤           │  │          │  ├── Subscribe ─┼→ CombatOpDetector  │
│    数据管理层         │           │  └──────────┘  │              ├─────────────────────┤
│                     │           │                │              │    框架层            │
│  PlayerDataModel    ─┼── Fire ──┤                │              │                     │
│  PlayerAccountMgr   ─┼── Fire ──┘                └── Subscribe ─┼→ DataModelComponent │
│                     │                                           │→ InGameState       │
└─────────────────────┘                                           └─────────────────────┘
```

## 事件流分类（用颜色区分）

| 颜色 | 类别 | 事件名 | 发布者 | 主要订阅者 |
|------|------|--------|--------|-----------|
| 🔵蓝色 | 状态切换 | OutOfGameEnter/LeaveEventArgs | OutOfGameState | GamePlayInfoUI, CurrencyUI, StarPhoneUI |
| 🔵蓝色 | 状态切换 | InGameEnter/LeaveEventArgs | InGameState | GamePlayInfoUI, PlayerSkillUI, StarPhoneUI |
| 🔵蓝色 | 状态切换 | ExplorationEnter/LeaveEventArgs | ExplorationState | PlayerSkillUI, CurrencyUI, CombatOpDetector |
| 🟠橙色 | 战斗相关 | CombatEnter/LeaveEventArgs | CombatState | CombatUI, PlayerSkillUI, EnemyEntityMgr |
| 🟠橙色 | 战斗相关 | CombatEndEventArgs | CombatManager | GamePlayInfoUI, InGameState, CombatState |
| 🟠橙色 | 战斗相关 | CombatPreparationReadyEventArgs | CombatPreparationUI | CombatPreparationState |
| 🟢绿色 | 数据变化 | PlayerDataChangedEventArgs | PlayerDataModel | 运行时数据管理 |
| 🟢绿色 | 数据变化 | PlayerLevelUpEventArgs | PlayerAccountMgr | CombatUI |
| ⚫灰色 | 框架级 | GFEventArgs(ApplicationQuit) | GF.OnExitGame | DataModelComponent |

## 绘制规格

### 尺寸与比例
- **画布尺寸**：1920×1080 (16:9 PPT全屏)
- **有效绘图区**：去除标题后约 1920×900
- **三栏比例**：左35% : 中15% : 右35%（上下留白各7.5%）

### 元素样式

**发布者/订阅者模块**：
- 圆角矩形（圆角4px）
- 字号：12-14pt
- 内边距：8px

**分组框**：
- 圆角矩形（圆角8px）
- 标题在顶部居中，14pt加粗
- 内部模块竖向排列

**中间EventBus**：
- 大号竖向圆角矩形（宽约200px，高约500px）
- 深蓝底白字
- 主标题：`GF.Event` 20pt Bold
- 副标题：`发布-订阅模式` 12pt

**箭头**：
- 左→中：实线箭头，线宽2px，标注文字 `Fire`
- 中→右：虚线箭头，线宽1.5px，标注文字 `Subscribe`
- 箭头汇聚到EventBus两侧边缘

## 底部标注文字

```
核心设计原则：
• 发布者只管发布事件，不关心谁订阅
• 订阅者只管响应事件，不关心谁发布
• 15个事件类覆盖全部跨模块通信，模块间零直接调用
```

## PPT绘图工具绘制步骤

1. **画三组左侧发布者框**：游戏状态层(4个)、战斗系统层(2个)、数据管理层(2个)
2. **画中间EventBus大矩形**：深蓝底，写上 GF.Event
3. **画三组右侧订阅者框**：UI表现层(6个)、业务逻辑层(3个)、框架层(2个)
4. **连接箭头**：左→中用实线（按颜色分类），中→右用虚线
5. **添加标注**：Fire / Subscribe 文字、底部设计原则

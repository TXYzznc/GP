## 各步骤详细说明

| 步骤 | 调用关系 | 说明 |
|:---:|---------|------|
| ① | `ChessAIBase.Attack(target)` → `CombatController.TriggerAttackFromAI(target)` | AI寻到最近敌人，触发攻击 |
| ② | `CombatController` → `Animator.PlayAttack()` + 缓存 `m_PendingAttackTarget` | 缓存目标+播放攻击动画 |
| ③ | `AnimEvent_AttackExecute()` → `CombatController.OnAttackExecute()` | 动画在命中帧触发事件回调 |
| ④ | `CombatController` → `NormalAttack.ExecuteAttack(caster, target)` | 转发给具体普攻实现类 |
| ⑤ | 普攻类构建 `HitContext` → `HitDetector.Execute(context)` | 设置延迟伤害回调，启动命中检测 |
| ⑥ | `HitDetectorBase.ApplyDamage()` → `target.Attribute.TakeDamage()` | 计算减伤、护盾吸收、扣血、显示飘字 |
| ⑦ | `EffectExecutor.ApplyBuffsOnHit()` → `target.BuffManager.AddBuff()` | 配置表BuffIds命中时自动施加 |

---

## 关键设计亮点标注（PPT中高亮）

1. **攻击缓存机制**（步骤②）：`m_PendingAttackTarget` 缓存目标，避免动画播放期间目标变化
2. **动画事件驱动**（步骤③）：伤害判定与动画视觉精确同步
3. **延迟伤害计算**（步骤⑤）：`CalculateDamageCallback` 委托，投射物命中时才计算伤害
4. **配置表Buff**（步骤⑦）：`BuffIds` 字段自动应用，无需硬编码

## 绘制规格

### 尺寸
- 画布：1920×1080 (16:9)
- 有效区域：去除标题后约 1920×850

### 配色

| 元素 | 颜色 | 色值 |
|------|------|------|
| 参与者方块 | 浅蓝 | #E3F2FD |
| 参与者方块边框 | 中蓝 | #1976D2 |
| 生命线（竖线） | 灰色 | #BDBDBD |
| 调用箭头（实线） | 深蓝 | #003366 |
| 返回箭头（虚线） | 灰色 | #757575 |

| 关键步骤高亮 | 橙色 | #F57C00 |
| 步骤编号圆圈 | 蓝色 | #1976D2 |

### 元素样式

**参与者**：
- 顶部：圆角矩形（宽120px，高50px），中文名+英文类名
- 下方：竖向虚线（生命线）

**消息箭头**：
- 同步调用：实线+实心箭头
- 异步/事件：实线+开放箭头
- 自身处理：回折箭头

**动画等待**：
- 浅橙色矩形块覆盖在动画系统生命线上
- 标注"动画播放中"

**步骤编号**：
- 左侧竖列，蓝色圆圈内白色数字 ①②③④⑤⑥⑦

## PPT简化版推荐方案

考虑PPT可读性，推荐使用**简化版**（6个参与者 + 7步），不展开内部细节。关键要体现：

1. AI → 控制器 → 动画系统 的左向右调用链
2. 动画系统 → 控制器 的回调（时间跳跃，用虚线框表示"动画播放等待"）
3. 控制器 → 普攻 → 命中检测 → 目标 的右向执行链
4. 步骤编号清晰可读

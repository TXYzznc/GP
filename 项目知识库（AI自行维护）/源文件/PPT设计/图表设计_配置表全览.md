# 配置表全览图表 — 设计与绘制指南

> 用途：展示项目中全部41张配置表及其作用
> 推荐放在 Slide 34（配置表系统实现）或作为补充页

---

## 图表设计方案：分类气泡/卡片矩阵

### 设计思路

将41张配置表按所属系统分为**7大类**，使用彩色分组卡片矩阵展示。每组一个颜色，内部每张表一个小方块写表名+一句话作用。

---

## 分类与内容

### 🔴 战斗系统（10张）

### 方案B：放射状/环形图

- 中心：`DataTable系统 (41张)`
- 7条放射线连向7个分类圆圈
- 每个圆圈内列出表名
- 圆圈大小按表数量成比例

### 方案C：树状图/思维导图

- 根节点：配置表系统
- 7个一级分支（按系统分类）
- 每个分支下挂具体表名

## 推荐方案：方案A（分类色块矩阵）

理由：
- 信息密度最高，一页能容纳全部41张表
- 颜色分组直观
- 适合快速浏览

---

## 绘制规格

### 尺寸
- 画布：1920×1080 (16:9)
- 有效区：标题占80px，底部留60px

### 配色

| 分类 | 背景色 | 边框色 |
|------|--------|--------|
| 战斗系统 | #FFEBEE | #E53935 |
| 棋子成长 | #FFF3E0 | #FB8C00 |
| 物品背包 | #FFFDE7 | #FDD835 |
| 策略卡 | #E8F5E9 | #43A047 |
| 探索系统 | #E3F2FD | #1E88E5 |
| 玩家召唤师 | #F3E5F5 | #8E24AA |
| 系统资源 | #ECEFF1 | #546E7A |

### 字体
- 分类标题：14pt 微软雅黑Bold + 颜色对应边框色
- 表名：10-11pt 微软雅黑Regular #333333
- 表数量标注：分类标题后括号内

### 布局规则
- 上半部分三大列（战斗10 / 物品8 / 玩家8）占60%高度
- 下半部分四小列（棋子4 / 卡牌2 / 探索3 / 系统6）占35%高度
- 每张表一行，只写表名（不写作用描述，太挤）
- 如需作用描述，鼠标悬停或演讲时口述

# 敌人对象组件配置指南

## 敌人对象需要的组件

### 1. **必需组件**

| 组件 | 来源 | 说明 |
|------|------|------|
| **EnemyEntity** | 脚本 | 敌人实体核心组件，负责初始化和管理敌人 |
| **NavMeshAgent** | Unity 内置 | 导航网格代理，用于寻路和移动 |
| **Animator** | Unity 内置 | 动画控制器，驱动敌人动画 |
| **EnemyAnimator** | 脚本 | 敌人动画控制脚本，根据 AI 状态播放动画 |

### 2. **自动添加的组件**

以下组件会在 `EnemyEntity.Initialize()` 时自动添加（如果不存在）：

| 组件 | 说明 |
|------|------|
| **VisionConeDetector** | 视野检测器，用于检测玩家 |

### 3. **可选组件**

| 组件 | 说明 |
|------|------|
| **Rigidbody** | 如果需要物理交互 |
| **Collider** | 碰撞体，用于检测和交互 |

## 敌人对象的层级结构

```
EnemyEntity (GameObject)
├── Mesh/Model (子对象，包含 SkinnedMeshRenderer)
│   └── Armature (骨骼)
└── 其他子对象（如武器、特效等）
```

**关键点：**
- EnemyEntity 脚本挂在根对象上
- Animator 可以在根对象或子对象上（EnemyAnimator 会自动查找）
- NavMeshAgent 必须在根对象上

## 敌人动画配置

### 1. **Animator 参数设置**

在 Animator 中需要配置以下参数：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| **AnimType** | Integer | 动画类型（0-6，对应 EnemyAnimationType 枚举） |
| **MoveSpeed** | Float | 移动速度（用于混合树或速度缩放） |

### 2. **动画类型枚举值**

```csharp
public enum EnemyAnimationType
{
    Idle = 0,       // 待机
    Walk = 1,       // 行走/巡逻
    Alert = 2,      // 警戒
    Run = 3,        // 追击/奔跑
    Attack = 4,     // 攻击（预留）
    Death = 5,      // 死亡
    Rest = 6,       // 休息
}
```

### 3. **Animator 状态机配置示例**

```
Base Layer
├── Idle (AnimType == 0)
├── Walk (AnimType == 1)
├── Alert (AnimType == 2)
├── Run (AnimType == 3)
├── Attack (AnimType == 4)
├── Death (AnimType == 5)
└── Rest (AnimType == 6)
```

**配置方式：**
1. 在 Animator 中创建状态
2. 为每个状态添加条件：`AnimType == [对应值]`
3. 使用 MoveSpeed 参数控制动画速度（可选）

### 4. **混合树配置（推荐用于移动动画）**

对于 Walk 和 Run 状态，可以使用 1D 混合树根据 MoveSpeed 混合不同速度的动画：

```
Walk (1D BlendTree)
├── Walk_Slow (MoveSpeed: 0.5)
├── Walk_Normal (MoveSpeed: 1.0)
└── Walk_Fast (MoveSpeed: 1.5)

Run (1D BlendTree)
├── Run_Normal (MoveSpeed: 1.0)
└── Run_Fast (MoveSpeed: 1.5)
```

## 敌人对象的初始化流程

### 1. **Awake 阶段**
- 获取 NavMeshAgent 组件
- 记录出生点位置
- 生成实体唯一标识符 (GUID)

### 2. **Start 阶段**
- 调用 `Initialize()` 方法
- 加载配置数据（从 EnemyEntityTable）
- 配置 NavMeshAgent 参数
- 初始化视野检测器
- 创建 AI 状态机
- 初始化动画控制器
- 注册棋子数据到 EnemyChessDataManager
- 注册到 EnemyEntityManager

### 3. **Update 阶段**
- 更新 AI 状态机（`m_AI.Tick()`）
- AI 状态机根据条件切换状态
- 状态变更时调用 EnemyAnimator 播放对应动画

## 敌人动画播放流程

### 1. **状态机驱动动画**

```
EnemyEntityAI (状态机)
    ↓
ChangeState(newState)
    ↓
State.OnEnter()
    ↓
EnemyAnimator.PlayAnimation(animType)
    ↓
Animator.SetInteger("AnimType", value)
    ↓
Animator 播放对应动画
```

### 2. **各状态对应的动画**

| AI 状态 | 播放动画 | 说明 |
|--------|--------|------|
| Idle | Idle (0) | 待机状态 |
| Patrol | Walk (1) | 巡逻状态 |
| Alert | Alert (2) | 警戒状态 |
| Chase | Run (3) | 追击状态 |
| Combat | Attack (4) | 战斗状态 |
| Defeated | Death (5) | 被击败 |
| Rest | Rest (6) | 休息状态 |

### 3. **动画播放代码示例**

```csharp
// 在 AI 状态的 OnEnter 中调用
public override void OnEnter()
{
    // 播放对应动画
    m_Entity.GetComponent<EnemyAnimator>()?.PlayAnimation(EnemyAnimationType.Walk, 1.0f);
}

// 或者通过 EnemyEntity 获取
var animator = m_Entity.GetComponent<EnemyAnimator>();
animator.PlayAnimation(EnemyAnimationType.Run, 1.5f);
```

## 常见问题

### Q: 敌人不动画？
**A:** 检查以下几点：
1. Animator 是否有 AnimType 参数
2. 状态是否有正确的转换条件
3. EnemyAnimator 是否正确初始化
4. 查看日志是否有错误信息

### Q: 敌人移动速度不对？
**A:** 检查以下几点：
1. NavMeshAgent.speed 是否正确设置
2. MoveSpeed 参数是否正确传递
3. 混合树的参数范围是否正确

### Q: 敌人卡住不动？
**A:** 检查以下几点：
1. NavMesh 是否正确烘焙
2. NavMeshAgent 是否在 NavMesh 上
3. 目标点是否可达
4. 是否在战斗状态（战斗状态下 NavAgent 被禁用）

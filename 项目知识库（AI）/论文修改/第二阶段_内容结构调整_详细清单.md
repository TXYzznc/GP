## 批注 6 - 用例图单独存在

### 问题分析

**当前情况**:
- 段落 414：`系统总体用例如图3.1所示：`
- 段落 416：`图 3.1 系统总体用例图`
- 用例图单独存在，没有文字介绍

**问题**:
- 用例图没有配合文字说明
- 读者不知道用例图表示什么
- 与上下文的连接不紧密

### 修改方案

#### 修改前：
```
系统总体用例如图3.1所示：

[用例图]

图 3.1 系统总体用例图

玩家可执行用例：
探索系统用例：移动探索、触发战斗...
```

#### 修改后：
```
系统总体用例如图3.1所示：

[用例图]

图 3.1 系统总体用例图

系统的主要参与者为玩家和系统，其中玩家可执行的用例包括：

(1) 探索系统用例
    - 移动探索：玩家通过键鼠在三维场景中自由移动，探索游戏世界
    - 触发战斗：玩家与敌人接触时触发战斗，支持偷袭、遭遇、被追三种方式
    - 净化敌人：战胜敌人后可获得策略卡牌奖励
    - 脱战机制：玩家可尝试逃离战斗，成功则返回探索状态
    - 污染值管理：追踪玩家的探索进度，影响敌人强度

(2) 战斗系统用例
    - 部署棋子：战前在战场格子上选择并部署我方棋子
    - 自动战斗：战斗开始后棋子自动寻敌、移动、攻击
    - 使用策略卡：在战斗中使用卡牌触发效果，消耗手牌
    - 脱战尝试：玩家可尝试逃离战斗
    - 战斗结算：战斗结束后显示奖励和经验

(3) 物品系统用例
    - 管理背包：查看、整理、分类背包中的物品
    - 装备/卸装：将物品装备到装备槽或卸下
    - 使用消耗品：使用恢复类物品获得效果
    - 查看物品详情：查看物品的属性和效果说明

(4) 卡牌系统用例
    - 查看手牌：在战斗中查看当前拥有的策略卡牌
    - 使用卡牌：选择卡牌并选择目标执行效果
    - 查看卡牌效果：查看卡牌的详细效果说明

系统自动执行的用例包括：
- 敌人AI行为：敌人根据玩家位置自动巡逻、警觉、追击
- 战斗AI：棋子根据战场情况自动选择目标和技能
- 事件触发：系统根据游戏状态自动触发相关事件
```

### 修改步骤

1. **在用例图前添加引导文字**
   - 说明用例图的含义
   - 介绍主要参与者

2. **在用例图后添加详细说明**
   - 按类别列出各个用例
   - 为每个用例添加简洁的描述
   - 说明用例的目的和效果

3. **确保文字与图表的连接**
   - 用例图和文字说明相互补充
   - 读者可以通过文字理解用例图
   - 用例图可以直观展示系统结构

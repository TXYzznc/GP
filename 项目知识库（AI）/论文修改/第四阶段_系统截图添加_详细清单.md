## 截图操作指南

### 方法一：游戏运行时截图（推荐）
1. 在 Unity 中运行游戏
2. 进入对应场景/界面
3. 按 **PrintScreen** 或使用截图工具（如 Snipaste）
4. 保存为 PNG 格式，分辨率建议 1920×1080

### 方法二：Unity Editor 截图
1. 在 Scene 视图或 Game 视图中截图
2. 使用 Unity 的 `ScreenCapture.CaptureScreenshot()` 代码截图
3. 或直接截取 Game 视图

### 截图质量要求
- 分辨率：**1920×1080 或以上**
- 格式：**PNG**（清晰度高）
- 字体：确保截图中的 UI 文字清晰可读
- 内容：截图要能清楚展示对应功能

---

## 插入截图到论文的步骤

1. **截图保存**：将截图保存到 `开发文档/毕业论文参考/截图/` 文件夹
2. **在 Word 中插入**：
   - 将光标放在对应章节的合适位置
   - 插入 → 图片 → 选择截图文件
3. **调整图片大小**：
   - 宽度建议 12-14cm（适合 A4 页面）
   - 保持宽高比不变
4. **添加图片标题**：
   - 在图片下方添加标题
   - 格式：`图 5.X 标题描述`
   - 使用论文的图片标题样式
5. **在正文中引用**：
   - 在对应段落中添加引用，如"如图5.1所示"
